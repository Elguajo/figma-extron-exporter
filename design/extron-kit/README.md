# Extron Kit / pen.dev

Кит создан через pen.dev MCP в открытом пользовательском документе `untitled.pen`. Содержит 30 компонентов (16 универсальных, 14 готовых), 5 переиспользуемых шаблонов контейнеров, инструкции и примеры экранов 1280×800 и 320×480. Исходный пользовательский Frame сохранён.

- `kit.json` — общий каталог типов, служебных имён и палитры для генератора Figma.
- `pen-canvas.snapshot.json` — снимок подготовленных объектов, прочитанный через MCP; это JSON-снимок, не `.pen` и не `.fig`.
- `build-universal.pen.js`, `build-presets.pen.js`, `build-templates.pen.js` — последовательные MCP execute-сценарии создания исходного холста. Повторный запуск создаёт новые объекты; не запускать в уже построенном документе без намерения добавить второй комплект.
- `previews/` — PNG из настоящего рендера pen.dev: `MeFgF.png` — универсальные, `bBKBy.png` — готовые, `T78n4.png` — 1025M, `EWlyr.png` — 300M.

В pen.dev используется Inter, поскольку Arial недоступен в его шрифтовом каталоге. Нативные подписи Figma-экспортёра используют Arial. Подтверждена связь основных компонентов и экземпляров, включая сохранение индивидуального override при изменении основного компонента.

Перенос в Figma выполняет локальный плагин 0.3.0 кнопкой **«Создать Extron Kit»**; платная подписка/MCP не нужны. Сохранить `.fig` можно затем из самой Figma. Полный процесс и ограничения: [EXTRON_KIT.md](../../src/figma-plugin/EXTRON_KIT.md).
