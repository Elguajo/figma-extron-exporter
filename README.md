# Figma → Extron Exporter

Локальный конвертер подготовленных интерфейсов Figma в проекты Extron GUI Designer.

Реализованы чтение контейнера `.gdl`/`.glt`, структурное чтение NRBF, пересборка контейнера и экспериментальное изменение подписи существующей кнопки с сохранением ID. Пересобранный проект и вариант с «Музыка» прошли открытие, редактирование, Verify, штатный Save and Build и повторное открытие в GUI Designer 1.28.0.7. Генерации новых кнопок, экспорта `.exui`, Figma-плагина и desktop UI пока нет.

Результат конвертера — редактируемый `.gdl`. Build выполняет пользователь внутри GUI Designer; собственной функции Build в конвертере нет. Запуск штатной сборки в протоколе служит проверкой совместимости.

## Среда

.NET SDK 10.0.402, Windows. Версия зафиксирована в `global.json`. В текущей рабочей папке SDK установлен из официального Microsoft dotnet-install в `.tools/dotnet`, без изменения системного PATH. Эта папка не хранится в Git. На другом компьютере требуется установить SDK либо подготовить такой же локальный SDK.

Единственная внешняя библиотека — Microsoft `System.Formats.Nrbf` 10.0.11. Она читает записи без создания объектов Extron. Lock-файлы сохраняют разрешённые версии зависимостей. Код не использует BinaryFormatter.Deserialize и не загружает DLL Extron.

## Сборка

В PowerShell из корня проекта:

```powershell
$dotnet = '.\.tools\dotnet\dotnet.exe'
& $dotnet restore ExtronExporter.slnx --locked-mode
& $dotnet build ExtronExporter.slnx --no-restore
```

Если SDK установлен системно, вместо `$dotnet` можно использовать `dotnet`.

## Исследовать файл

```powershell
& $dotnet run --project src/cli --no-build -- inspect samples/original/Full-Test-Project.gdl
```

Выводит JSON: размер и SHA-256 payload, тип корня, поля проекта, количество записей, классов и краткий список элементов. Не проверяет открытие файла в GUI Designer.

## Пересобрать контейнер

```powershell
& $dotnet run --project src/cli --no-build -- repack samples/original/Full-Test-Project.gdl output/repacked-new.gdl
```

Каталог назначения должен существовать. Команда создаёт только новый файл и отказывается перезаписывать существующий. NRBF payload остаётся побайтово неизменным. Сжатие и размер контейнера могут отличаться. Это проверка упаковки, а не генерация интерфейса и не запись нового графа объектов.

Выходные коды: 0 — успешно, 1 — ошибка файла/формата/записи, 2 — неверные аргументы.

## Проверки

Используется небольшой исполняемый набор проверок без отдельного тестового фреймворка; запускается через `dotnet run`, а не `dotnet test`.

```powershell
& $dotnet run --project tests/format --no-build -- samples/original/Full-Test-Project.gdl 'C:\Users\Public\Documents\Extron\GUI Designer Templates\TouchLink Templates'
```

Без аргументов выполняются 24 синтетические проверки. Первый аргумент добавляет 10 проверок реального Full-Test-Project (чтение и изменение кнопки 8000), второй — каждого GLT в указанном каталоге. Полный прогон: 78 passed, 0 failed. Набор возвращает ненулевой код при ошибке.

Исходный GDL скопирован из родительской папки; SHA-256 указан в `samples/manifest.json`. Крупные сторонние образцы и сгенерированные проекты исключены из Git. При переносе репозитория образцы нужно предоставить отдельно и сверить с манифестом.

## Граница поддержки

Поддерживается только обнаруженный профиль: KP-контейнер с одной записью `ProjectGCP`, stored или DEFLATE, без шифрования, data descriptors, ZIP64, нескольких дисков и префикса перед локальной записью. Ограничения размера: контейнер 64 MiB, распакованный payload 128 MiB. Проверяются центральный каталог, соответствие локального заголовка, длины и CRC32.

Штатный Save and Build добавляет в GDL другие записи. Такие многозаписные файлы текущий reader намеренно отклоняет; это ограничение нашего инструмента, а не ошибка проекта. Для эксперимента оставлены копии до GUI-сохранения: `output/Full-Test-Project-repacked-before-gui.gdl` и `output/Full-Test-Project-music-generated.gdl`. Исходные проекты не изменялись.

## Экспериментальное изменение подписи

```powershell
& $dotnet run --project src/cli --no-build -- set-button-text samples/original/Full-Test-Project.gdl output/music-new.gdl 8000 'Press to begin' 'Музыка'
```

Создаёт только новый файл. Меняет обычный текст всех состояний одной кнопки по уникальному ID; проверяет ожидаемую старую подпись. Поддержан наблюдаемый профиль 1.28.0.7 с нулевым `UInt64 checksum`, без formatted text, общих с другими объектами строк/состояний и неизвестных массивов. Остальные байты NRBF, ссылки, ID и поля классов сохраняются. CRC и размеры контейнера пересчитываются. Это ограниченный редактор существующих строк, не writer новых объектов.
