Плагин **0.7.0** и **CLI 0.7.0** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Выпускаются парой, контракт — **EXUI/5**.

## Что изменилось

- Global Configurator Plus больше не показывает пустую страницу или popup, если на них есть картинки, фигуры, линии или регуляторы. CLI пишет у них пустой Text вместо null.
- Закруглённые кнопки больше не получают белые углы на фоне-изображении: состояния с PNG экспортируются с прозрачной заливкой.
- Оформление кнопок применяется к выделенному popup, модальному окну или группе popup во всех режимах экспорта, не затрагивая другие экраны. Сообщение называет область и считает подготовленные и обновлённые кнопки.
- Полупрозрачный нативный текст останавливает проверку с понятной подсказкой. Цвет текста — любой непрозрачный.
- Новое место `popupref_Name` автоматически связывается с соседним `popup_Name` или `popupgroup_Name` по одинаковой части имени. При нескольких совпадениях экспорт указывает конкретное место; сохранённые связи не заменяются.

Plugin ID, сохранённые назначения, ключи и ID элементов сохраняются. Существующие EXUI/5 можно конвертировать новым CLI без повторного экспорта; для исправления углов кнопок экспортируйте макет заново.

## Файлы

- `figma-extron-plugin-0.7.0.zip` — плагин Figma. Распакуйте в постоянную папку и импортируйте `manifest.json` через Plugins → Development → Import plugin from manifest.
- `figma-extron-cli-0.7.0-windows.zip` — CLI для Windows. Нужны .NET 10 Runtime x64 и GUI Designer 1.28.0.7. Доноры и DLL Extron в архив не входят; используйте собственный комплект или `--registry`.
- `SHA256SUMS.txt` — контрольные суммы архивов.

## Проверка и ограничения

Проверены тесты плагина и .NET, сборка и конвертация из итоговых архивов через установленные DLL Extron с независимым чтением GDL. Углы кнопок проверены визуально в GUI Designer; исправление пустого preview подтверждено пользователем в GCP.

Это preview. Figma API в автоматических сценариях моделируется; физическая панель не проверена. Команды, переходы и feedback подключает программа управления Extron.
