Плагин Figma **0.6.0** и CLI для Windows **0.6.0**: перенос макета сенсорной панели из Figma в редактируемый проект Extron GUI Designer (`.gdl`). Контракт пакетов — **EXUI/5**. Панели: TLP Pro 1025M (1280×800) и TLP Pro 300M (320×480, портрет).

> Preview. Конвертация проверена в GUI Designer (Verify → Save and Build → повторное открытие) на прежних выпусках. Работа на физической панели, касания, удержания и feedback ещё не проверены.

## Что скачать

| Файл | Для чего |
|---|---|
| `figma-extron-plugin-0.6.0.zip` | плагин для Figma Desktop |
| `figma-extron-cli-0.6.0-windows.zip` | CLI: проверка пакета, карта ID, конвертация в `.gdl` |

Нужны: Figma Desktop; для CLI — Windows и .NET 10 Runtime x64; для конвертации — Extron GUI Designer 1.28.0.7 и донорские GDL. **Доноры и DLL Extron в архивы не входят.**

## Установка

1. Распакуйте оба архива в постоянные папки.
2. Figma Desktop → **Plugins → Development → Import plugin from manifest…** → `manifest.json`. В заголовке плагина — **0.6.0**. Не меняйте `id` в `manifest.json`: назначения элементов привязаны к нему.
3. В PowerShell из папки CLI проверьте пример:
   ```powershell
   .\ExtronExporter.ps1 validate-package .\examples\home-1025m\home.exui
   ```
4. Положите доноры в `samples\donors\` и конвертируйте:
   ```powershell
   .\ExtronExporter.ps1 convert-package .\examples\home-1025m\home.exui .\home.gdl
   ```

Полная инструкция — в [README](https://github.com/Elguajo/figma-extron-exporter#как-пользоваться).

## Что нового с 0.5.5

- **Ключи по именам слоёв.** «Проверить макет» и «Скачать .exui» строят ключи из текущих имён: `page.home` у `screen_AudioControl` становится `page.audiocontrol`, `homeexportready.volume-2` — `audiocontrol.volume`. Переходы обновляются, ID не меняются. Ключ, введённый вручную, сохраняется; пустое поле возвращает автоматический.
- **Только латиница в именах слоёв.** Русские буквы в именах экранов, popup, групп и элементов — ошибка с латинским вариантом (`Главная` → `screen_Glavnaya`). Видимый текст может оставаться русским.
- **Порядок страниц по именам.** Страницы и popup идут в GDL по именам фреймов с учётом чисел: `screen_01-MainDashboard`, `screen_02-AudioControl`, `screen_10-Video`. Номер не входит в ключ; стартовая страница не меняется.
- **Подписи Inter** больше не обрезаются в GUI Designer.
- **CLI 0.6.0** — общая версия комплекта; конвертация не изменилась с 0.5.2.

Полная история — [CHANGELOG.md](https://github.com/Elguajo/figma-extron-exporter/blob/main/CHANGELOG.md).

## Совместимость

- Плагин 0.6.0 работает с CLI 0.6.0. CLI 0.6.0 принимает пакеты EXUI/5 от плагинов 0.5.0–0.5.5 и даёт тот же GDL, что и CLI 0.5.2.
- Пакеты EXUI/1–4 нужно экспортировать из Figma заново.
- Назначения и ID в существующих файлах Figma сохраняются. Ключи при первой проверке перестраиваются по именам слоёв. Слои с русскими именами нужно переименовать латиницей.
