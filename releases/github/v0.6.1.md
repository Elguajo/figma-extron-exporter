Плагин Figma **0.6.1** и CLI для Windows **0.6.0**: перенос макета сенсорной панели из Figma в редактируемый проект Extron GUI Designer (`.gdl`). Контракт пакетов — **EXUI/5**. Панели: TLP Pro 1025M (1280×800) и TLP Pro 300M (320×480, портрет).

> Preview. Конвертация проверена в GUI Designer (Verify → Save and Build → повторное открытие) на прежних выпусках. Работа на физической панели, касания, удержания и feedback ещё не проверены.

## Что скачать

| Файл | Для чего |
|---|---|
| `figma-extron-plugin-0.6.1.zip` | плагин для Figma Desktop |
| `figma-extron-cli-0.6.0-windows.zip` | CLI: проверка пакета, карта ID, конвертация в `.gdl` |

Нужны: Figma Desktop; для CLI — Windows и .NET 10 Runtime x64; для конвертации — Extron GUI Designer 1.28.0.7 и донорские GDL. **Доноры и DLL Extron в архивы не входят.**

## Установка

1. Распакуйте оба архива в постоянные папки.
2. Figma Desktop → **Plugins → Development → Import plugin from manifest…** → `manifest.json`. В заголовке плагина — **0.6.1**. Не меняйте `id` в `manifest.json`: назначения элементов привязаны к нему.
3. В PowerShell из папки CLI проверьте пример:
   ```powershell
   .\ExtronExporter.ps1 validate-package .\examples\home-1025m\home.exui
   ```
4. Положите доноры в `samples\donors\` и конвертируйте:
   ```powershell
   .\ExtronExporter.ps1 convert-package .\examples\home-1025m\home.exui .\home.gdl
   ```

Полная инструкция — в [README](https://github.com/Elguajo/figma-extron-exporter#как-пользоваться).

## Что нового с 0.6.0

- **Дата и время в Extron Kit.** «Создать Extron Kit» добавляет `datetime_Clock` с 28 форматами: 24 пресета Pattern из GUI Designer 1.28 и 4 дополнительных, включая `MMMM d, h:mm tt`. Формат выбирается свойством **Format** экземпляра, текст показывает пример как в GUI Designer — `September 28, 12:00 AM`. Оформление текста сохраняется при смене формата.
- **Формат по макету.** Свойство Format, Text-слой `Pattern: dddd, d MMMM`, текст-пример из каталога или сам формат `HH:mm`. В плагине — список форматов и живой пример; введённый вручную формат сохраняется.
- **Понятная ошибка** для текста вроде `12:45`, который не является ни форматом, ни примером, — вместо неверного Pattern в GDL.

Полная история — [CHANGELOG.md](https://github.com/Elguajo/figma-extron-exporter/blob/main/CHANGELOG.md).

## Совместимость

- Плагин 0.6.1 работает с CLI 0.6.0; CLI не изменился.
- Прежние макеты не меняются: сохранённый формат даты/времени используется, пока текст слоя — сам формат.
- Назначения и ID в существующих файлах Figma сохраняются; EXUI/5 и plugin ID прежние.
