Плагин **0.8.0** и **CLI 0.8.0** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт **EXUI/5**; plugin ID, metadata слоёв и сохранённые назначения не менялись.

## Что изменилось

- **Extron Kit.** Apple-inspired Light для всех семейств и форматов часов, AV-сценарии `project_AVPatterns` для 1025M и 300M, 18 иконок Lucide, кнопки Volume +/− и навигации — Normal / Pressed. Новая библиотека создаётся рядом со старой.
- **Совместимость Extron.** Поддерживаемые версии GUI Designer описаны в `compatibility/extron.json`, команды генерации принимают `--compatibility`. Новая команда `doctor` проверяет установку без загрузки проекта.
- **Быстрее.** Выделение слоя и проверка/выгрузка проекта в 2–3 раза реже обходят дерево дизайна; генерация больших проектов в CLI ~15% быстрее. Пакеты `.exui` и проекты `.gdl` совпадают с прежними байт в байт.
- **Стабильнее.** Повреждённые данные слоя больше не «замораживают» панель плагина. CLI не сообщает об ошибке после успешной записи из-за временных файлов и не завершается аварийно при повреждённом ответе хоста. Новые переменные: `EXUI_HOST_TIMEOUT`, `EXUI_HOST_TRACE`. В плагине — кнопка «Скопировать диагностику».
- Нумерация обрабатывает только непосредственно выделенные кнопки.

## Установка

- `figma-extron-plugin-0.8.0.zip` — распаковать и импортировать `manifest.json` через Plugins → Development → Import plugin from manifest. При обновлении заменить файлы и перезапустить плагин. Заголовок — **0.8.0**.
- `figma-extron-cli-0.8.0-windows.zip` — CLI для Windows; нужны .NET 10 Runtime x64 и GUI Designer 1.28.0.7. Доноры и DLL Extron не включены. Перед первой конвертацией: `.\ExtronExporter.ps1 doctor`.
- `SHA256SUMS.txt` — контрольные суммы архивов.
