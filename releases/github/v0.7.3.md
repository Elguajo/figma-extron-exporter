Плагин **0.7.3** и **CLI 0.7.3** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт **EXUI/5**.

## Что изменилось

- Под «Оформление кнопок» добавлен отдельный раздел **«Нумерация кнопок»** с основой имени, начальным номером и предпросмотром.
- **«Заново по расположению»** нумерует слева направо, сверху вниз. В каждой группе или фрейме отдельный счёт, включая вложенные контейнеры.
- **«Исправить только повторы»** сохраняет занятые номера и выдаёт свободные копиям и кнопкам без номера выбранной основы. Оригинал имеет приоритет перед копией; невыбранные слои не меняются.
- Имена слоёв и текст обновляются независимо. Текст можно синхронизировать во всех состояниях кнопки, включая скрытые. Обновление текста изначально выключено.
- ID Extron сохраняются. Неоднозначные подписи и ошибки шрифтов обнаруживаются до записи; устаревший план требует обновления. Изменения можно отменить в Figma.
- CLI выпускается парой с прежним конвертером. Формат EXUI/5 и plugin ID не менялись.

## Установка

- `figma-extron-plugin-0.7.3.zip` — распаковать и импортировать `manifest.json` через Plugins → Development → Import plugin from manifest. При обновлении заменить файлы и перезапустить плагин. Заголовок — **0.7.3**.
- `figma-extron-cli-0.7.3-windows.zip` — CLI для Windows; нужны .NET 10 Runtime x64 и GUI Designer 1.28.0.7. Доноры и DLL Extron не включены.
- `SHA256SUMS.txt` — контрольные суммы архивов.
