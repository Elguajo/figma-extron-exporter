Плагин Figma **0.5.5** и CLI для Windows **0.5.2**: перенос макета сенсорной панели из Figma в редактируемый проект Extron GUI Designer (`.gdl`). Контракт пакетов — **EXUI/5**. Панели: TLP Pro 1025M (1280×800) и TLP Pro 300M (320×480, портрет).

> Preview. Конвертация проверена в GUI Designer (Verify → Save and Build → повторное открытие). Работа на физической панели, касания, удержания и feedback ещё не проверены.

## Что скачать

| Файл | Для чего |
|---|---|
| `figma-extron-plugin-0.5.5.zip` | плагин для Figma Desktop |
| `figma-extron-cli-0.5.2-windows.zip` | CLI: проверка пакета, карта ID, конвертация в `.gdl` |

Нужны: Figma Desktop; для CLI — Windows и .NET 10 Runtime x64; для конвертации — Extron GUI Designer 1.28.0.7 и донорские GDL. **Доноры и DLL Extron в архивы не входят.**

## Установка

1. Распакуйте оба архива в постоянные папки.
2. Figma Desktop → **Plugins → Development → Import plugin from manifest…** → `manifest.json`. В заголовке плагина — **0.5.5**. Не меняйте `id` в `manifest.json`: назначения элементов привязаны к нему.
3. В PowerShell из папки CLI проверьте пример:
   ```powershell
   .\ExtronExporter.ps1 validate-package .\examples\home-1025m\home.exui
   ```
4. Положите доноры в `samples\donors\` и конвертируйте:
   ```powershell
   .\ExtronExporter.ps1 convert-package .\examples\home-1025m\home.exui .\home.gdl
   ```

Полная инструкция — в [README](https://github.com/Elguajo/figma-extron-exporter#как-пользоваться).

## Что нового с 0.5.1

- **Кнопки в предпросмотре (0.5.5).** «Проверить макет» и «Скачать .exui» сами скрывают лишние видимые состояния кнопки; вручную переключать слои больше не нужно. В экспорт по-прежнему входят все состояния.
- **Дробные линии (0.5.4).** Линии Pen/Line Tool с толщиной вроде 1.5 px и дробными координатами округляются при экспорте и остаются нативным PBLine.
- **Повёрнутые кнопки и текстовые компоненты (0.5.3).** Поворот и отражение кнопок сохраняются в PNG состояний. Label / Value / DateTime принимают Component с одним Text.
- **Целые пиксели и понятные ошибки (0.5.2).** Координаты и размеры нативных элементов округляются до целых пикселей, исходный макет не меняется. Ошибка имени показывает недопустимый символ и пример исправления. «Показать слой» точно наводит на слой, включая линии нулевой высоты.

Полная история — [CHANGELOG.md](https://github.com/Elguajo/figma-extron-exporter/blob/main/CHANGELOG.md).

## Совместимость

- Плагин 0.5.5 работает с CLI 0.5.2. Отдельного CLI 0.5.5 нет — менялся только плагин.
- Пакеты EXUI/5 от плагинов 0.5.0–0.5.4 принимаются. Пакеты EXUI/1–4 нужно экспортировать из Figma заново; ключи и ID сохранятся.
- Назначения элементов, ключи и ID в существующих файлах Figma сохраняются.
