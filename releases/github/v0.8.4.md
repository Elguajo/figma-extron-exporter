Плагин **0.8.4** для переноса макетов Figma в редактируемый проект Extron GUI Designer, вместе с **CLI 0.8.3**. Контракт **EXUI/5**. Preview.

Plugin **0.8.4** for turning Figma layouts into editable Extron GUI Designer projects, used with **CLI 0.8.3**. Contract **EXUI/5**. Preview.

## Что изменилось / What changed

- Документация на английском: README на английском (русский — README.ru.md), руководства плагина и CLI — сначала на русском, ниже на английском. Интерфейс плагина остаётся на русском. / English documentation: the README is in English (Russian in README.ru.md); plugin and CLI guides contain Russian first and English below. The plugin interface stays in Russian.
- В архив плагина добавлен `LICENSE`. / The plugin archive now includes `LICENSE`.
- Функции плагина, EXUI/5, plugin ID и назначения не менялись; CLI остаётся 0.8.3. / Plugin features, EXUI/5, the plugin ID and assignments are unchanged; the CLI stays at 0.8.3.

## Установка / Installation

- `figma-extron-plugin-0.8.4.zip` — распаковать и импортировать `manifest.json` через Plugins → Development → Import plugin from manifest; заголовок — **0.8.4**. / Unpack and import `manifest.json` via Plugins → Development → Import plugin from manifest; the title shows **0.8.4**.
- CLI: `figma-extron-cli-0.8.3-windows.zip` из [выпуска v0.8.3](https://github.com/Elguajo/figma-extron-exporter/releases/tag/v0.8.3). / CLI: from the [v0.8.3 release](https://github.com/Elguajo/figma-extron-exporter/releases/tag/v0.8.3).
- `SHA256SUMS.txt` — контрольная сумма архива плагина. / Checksum of the plugin archive.
