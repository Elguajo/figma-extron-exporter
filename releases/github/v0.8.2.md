Плагин **0.8.2** и **CLI 0.8.2** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт **EXUI/5**. Preview.

## Что изменилось

- **Автоматическое положение текста кнопок.** В «Тексте кнопок для GCP» появился режим «Автоматически из Figma»: при каждом экспорте положение текстовой рамки внутри кнопки определяет центр или низ; по горизонтали текст всегда по центру. Рамка на всю кнопку означает центр. Верхнее и неоднозначное положение дают понятную ошибку с указанием слоя. Ручные режимы и отмена сохранены.
- **Обновление настроенных проектов без потери логики.** Инструкция `docs/updating-configured-projects.md` описывает основной путь для проектов, где программист добавлял страницы и кнопки прямо в GUI Designer: оформление выбранных кнопок переносится в рабочий GDL (`plan-layout-update` → `selection.json` → `update-layout`), а не импортируется GDL из Figma целиком. Даны готовые команды PowerShell. Путь проверен в копии реального проекта GCP: команды, Text и Visual Feedback обновлённых кнопок и ручные страницы сохранились.
- Конвертер CLI не менялся: пакеты EXUI от плагина 0.8.1 подходят.

## Установка

- `figma-extron-plugin-0.8.2.zip` — распаковать и импортировать `manifest.json` через Plugins → Development → Import plugin from manifest. При обновлении заменить файлы и перезапустить плагин; заголовок — **0.8.2**.
- `figma-extron-cli-0.8.2-windows.zip` — CLI для Windows. Для конвертации нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные подготовленные доноры. Доноры и DLL Extron в архив не входят.
- `SHA256SUMS.txt` — контрольные суммы обоих архивов.

Сохранённый режим `auto` читает только плагин 0.8.2 и новее. Чтобы вернуться к 0.8.1, сначала выберите ручное положение или «Сохранить расположение Figma».

## Проверки и ограничения

TypeScript и 647 тестов плагина, сборка .NET без предупреждений, 251 тест формата, 286 проверок с реальными донорами Extron и шесть эталонных GDL байт в байт, интерфейс в Chromium, 28 сценариев, нумерация и нативный текст из итоговых архивов. Команды новой инструкции выполнены итоговым CLI на GDL реального проекта.

Рабочий GDL для выборочного обновления должен быть сохранён GUI Designer; файл в обычном ZIP-контейнере CLI не читает (`Missing KP end record…`). В консоли с кодовой страницей 437 кириллица в JSON-выводе CLI показывается как `?`; в GDL текст сохраняется правильно.

[Полный протокол выпуска](https://github.com/Elguajo/figma-extron-exporter/blob/main/docs/verification/results/2026-10-25-release-0.8.2.md). Figma API и PNG в автоматических сценариях моделируются. Физическая панель не проверялась. Проверки данных не заменяют проверку назначений и feedback в вашем проекте GCP.
