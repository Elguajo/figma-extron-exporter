Плагин **0.7.2** и **CLI 0.7.2** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт **EXUI/5**.

## Что изменилось

- В «Оформление кнопок» можно выбрать **Off / On** либо **Normal / Pressed**. Оба состояния создаются и оформляются по образцам.
- **Override** («Применить новый стиль и к готовым») также преобразует готовые обычные пары **Off / On ↔ Normal / Pressed**. Имена и роли сохранённых назначений обновляются вместе; ID кнопки, слои, содержимое, геометрия и видимость сохраняются. В пакете и GDL остаются слоты 0/1.
- «Пропустить готовые кнопки» сохраняет существующие пары. Feedback-кнопки сохраняют свою схему Normal / Active с необязательным Pressed.
- Override обрабатывает только текущее выделение: один или несколько фреймов либо контейнеры отдельных кнопок. Остальные экраны и связанные popup не добавляются из сохранённой области экспорта.
- Включены коррекция контраста текста/иконок и применение активного образца к существующему Pressed.
- CLI выпускается парой без изменения конвертера. Сохранены исправления пустых страниц GCP и прозрачных углов кнопок из 0.7.0.

## Установка

- `figma-extron-plugin-0.7.2.zip` — распаковать и импортировать manifest.json через Plugins → Development → Import plugin from manifest. При обновлении заменить файлы и перезапустить плагин. Заголовок — **0.7.2**.
- `figma-extron-cli-0.7.2-windows.zip` — CLI для Windows; нужны .NET 10 Runtime x64 и GUI Designer 1.28.0.7. Доноры и DLL Extron не включены.
- `SHA256SUMS.txt` — контрольные суммы архивов.
