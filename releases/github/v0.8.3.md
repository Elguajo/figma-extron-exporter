Плагин **0.8.3** и **CLI 0.8.3** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт **EXUI/5**. Preview, сопровождающий выпуск.

## Что изменилось

- Функции плагина, конвертер CLI и утилита обновления не менялись по сравнению с 0.8.2; версии подняты для нового парного комплекта. Пакеты EXUI от плагинов 0.8.1 и 0.8.2 подходят.
- Старые выпуски плагина 0.1.1–0.4.5 перенесены в `releases/figma-plugin/Legacy/`.

## Установка

- `figma-extron-plugin-0.8.3.zip` — распаковать и импортировать `manifest.json` через Plugins → Development → Import plugin from manifest. При обновлении заменить файлы и перезапустить плагин; заголовок — **0.8.3**.
- `figma-extron-cli-0.8.3-windows.zip` — CLI для Windows. Для конвертации нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные подготовленные доноры. Доноры и DLL Extron в архив не входят.
- `SHA256SUMS.txt` — контрольные суммы обоих архивов.

## Проверки и ограничения

TypeScript и 647 тестов плагина, сборка .NET без предупреждений, 286 проверок с реальными донорами Extron и шесть эталонных GDL байт в байт, 28 сценариев, нумерация и нативный текст из итоговых архивов.

[Полный протокол выпуска](https://github.com/Elguajo/figma-extron-exporter/blob/main/verification/results/2026-10-25-release-0.8.3.md). Figma API и PNG в автоматических сценариях моделируются. Физическая панель не проверялась.
