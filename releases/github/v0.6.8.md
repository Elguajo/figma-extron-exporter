Плагин **0.6.8** и совместимый **CLI 0.6.5** для переноса макетов Figma в редактируемый проект Extron GUI Designer. Контракт — **EXUI/5**.

## Что изменилось

- Связанные popup автоматически включаются в экспорт выбранных экранов и текущей страницы. Ошибки отсутствующей цели и несовпадения размеров показывают конкретный popupref.
- Прозрачный popup больше не получает серую внутреннюю заливку донора. CLI проверяет оформление контейнера и принимает прозрачную заливку состояний кнопок.
- Линии поддерживают прозрачность Stroke/Fill и Opacity, сохраняя нативный тип PBLine.
- Сокращены повторные обходы страницы при запуске плагина и обновлении выбора. Раздел оформления кнопок изначально свёрнут.
- Растровые изображения обрезаются по Clip content экрана или popup.

Plugin ID, сохранённые назначения, ключи и ID элементов сохраняются. Существующие EXUI/5 можно конвертировать новым CLI без повторного экспорта.

## Файлы

- `figma-extron-plugin-0.6.8.zip` — плагин Figma. Распакуйте в постоянную папку и импортируйте `manifest.json` через Plugins → Development → Import plugin from manifest.
- `figma-extron-cli-0.6.5-windows.zip` — CLI для Windows. Нужны .NET 10 Runtime x64 и GUI Designer 1.28.0.7. Доноры и DLL Extron в архив не входят; используйте собственный комплект или `--registry`.
- `SHA256SUMS.txt` — контрольные суммы архивов.

## Проверка и ограничения

Проверены тесты плагина, типы, сборка, интерфейс в Chromium и конвертация из итоговых архивов через установленные DLL Extron с независимым чтением GDL. Пользователь подтвердил корректный результат исправленного рабочего GDL в GUI Designer. Числа отдельного Verify не записаны.

Это preview. Figma API в автоматических сценариях моделируется; физическая панель не проверена. Команды, переходы и feedback подключает программа управления Extron.
