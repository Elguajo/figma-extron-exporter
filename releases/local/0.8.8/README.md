# Полный локальный комплект 0.8.8

Содержит плагин Figma, CLI, папку `updater`, инструкции и локальные доноры. Архив не входит в Git и не предназначен для публичной публикации; публичные ZIP без доноров размещены в `releases/figma-plugin/0.8.8` и `releases/cli/0.8.8`.

Новый процесс: EXUI → выбор соответствий кнопок в LayoutUpdater → новый GDL и карта ID → импорт карты в плагин Figma → следующий EXUI с ID GUI Designer.
