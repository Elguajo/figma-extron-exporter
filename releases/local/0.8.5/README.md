# Локальный комплект 0.8.5

По запросу пользователя комплект размещён рядом с остальными выпусками в `releases`.

`figma-extron-complete-0.8.5-local.zip` содержит плагин, CLI, папку `updater` и частные доноры из этого репозитория. Это локальный архив; в Git и публичный релиз он не входит. Для публичного распространения используются отдельные ZIP в `releases/figma-plugin/0.8.5` и `releases/cli/0.8.5`, в CLI ZIP доноров нет.
