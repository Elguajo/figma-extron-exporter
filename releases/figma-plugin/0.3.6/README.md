# Figma → Extron Exporter 0.3.6 preview

[Скачать обновлённый плагин](../../../output/releases/0.3.6/figma-extron-plugin-0.3.6.zip).

Распакуйте в постоянную папку и импортируйте `manifest.json` через Figma → Plugins → Development → Import plugin from manifest… . Перезапустите плагин: в заголовке должно быть **0.3.6**. Plugin ID сохранён. CLI обновлять для изменения отчёта не требуется; используйте совместимый CLI 0.3.0.

При ошибке распознавания, проверки или скачивания отчёт сразу показывает проблемы. У каждой ошибки есть имя и фактический тип слоя, путь от экрана, требование и инструкция исправления. Одноимённые `Normal` в разных кнопках различаются по пути.

1. Нажмите **«Показать слой»** — плагин выделит нужный элемент в Figma и приблизит его на холсте. Отчёт сохранится.
2. Исправьте имя или структуру слоя в Figma по инструкции.
3. Нажмите **«Повторить распознавание»** — проверяется весь исходный экран или набор экранов, даже после перехода к вложенному слою.

Ошибки блокируют запись назначений. Частично распознанные назначения свёрнуты под ошибками. Существующие назначения сохраняются. Исправления структуры выполняет дизайнер; плагин не группирует и не переименовывает рисунок автоматически. Дополнительные требования оформления могут обнаружиться после исправления структуры.

[Протокол проверки](../../../verification/results/2026-10-21-recognition-errors.md). Проверены исходники и Chromium со стендом Figma API. Живой Figma Desktop, GUI Designer и физические панели для этой ревизии не проверялись.
