# Figma → Extron Exporter 0.4.1 preview

Нарисуйте кнопки обычными **Group или Frame**, задайте префиксы и два эталона оформления. Плагин создаст вложенные Group состояний: `button_` / `btn_` → **Off / On**, `feedbackbutton_` / `fbtn_` → **Normal / Active**. Ручной Pressed, существующие состояния и ID сохраняются. Отдельная команда обновляет заливку/обводку из эталонов.

[Архив плагина](../../../output/releases/0.4.1/figma-extron-plugin-0.4.1.zip) · [Инструкция](../../../src/figma-plugin/BUTTON_STATES.md) · [Проверки](../../../verification/results/2026-10-21-button-state-preparation.md).

Распакуйте архив в постоянную папку, импортируйте или обновите development-плагин через `manifest.json` с сохранением plugin ID. После перезапуска заголовок должен показывать **0.4.1**. CLI остаётся **0.4.0**, формат **EXUI/5** не меняется.

1. На той же странице, вне экранов, создать `Button Styles` с образцами `Passive` и `Active`. Либо в разделе «Состояния кнопок» явно запомнить выбранные прямоугольники/готовые состояния как обычный и активный эталон.
2. Выделить экран или выбранные экраны проекта → «Создать состояния по эталонам».
3. «Проверить макет» → «Скачать .exui».
4. После изменения эталонов — «Обновить стили состояний». Скругление переносится по отдельной настройке.

Если фон неоднозначен, выбрать нужный прямоугольник и нажать «Выбранный слой — фон». Оформление сохраняется в PNG; подписи произвольного размера тоже входят в PNG, а поддержанный текст на всю кнопку может остаться нативным. Прозрачные углы используют цвет страницы; для полного контура использовать Stroke INSIDE. Подробные ограничения приведены в инструкции.

Проверки API используют явный Figma fixture; Chromium проверяет настоящий UI с моделируемым bridge. Ручной цикл Figma Desktop → GUI Designer Verify / Save and Build и физическая панель для этой версии не выполнены.
