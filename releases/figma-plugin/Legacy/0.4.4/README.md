# Figma → Extron Exporter 0.4.4 preview

Исправлен ложный отказ у обычной линии с Position Center и постоянной толщиной. Figma может возвращать `variableWidthStrokeProperties: {widthProfile: 'UNIFORM'}`; прежняя проверка ошибочно отклоняла любой объект в этом поле. UNIFORM теперь принимается наравне с null: такая линия экспортируется нативным PBLine без PNG.

Текст ошибки разделён по реальной причине: положение обводки, пунктир, переменная толщина или кисть. Ошибка больше не просит выбрать Center, когда отказ вызван другим свойством.

[Скачать плагин](../../../../output/releases/0.4.4/figma-extron-plugin-0.4.4.zip). CLI **0.4.0**, EXUI/5 и plugin ID сохранены. Включены предыдущие исправления дробной геометрии внутри PNG и декоративных углов Frame экрана.

Для development-плагина из src/figma-plugin/manifest.json закрыть окно и запустить плагин снова. Заголовок должен показывать **0.4.4**. Затем выбрать Frame экрана и повторить проверку. При установке из ZIP импортировать manifest.json распакованного нового архива с прежним plugin ID.
