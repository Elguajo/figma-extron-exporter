# Figma → Extron Exporter 0.3.7 preview

Текущий комплект: **плагин 0.3.7 + CLI 0.4.0**, только **EXUI/5**.

[Плагин](../../../../output/releases/0.3.7/figma-extron-plugin-0.3.7.zip) · [CLI Windows](../../../../output/releases/0.3.7/figma-extron-cli-0.4.0-windows.zip).

Распакуйте плагин в постоянную папку, обновите существующий development-плагин через `manifest.json`, сохранив plugin ID, и перезапустите его. Заголовок должен показывать **0.3.7**. Обновите CLI вместе с плагином; инструкция находится в архиве CLI.

В этой версии:

- Ручные назначения и распознавание используют общие правила типов узлов и состояний.
- Экран, секция, выбранные фреймы и текущая страница разрешаются одним модулем области экспорта.
- Типы назначений требуют соответствующие ключи, ID и свойства.
- Проверенное после записи описание переиспользуется при проверке и экспорте. Изменения дизайна проверяются до и после PNG, включая родителя и абсолютную геометрию.
- Плагин всегда выпускает EXUI/5; CLI больше не читает EXUI/1–4. Старый пакет нужно экспортировать из Figma заново. Сохранённые назначения, ключи и ID остаются на месте.

Подробные ошибки распознавания из 0.3.6, автоматические назначения, Pen/Line, компоненты и оба профиля панелей сохранены. Повторная конвертация создаёт новый GDL и не переносит ручные правки из предыдущего GDL.

Сборка и автоматические проверки не заменяют отдельный цикл GUI Designer Verify/Build и проверку оборудования. Результаты проверок этой версии записаны в [протоколе](../../../../docs/verification/results/2026-10-21-simplification.md).
