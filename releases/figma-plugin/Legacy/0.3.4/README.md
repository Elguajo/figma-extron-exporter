# Figma → Extron Exporter 0.3.4 preview

Pen Tool (Vector) и Line Tool поддерживаются как редактируемые нативные линии Extron без PNG. Совместимый CLI — 0.3.0; EXUI/5, plugin ID и существующие назначения не меняются. Возможности 0.3.3 сохранены.

- [Плагин 0.3.4](../../../../output/releases/0.3.4/figma-extron-plugin-0.3.4.zip).
- [Полный локальный комплект с CLI 0.3.0](../../../../output/releases/0.3.4/figma-extron-complete-0.3.4-local.zip).
- [Правила подготовки линий](../../../../src/figma-plugin/AUTHORING_STANDARD.md#линии-pen-tool-и-line-tool-034).
- [Протокол проверки](../../../../verification/results/2026-10-21-pen-lines.md).

Распаковать архив в постоянную папку и импортировать `manifest.json` через Figma → Plugins → Development → Import plugin from manifest… (в полном комплекте — `figma-plugin/manifest.json`). Перезапустить плагин; заголовок должен показывать **0.3.4**.

1. Назвать отрезок `line_Divider` / `ln_Divider` и поместить непосредственно в Frame страницы.
2. Один открытый горизонтальный или вертикальный отрезок; Stroke SOLID, непрозрачный, CENTER, без Fill, плоские окончания NONE. Толщина и длина — целые пиксели; длина больше толщины.
3. Для нечётной толщины края обводки попадут на целые пиксели, если ось проходит по половине пикселя (например y=100.5 при толщине 1 px).
4. Выбрать экран/проект → «Распознать по именам» → «Сохранить распознанные назначения» → «Проверить макет» → «Скачать .exui».

Кривые, диагонали, ломаные, замкнутые контуры, пунктир, стрелки и кисти пока не поддержаны. Простые линии сохраняют цвет и толщину Stroke; ручное назначение типа «Линия» также доступно. Старый способ через пустой Frame/Rectangle с заливкой остаётся рабочим.

Автоматические проверки используют Figma API fixture и настоящий CLI/Extron writer. Figma Desktop, GUI Designer Verify/Build и физическая панель требуют отдельного прогона для этой версии.
