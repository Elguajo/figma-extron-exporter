# Figma → Extron Exporter 0.2.1

[Плагин 0.2.1](figma-extron-plugin-0.2.1.zip) · [Совместимый CLI для Windows](../../../cli/0.2.1/figma-extron-cli-0.2.1-windows.zip) · [Запуск CLI](../../../cli/0.2.1/README.md)

## Что изменилось

Плагин теперь экспортирует в exui/5 кнопки с ровно пустой собственной подписью. Отдельные Label/Value можно оставить поверх кнопок на исходных координатах — как в проверенном Home 1025M. Пробельные строки запрещены; Label/Value и Multistate Level остаются непустыми. Прежние exui/1–4 и стабильный plugin ID сохранены.

CLI этого релиза включает последние исправления бегунка Slider и его пропорций, PBImage и выравнивания Value/Label. Нужны плагин и CLI из одного комплекта; архив 0.2.0 остаётся прежним.

## Установка

1. Распаковать ZIP в постоянную папку. В Figma Desktop: Plugins → Development → Import plugin from manifest… → выбрать `manifest.json` из распакованной папки. ID вручную не менять.
2. Перезапустить плагин; заголовок должен показывать **0.2.1**. Выбрать подготовленный **HomeLayoutReady** в документе «2026-10 - Trilliant» либо собственный подготовленный Frame.
3. Нажать «Проверить экран» → «Скачать .exui». Существующие назначения заново сохранять не требуется.
4. Проверить и преобразовать пакет совместимым CLI по его инструкции. Открыть копию GDL в GUI Designer → Verify → Save and Build → закрыть и открыть снова.

Стандарт и справочник входят в архив: `AUTHORING_STANDARD.md`, `PREFIXES.md`. Для самостоятельного CLI нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и закреплённые доноры. Полный локальный комплект с донорами и Home хранится отдельно в `output/releases/0.2.1/`.

## Проверки и ограничения

[Протокол выпуска](../../../../docs/verification/results/2026-10-21-release-0.2.1.md) фиксирует проверки именно готовых архивов. [Предыдущий настоящий Home/GUI-цикл](../../../../docs/verification/results/2026-10-21-home-layout-1025m.md): 47 элементов, 15 PNG, 432/432 при конвертации, Verify 0/0, Build/reopen, 426/426 после Build.

Повторный настоящий экспорт установленного архива 0.2.1 подтверждён: HomeLayoutReady → 47 элементов / 15 PNG → Release CLI 432/432. EXUI и GDL побайтово совпали с контрольными результатами. Новый GUI-цикл также завершён: Verify 0/0 → Save and Build / Keep → Close → reopen, независимая проверка 426/426. Итоговый локальный GDL: `output/releases/0.2.1/reexport/home-021-gui.gdl`; исходные ZIP и их SHA сохранены.

Оборудование ещё не проверено. Цвет отдельных подписей не следует за состоянием кнопки автоматически. Касания под Label/Value, удержания и feedback нужно проверить на панели; команды, переходы и синхронизацию громкости задаёт программа Extron. Пример пакета не заменяет редактируемый Figma-документ. Облачная сохранность Figma после перезапуска Desktop проверяется отдельно.
