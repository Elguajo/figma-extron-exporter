# Figma → Extron Exporter 0.4.2 preview

Исправлена ложная ошибка «координаты и размеры должны быть целыми пикселями» на деталях иконок внутри составного состояния кнопки. При поиске фона плагин больше не применяет проверку нативной геометрии к каждому вложенному прямоугольнику. Подписи с дробной геометрией также могут сохраняться в PNG.

Размеры и положение исходных деталей не округляются и не меняются. Границы кнопки и состояния по-прежнему должны быть целочисленными. CLI 0.4.0, EXUI/5, plugin ID и назначения сохраняются.

[Скачать плагин](../../../../output/releases/0.4.2/figma-extron-plugin-0.4.2.zip) · [Инструкция](../../../../src/figma-plugin/BUTTON_STATES.md).

Для development-плагина из src/figma-plugin достаточно закрыть и заново запустить плагин после сборки. Заголовок должен показывать **0.4.2**. При установке из ZIP распаковать новый архив и импортировать manifest.json с прежним plugin ID. Затем повторить проверку исходного экрана.
