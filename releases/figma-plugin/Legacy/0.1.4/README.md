## Подготовка собственного макета

1. Назвать внешний Frame `Home` (либо `scr_Home` / `screen_Home`). Размер — 1280×800 или 320×480.
2. Непосредственные элементы назвать `btn_Music` / `button_Music`, `lvl_Volume` / `level_Volume`, `txt_VolumeValue` / `text_VolumeValue`. У кнопок два Frame Off/On, при необходимости третий Pressed. В каждом состоянии один Text на всю площадь и необязательный Frame Icon (`ico_Music` / `icon_Music`).
3. В плагине выбрать Frame и профиль, нажать «Распознать по именам», проверить отчёт, затем «Сохранить распознанные назначения».
4. Нажать «Проверить экран», затем «Скачать .exui».

Распознавание не изменяет слои и оформление. Новым элементам назначаются ключи и ID, существующие сохраняются. После переименования приоритет имеют сохранённые назначения. Копии уже назначенных элементов требуют явного переназначения через ручную форму. Ошибки и несовместимое оформление блокируют сохранение.

Off и On — вложенные состояния одного button_Mute, а не два внешних элемента. Pressed необязателен: у двухсостояниевой кнопки остаются два состояния и выключен отдельный press feedback. При наличии такой кнопки пакет имеет контракт exui/3; **нужен обновлённый CLI из текущего проекта**. Все прежние пакеты v1/v2 читаются по прежним правилам. Собственные скруглённые дорожки/бегунки, группы и произвольное оформление по-прежнему не поддержаны.

## Установка

Распаковать архив в постоянную папку и импортировать `manifest.json` через Figma Desktop → Plugins → Development → Import plugin from manifest. Для существующей установки обновить файлы и перезапустить плагин. В заголовке должна быть 0.1.4. Plugin ID сохранён, существующие назначения пересоздавать не нужно.

В архив включён `AUTHORING_STANDARD.md`. Для конвертации пакетов Off/On пересобрать локальное решение из исходников либо использовать уже обновлённую сборку CLI в этой рабочей папке. Build GDL выполняется отдельно в GUI Designer.
