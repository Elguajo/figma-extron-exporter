# Figma → Extron Exporter 0.3.3 preview

Выбранные фреймы экспортируются как один проект без секции или внешнего Frame. Остальные фреймы не получают назначений и не входят в пакет. Существующие режимы секции и одного экрана сохранены. Совместимый CLI — **0.3.0**.

- [Полный локальный комплект 0.3.3 с CLI 0.3.0](../../../../output/releases/0.3.3/figma-extron-complete-0.3.3-local.zip).
- [Инструкция](../../../../src/figma-plugin/README.md).

Распаковать архив в постоянную папку, обновить путь development-плагина к `manifest.json` (в полном комплекте — `figma-plugin/manifest.json`) и перезапустить. Заголовок — **0.3.3**, plugin ID прежний.

1. Выделить вместе `screen_Main` и `screen_AudioControl`.
2. Проверить «Что экспортировать → Выбранные фреймы — один проект» и профиль панели.
3. «Распознать по именам» → «Сохранить распознанные назначения».
4. Выбрать кнопку Audio Control → раскрыть назначение → выбрать страницу в «Открыть страницу или popup» → сохранить.
5. «Проверить макет» → «Скачать .exui».

Плагин помнит выбранный набор при настройке отдельных кнопок/страниц. После перезапуска или смены страницы набор нужно выделить заново. Новое выделение нескольких фреймов заменяет его. Имя проекта берётся из файла Figma; стартовой становится первая страница в порядке выделения. Сохранённые назначения приоритетны, конфликтующие ID не перенумеровываются автоматически.

Режим «Экраны текущей страницы» собирает экраны выбранного размера по `screen_`, `scr_`, `Home` и существующим назначениям, исключая остальные макеты. Другие страницы документа не сканируются. Переходы исполняет программа управления Extron по карте ID. Figma Desktop, GUI Designer Verify/Build и физическая панель требуют отдельного прогона для этой версии.

Проверено: TypeScript/сборка, 139 тестов, архивный UI в Chromium и настоящий CLI → GDL для обеих панелей (**59/59 + 59/59**).
