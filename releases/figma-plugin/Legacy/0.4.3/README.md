# Figma → Extron Exporter 0.4.3 preview

Скругление внешнего Frame экрана теперь игнорируется при экспорте в Extron. В Figma экран может иметь Corner radius 10 или разные радиусы углов для удобства просмотра; в GDL страница всегда остаётся прямоугольной на всю область панели. Плагин не меняет скругление или Clip content исходного Frame.

Изменение относится только к Frame страниц экрана — отдельно и внутри проекта. Оформление кнопок и нативных фигур сохраняется; проверки обводки/эффектов/геометрии экрана и прежние правила popup не ослабляются. Исправление дробных деталей иконок из 0.4.2 также включено.

[Скачать плагин](../../../../output/releases/0.4.3/figma-extron-plugin-0.4.3.zip). CLI остаётся **0.4.0**, контракт **EXUI/5**, plugin ID и назначения не меняются.

Если development-плагин импортирован из src/figma-plugin/manifest.json, закрыть и запустить его заново: заголовок должен показывать **0.4.3**. При установке из ZIP распаковать новый архив и импортировать manifest.json с сохранением plugin ID. Выбрать Frame экрана и повторить «Проверить макет».
