# Figma → Extron Exporter 0.1.3

[Архив плагина](figma-extron-plugin-0.1.3.zip) · [Инструкция для своего макета](../../../../src/figma-plugin/README.md#собственный-макет-и-громкость).

Для выбранного Frame без назначения добавлена кнопка **«Подготовить выбранный экран»**. Она проверяет размеры панели и сохраняет назначение страницы, сохраняя слои и их оформление. Существующие ID не заменяются. Ошибка экспорта неподготовленного макета теперь объясняет дальнейшие действия.

Это подготовка внешнего Frame, а не автоматическое распознавание всего макета. Элементы нужно назначать явно, а структуру и оформление приводить к поддерживаемому формату. Кастомные бегунки и дорожки громкости пока не поддерживаются.

Для установки распаковать архив в постоянную папку и импортировать `manifest.json` через Figma Desktop → Plugins → Development → Import plugin from manifest. Для обновления существующей установки заменить файлы и закрыть/снова запустить плагин; в заголовке должна быть версия 0.1.3. Plugin ID сохранён.

SHA-256: `9915CE67FF83FAA7D00D183828C54EBE7601F6F07C4217AA85F8C07F93E082B2`; 47 890 байт.

Проверено: типы, сборка, 40 автоматических тестов и Chromium UI. Новый сценарий проходит от собственного неподготовленного Frame через подготовку и назначение Text до пакета с редактируемым Label. Figma API в тестах моделируется; экспорт конкретного макета пользователя в настоящей Figma и его открытие в GUI Designer в этой проверке не выполнялись.
