# Figma → Extron Exporter 0.1.5

[ZIP плагина](figma-extron-plugin-0.1.5.zip) · [Таблица префиксов](../../../../src/figma-plugin/PREFIXES.md) · [Полный стандарт](../../../../src/figma-plugin/AUTHORING_STANDARD.md).

Архив: 69 572 байт, SHA-256 `0784981AC150FB8BF92849E068BA94949837CADE2206A9FE36FECE0E6EB182BA`.

В архиве есть PREFIXES.md с короткими/полными префиксами и объяснениями. В самом плагине — раскрываемый «Справочник префиксов и состояний».

- `btn_` / `button_` — кнопка; VolumeUp, VolumeDown и Mute — стандартные имена функций громкости.
- `lvl_` / `level_` — регулятор; `txt_` / `text_` — подпись.
- `logo_` и `img_` / `image_` — отдельное статичное изображение на экране, нативный PBImage без состояний/controlId. Содержимое Frame растрируется в PNG 1×.
- `ico_` / `icon_` или Icon — иконка внутри состояния кнопки.
- Регистр всего имени не важен: btn_volumeup и button_VolumeUp равнозначны. Существующие ключи/ID сохраняются; case-only дубликаты блокируют назначение.

Схемы кнопок: **Normal/Pressed** для «+»/«−», **Off/On** для обратной связи, **Off/On/Pressed** для обратной связи с отдельным видом удержания. Жёлтый Pressed рисует дизайнер; плагин не меняет цвет автоматически. Шаг, повтор при удержании и AV-команды реализует программа управления.

Распаковать в постоянную папку, импортировать manifest.json через Figma Desktop → Plugins → Development. При обновлении заменить файлы и перезапустить плагин, в заголовке должна быть 0.1.5. Plugin ID сохранён. Выбрать экран и профиль → «Распознать по именам» → проверить отчёт → «Сохранить распознанные назначения» → проверить → скачать .exui.

Для логотипов и Normal/Pressed используется exui/4: нужен обновлённый CLI и текущий samples/donors.json. В этой рабочей папке CLI уже собран. Результат конвертации — новый GDL, Build выполняется отдельно в GUI Designer. Старые пакеты читаются текущим CLI по прежним правилам; старый CLI может отклонить новую версию пакета или новое поле реестра.

Проверено: 64 теста плагина, typecheck/build, 137 проверок .NET, Chromium UI. Native writer/NRBF для обеих панелей: прежние демо 65/65, Off/On 63/63, логотип и жёлтый Normal/Pressed 73/73. Figma API/PNG-рендер в тестах моделируются. Ручная Figma, GUI Designer/Build и оборудование этой версии не проверены.
