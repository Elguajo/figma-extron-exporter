# Figma → Extron Exporter 0.3.1 preview

Новая версия отличает доработанный плагин от прежнего 0.3.0 preview. Включает имена с точками (`button_side.hall`), двухсостояниевые Normal / Pressed и Passive / Active, необязательный Pressed у feedback-кнопок и exui/5 без отдельного предела 16 PNG. Сохраняются ограничения размера пакета и изображений. Совместимый CLI — **0.3.0**.

- [Архив плагина 0.3.1](../../../../output/releases/0.3.1/figma-extron-plugin-0.3.1.zip).
- [Полный локальный комплект: плагин 0.3.1 + CLI 0.3.0 + доноры](../../../../output/releases/0.3.1/figma-extron-complete-0.3.1-local.zip).
- [Инструкция плагина](../../../../src/figma-plugin/README.md).
- [Проверка поведения предыдущей сборки](../../../../verification/results/2026-10-21-flexible-authoring.md).

Распаковать в постоянную папку, обновить путь существующего development-плагина к figma-plugin/manifest.json и перезапустить плагин. Заголовок должен показывать **0.3.1**. Plugin ID сохранён; переустанавливать назначения элементов не нужно. Для пакетов более 16 PNG использовать CLI 0.3.0 из нового комплекта.

Это изменение версии и упаковки; логика экспорта не менялась. Новый GUI Designer Build и физическая панель требуют отдельной проверки.
