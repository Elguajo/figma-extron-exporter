# Figma → Extron Exporter 0.3.5 preview

Ключи и свободные ID заполняются при экспорте. Выберите экран или несколько экранов, профиль панели и нажмите **«Скачать .exui»**. «Проверить макет» выполняет ту же подготовку. Заполнять ручную форму и отдельно сохранять распознавание больше не требуется.

- [Плагин 0.3.5](../../../../output/releases/0.3.5/figma-extron-plugin-0.3.5.zip).
- [Полный комплект с CLI 0.3.0](../../../../output/releases/0.3.5/figma-extron-complete-0.3.5-local.zip).
- [Протокол проверки](../../../../verification/results/2026-10-21-auto-assignments.md).

Распакуйте архив в постоянную папку и импортируйте `manifest.json` через Figma → Plugins → Development → Import plugin from manifest…; в полном комплекте он находится в `figma-plugin/`. Сохраните прежний plugin ID. Перезапустите плагин: в заголовке должно быть **0.3.5**.

Новые элементы, копии и конфликтующие назначения получают уникальные ключи и свободные ID. Исправляются в том числе одинаковые `page.home` / `100` после отдельной подготовки экранов. Копии кнопок получают назначения для существующих состояний и PNG. Одинаковые имена обычных слоёв разрешены; одинаковые имена страниц различаются в пакете, исходные слои Figma не переименовываются. Повторное скачивание использует сохранённые значения.

Диапазон Slider/Level по умолчанию — **0–100**. Собственный диапазон, направление, поведение и переходы сохраняются; для их настройки остаётся ручная форма. При исправлении уже конфликтовавших ID используйте актуальную карту ID для программы управления. Неоднозначная ссылка на прежний повторяющийся ключ сохраняет цель, оставшуюся с этим ключом; при необходимости выберите другую страницу в форме.

Нужны поддержанные префиксы и структура макета. Произвольные рисунки и неверные состояния не исправляются автоматически. Ошибки структуры останавливают подготовку до записи; ошибка записи восстанавливает прежние назначения. Уже успешно сохранённые назначения остаются в Figma при последующем отказе PNG-рендера и используются при повторной попытке.

EXUI и схемы metadata совместимы с прежними версиями; CLI 0.3.0 подходит. Figma Desktop, GUI Designer Verify/Build и оборудование требуют отдельного ручного прогона.
