# Плагин 0.6.4 preview — связь popup и память страницы

Комплект: плагин **0.6.4 + CLI 0.6.3**, EXUI/5. Обновлять CLI 0.6.3 для этих действий не требуется. Архивы прошлых выпусков не изменяются.

## Связать Hall и Terrace с местом

1. Создайте пустой Frame `popupref_AudioControls` внутри `screen_AudioControl`.
2. Выберите его → «Назначение выбранного элемента → Место popup · Frame» → «Сохранить назначение». Ключи и ID можно оставить пустыми.
3. Выделите `popup_HallSources` и `popup_TerraceSources` вместе или целиком их существующую группу.
4. В блоке «Размещение popup» выберите `screen_AudioControl → popupref_AudioControls` → «Связать с местом popup».

Группа создаётся автоматически или используется существующая. Положение и содержимое popup сохраняются. Popup и место должны иметь одинаковые размеры и профиль. Новая группа создаётся из соседних popup непосредственно в проекте без Auto Layout; для существующей группы нужно выбрать всех участников. Модальные popup не участвуют. Пустое место без связи можно сохранить, но до связывания экспорт недоступен.

## Сохранение настроек

Тип и свойства слоя, включая стартовую страницу и оформление popup, сохраняются кнопкой «Сохранить назначение» в файле Figma. Для новых контейнеров пустые ключ/ID/имя проекта заполняются автоматически. Смена стартовой страницы атомарно переводит прежнюю в обычную. После выбора другого слоя и перезапуска назначения восстанавливаются.

Профиль панели, режим экспорта и выбранный состав проекта запоминаются отдельно на каждой странице Figma. Удалённые Frame не восстанавливаются, настройки другой страницы не подменяют текущие. Это сохранение текущего состояния, а не история всех действий.
