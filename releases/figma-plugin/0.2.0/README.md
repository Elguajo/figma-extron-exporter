## Обновление

1. Распаковать архив в постоянную папку. При необходимости импортировать manifest.json через Figma Desktop > Plugins > Development > Import plugin from manifest.
2. Перезапустить плагин: заголовок должен показывать 0.2.0. Стабильный plugin ID сохранён, не менять его вручную.
3. Новые возможности требуют текущих CLI и samples/donors.json. В этой рабочей папке CLI уже собран. Контракт новых пакетов - exui/5, старые exui/1-4 читаются по прежним правилам. Донорские GDL не менялись.
4. Выбрать Home либо project_Name, распознать имена, проверить таблицу, сохранить назначения, проверить экран, скачать .exui.

Новые назначения/свойства используют metadata/2: плагин 0.1.5 их не понимает. Старые назначения не переписываются при распознавании. Полного отката подготовленного нового документа к старому плагину нет; резервную копию макета вести штатными средствами Figma.

Программа Extron отдельно задаёт команды, feedback, начальное значение Slider, обновление Value, переходы, доступность/видимость. GDL не исполняет указания id-map сам. Изображения дорожки/бегунка и сложные эффекты Slider не реализованы. Видео и динамические изображения для 1025M/300M отклоняются явно.

Проверено: 81 тест плагина, typecheck/build, 149 проверок .NET, Chromium UI, 60 независимых проверок JSON Schema. Нативная конвертация обеих панелей: расширенные элементы 101/101, вертикальный вариант 101/101, проект с popup 200/200; прежние сценарии также проходят. Figma API/PNG в тестах моделируются. Исходный автоматический прогон не проверял Figma/GUI/оборудование; последующие ручные прогоны описаны ниже.
