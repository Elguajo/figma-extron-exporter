# Плагин 0.8.3 — сопровождающий выпуск

Парный выпуск: **плагин 0.8.3 + CLI 0.8.3**, контракт **EXUI/5**; CLI 0.8.1 и 0.8.2 тоже подходят. Заголовок плагина после обновления должен показывать **0.8.3**. Распакуйте `figma-extron-plugin-0.8.3.zip` и импортируйте manifest.json через Plugins → Development → Import plugin from manifest; для обновления замените файлы и перезапустите плагин.

Функции плагина не менялись по сравнению с [0.8.2](../0.8.2/README.md): «Текст кнопок для GCP» с режимом «Автоматически из Figma», ручные Center / Bottom Center и отмена через «Сохранить расположение Figma». Plugin ID, сохранённые назначения и plugin data остаются прежними; возврат к 0.8.2 возможен заменой файлов.

Выпуски плагина 0.1.1–0.4.5 перенесены в [Legacy](../Legacy/); их архивы и описания не менялись.

Чтобы обновить уже настроенный проект GCP, где программист добавлял страницы в GUI Designer, переносите оформление выбранных кнопок в рабочий GDL, а не импортируйте GDL из Figma целиком: [инструкция](../../../docs/updating-configured-projects.md#выборочное-обновление-рабочего-gdl).
