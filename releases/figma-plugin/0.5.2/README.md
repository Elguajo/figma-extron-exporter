# Figma → Extron Exporter 0.5.2 preview

Комплект включает последние изменения основной рабочей папки на 22.10.2026:

- Координаты и размеры нативных элементов, кнопок и состояний округляются при экспорте: 218.21 → 218, 218.7 → 219, 218.5 → 219. PNG состояний получает размер экспортируемой кнопки. Исходный макет Figma не меняется. Отдельные изображения и статический текст сохраняют точную дробную геометрию в прозрачном PNG-контейнере; для Pen/Line Tool остаются требования к краям Stroke.
- Ошибка имени показывает полное имя, позицию недопустимого символа и допустимый пример: `line_Devider 4` → `line_Devider-4`. Правила имён сохранены.
- «Показать слой» рассчитывает центр по координатам холста с учётом вложенности и поворота; поддерживает линии с нулевой шириной/высотой. Приближение ограничено 200%. Отчёт и область повторного распознавания сохраняются.
- Включены последнее оформление кнопок с явным выбором пропуска/обновления, подсказки Off / On, Normal / Pressed, Normal / Active / Pressed и прежние синонимы состояний.
- В архивы добавлена обновлённая трёхстраничная PDF-шпаргалка 0.5.2 с примерами применения префиксов.

[Плагин 0.5.2](../../../output/releases/0.5.2/figma-extron-plugin-0.5.2.zip) · [CLI Windows 0.5.2](../../../output/releases/0.5.2/figma-extron-cli-0.5.2-windows.zip) · [Инструкция CLI](../../cli/0.5.2/README.md).

Распакуйте новый ZIP и импортируйте его `manifest.json` в Figma через Plugins → Development → Import plugin from manifest. Закройте прежний плагин и откройте новый; заголовок должен показывать **0.5.2**. Plugin ID, EXUI/5 и сохранённые назначения совместимы; прежние архивы сохранены. CLI пересобран с номером 0.5.2, логика конвертации сохранена.

[Протокол сборки и проверок](../../../docs/verification/results/2026-10-22-release-0.5.2.md). Figma API в автоматических проверках моделируется; поведение камеры в пользовательском документе, GUI Designer Build и физическая панель требуют ручной проверки.
