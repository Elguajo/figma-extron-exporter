# Плагин 0.8.1 — текст Button для Text Feedback

Парный выпуск: **плагин 0.8.1 + CLI 0.8.1**, контракт **EXUI/5**. Заголовок плагина после обновления должен показывать **0.8.1**. Распакуйте `figma-extron-plugin-0.8.1.zip` и импортируйте manifest.json через Plugins → Development → Import plugin from manifest; для обновления замените файлы и перезапустите плагин.

Выпуск включает Extron Kit / AV-сценарии, профили совместимости и улучшения стабильности из 0.8.0. Исправлены четыре теста обновления компоновки; подробные результаты актуальной сборки — в [протоколе 0.8.1](../../../verification/results/2026-10-25-release-0.8.1.md). Прежние проверки живого макета ниже относятся к промежуточной сборке функции; новый прогон Desktop/GCP и физической панели ими не заявляется.

В блоке «Текст кнопок для GCP» выберите положение подписи и примените к выделенным кнопкам, экрану или popup. При повторном экспорте текст записывается в состояния Button, отдельный Label для этой подписи не создаётся, из PNG он исключается. Исходные слои, фон, иконки и ID сохраняются. В GDL текст выравнивается по центру либо снизу по центру; точное произвольное расположение из Figma заменяется выбранным выравниванием.

Кнопки без текста пропускаются. Несколько непустых подписей, маски и неподдержанный нативный шрифт требуют исправления до применения. Проверка всей области выполняется до записи настроек. Вернуться к прежнему экспорту можно через «Сохранить расположение Figma».

Уже созданный проект GCP эта настройка не меняет. Нужны повторный экспорт EXUI, конвертация в новый GDL, Save and Build в GUI Designer и обновление интерфейса GCP с сохранением назначений.

Сборка проверена: typecheck, 640 unit-тестов, Chromium с настоящим UI/бандлом, реальный генератор Extron и независимое чтение GDL для двух панелей и двух выравниваний. В интеграционной проверке Figma API и PNG моделируются; замена текста выполнена через CLI. Работа на физической панели не проверена.

Также проверен экспорт живого документа Trilliant: 134 Button, 0 отдельных подписей кнопок, генерация GDL 2801/2801, GUI Designer Verify — 0 ошибок и предупреждений, Save And Build выполнен. Тексты и ID всех кнопок сохранились после сборки. [Подробный отчёт и границы проверки GCP](../../../verification/results/2026-10-25-button-native-text.md).
