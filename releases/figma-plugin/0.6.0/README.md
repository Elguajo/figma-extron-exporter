# Плагин 0.6.0 preview

Ключи больше не нужно переписывать вручную, русские буквы в именах слоёв запрещены, а порядок страниц в GDL задают имена фреймов.

- **Ключи по именам слоёв.** При каждой «Проверить макет» и «Скачать .exui» ключи экранов и элементов строятся из текущих имён: `page.home` у `screen_AudioControl` становится `page.audiocontrol`, `home.ch01` — `audiocontrol.ch01`, `homeexportready.volume-2` — `audiocontrol.volume`. Переходы на переименованный экран и ключи иконок кнопок обновляются. ID объектов, управления и состояний не меняются. Отчёт показывает, сколько ключей обновлено.
- **Ручной ключ.** Ключ, введённый в «Назначение выбранного элемента», сохраняется при переименовании слоя. Очистите поле, чтобы вернуть автоматический. Копия слоя ручной ключ не наследует. Ключи, введённые вручную в прежних версиях, один раз перезапишутся по именам: до 0.6.0 отметки «вручную» не было.
- **Только латиница в именах.** Русские буквы в именах экранов, popup, групп popup и элементов — ошибка с латинским вариантом: `Главная` → `screen_Glavnaya`, `button_Канал1` → `button_Kanal1`. Так же работает «Подготовить выбранный экран». Видимый текст, текстовые слои внутри кнопок, имена секций и страниц Figma могут оставаться русскими.
- **Порядок страниц по именам.** Страницы и popup идут в GDL по именам фреймов, числа сравниваются по значению: `screen_01-MainDashboard`, `screen_02-AudioControl`, `screen_10-Video`. Номер не входит в ключ (`page.maindashboard`), поэтому перенумерация не меняет ключи, переходы и ID. Стартовая страница не меняется: сохранённая или первая выделенная. Имя страницы в GDL — полное имя фрейма с номером.
- **Подписи Inter** (Label и подпись кнопки) больше не обрезаются в GUI Designer: рамка расширяется под метрики GDI, не выходя за кнопку или холст. Arial не меняется.
- Демо плагина использует латинские имена слоёв; его ключи помечены как ручные.

Комплект: плагин 0.6.0 + CLI 0.6.0. CLI пересобран для общей версии, конвертация не изменилась с 0.5.2. EXUI/5 и plugin ID сохранены; назначения и ID в существующих файлах Figma остаются.

## Установка

Распаковать [архив плагина](../../../output/releases/0.6.0/figma-extron-plugin-0.6.0.zip) и [CLI](../../../output/releases/0.6.0/figma-extron-cli-0.6.0-windows.zip) в постоянные папки. В Figma: Plugins → Development → Import plugin from manifest… → manifest.json. В заголовке должна быть версия 0.6.0. Выбрать экраны и нажать «Проверить макет»: ключи обновятся, русские имена будут показаны как ошибки.

Проверки и их границы: [протокол](../../../verification/results/2026-10-22-release-0.6.0.md).
