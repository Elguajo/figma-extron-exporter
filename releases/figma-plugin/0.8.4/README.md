# Плагин 0.8.4 — английская документация и лицензия

Выпуск только плагина: **плагин 0.8.4 + CLI 0.8.3**, контракт **EXUI/5**. CLI не менялся — используйте [CLI 0.8.3](../../cli/0.8.3/README.md). Заголовок плагина после обновления должен показывать **0.8.4**. Распакуйте `figma-extron-plugin-0.8.4.zip` и импортируйте manifest.json через Plugins → Development → Import plugin from manifest; для обновления замените файлы и перезапустите плагин.

Функции плагина не менялись по сравнению с [0.8.3](../0.8.3/README.md). Plugin ID, сохранённые назначения и plugin data остаются прежними; интерфейс плагина остаётся на русском.

- Руководства в архиве (README, PREFIXES, BUTTON_STATES, NATIVE_TEXT, EXTRON_KIT, справочник префиксов) содержат сначала русский текст, ниже английский. AUTHORING_STANDARD остаётся на русском.
- В архив добавлен файл `LICENSE` с условиями использования.
