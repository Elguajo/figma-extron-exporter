# Figma → Extron Exporter 0.2.2

[Скачать плагин](figma-extron-plugin-0.2.2.zip). Использовать с [CLI 0.2.1](../../cli/0.2.1/README.md); новый CLI не требуется.

| Новая кнопка | Состояния |
|---|---|
| `button_Name` / `btn_Name` | **Off + On**, строго два |
| `feedbackbutton_Name` / `fbtn_Name` | **Normal + Active + Pressed**, строго три |

Active/On задаёт программа Extron; Pressed — вид при удержании, отдельный press feedback включён только у второго типа. Неполный/лишний набор блокирует экспорт, состояния не создаются и не удаляются автоматически.

Распаковать архив в постоянную папку, импортировать его `manifest.json` в Figma Desktop через Plugins → Development → Import plugin from manifest. Стабильный plugin ID не менять. После перезапуска заголовок — **0.2.2**. Для новых элементов использовать префиксы выше либо поле **«Тип кнопки»** в ручной форме, затем проверить экран и скачать EXUI.

Существующие сохранённые кнопки продолжают работать по прежним назначениям; ID и состояния не мигрируют автоматически. В форме они показаны как «Сохранённая · прежние состояния». Для перехода выбрать новый тип и согласовать имена/роли/ID состояний. Одно переименование слоя тип не меняет. Новые кнопки используют metadata/3 и требуют плагин 0.2.2; 0.2.1 их отвергает. Старые exui-node/1, /2 и пакеты EXUI остаются совместимыми.

В архиве — стандарт 2.1, таблица префиксов и notices. [Протокол проверок](../../../verification/results/2026-10-21-button-types.md). Новые GDL проверяются на данные; отдельный настоящий Desktop/GUI-цикл этих новых типов и работа на панели не заявляются по автоматическим тестам. Прежний Home 0.2.1 и его GUI-цикл остаются отдельным доказательством.
