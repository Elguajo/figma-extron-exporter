# Плагин 0.8.2 — автоматическое положение текста Button

Парный выпуск: **плагин 0.8.2 + CLI 0.8.2**, контракт **EXUI/5**; CLI 0.8.1 тоже подходит. Заголовок плагина после обновления должен показывать **0.8.2**. Распакуйте `figma-extron-plugin-0.8.2.zip` и импортируйте manifest.json через Plugins → Development → Import plugin from manifest; для обновления замените файлы и перезапустите плагин.

Выделите кнопки, экран или popup, откройте «Текст кнопок для GCP» и примените «Автоматически из Figma». Положение Text-рамки внутри состояния кнопки определяет Middle-Center / Bottom-Center при каждом экспорте. Настройки абзаца намеренно игнорируются, по горизонтали всегда Center. Рамка на всю кнопку означает Middle-Center; короткая рамка в нижней части — Bottom-Center. Сохранённые ручные настройки меняются только после применения; для новых кнопок примените режим к области повторно.

Верх, равное расстояние между якорями и выход рамки за кнопку дают ошибку с указанием слоя. Остаются ручные режимы и отмена через «Сохранить расположение Figma». Подпись хранится в состояниях Button, без отдельного Label и текста в PNG. Слои Figma, фон, иконки и ID не меняются.

Это правила экспортёра: GUI Designer поддерживает девять вариантов Text Alignment. Два варианта для Button ограничены текущей реализацией экспорта, а не GCP. Для предотвращения наложения важна принадлежность текста Button.

Для сохранённого режима `auto` нужен плагин 0.8.2 или новее. Старый плагин отклонит этот режим. Чтобы вернуться к 0.8.1, сначала примените ручное положение либо отмените настройку новым плагином. Пакеты EXUI совместимы с CLI 0.8.1 и 0.8.2.

Чтобы обновить уже настроенный проект GCP, где программист добавлял страницы в GUI Designer, переносите оформление выбранных кнопок в рабочий GDL, а не импортируйте GDL из Figma целиком: [инструкция](../../../docs/updating-configured-projects.md#выборочное-обновление-рабочего-gdl).

Проверено: 647 unit-тестов, typecheck/build, Chromium с настоящим UI/bundle (ширины 320/420), восемь сценариев реального генератора и независимого reader Extron (две панели × ручной центр/низ и автоматический центр/низ). Figma API и PNG в этих тестах моделируются. Работа на физической панели не проверена; ранее собранные GDL и текущий импорт GCP не менялись.
