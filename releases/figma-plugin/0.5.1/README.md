# Figma → Extron Exporter 0.5.1 preview

Оформление кнопок стало одним понятным сценарием: выбрать экран → увидеть обычный и активный образцы и число кнопок → «Применить оформление» → «Проверить и скачать .exui».

Если уже есть готовые кнопки, плагин требует явно выбрать «Пропустить готовые кнопки» или «Применить новый стиль и к готовым». Вариант заранее не выбран. Видно, сколько кнопок будет подготовлено, обновлено или пропущено. При выборе Button Styles вместо экрана показана подсказка выбрать экран. Ручной выбор образцов и фона перенесён в дополнительные настройки.

Иконки, подписи, геометрия, видимость, ручной Pressed и сохранённые ID остаются на месте. Подготовка и выбранное обновление входят в одну операцию с общей проверкой и откатом. Поддержанные схемы и синонимы имён сохраняются. [Инструкция](../../../src/figma-plugin/BUTTON_STATES.md).

[Плагин 0.5.1](../../../output/releases/0.5.1/figma-extron-plugin-0.5.1.zip) · [CLI Windows 0.5.1](../../../output/releases/0.5.1/figma-extron-cli-0.5.1-windows.zip) · [Инструкция CLI](../../cli/0.5.1/README.md).

CLI пересобран с номером 0.5.1; логика конвертации, EXUI/5, plugin ID и сохранённые назначения совместимы с 0.5.0. Старые архивы не заменены. Для development-плагина закрыть и снова открыть его; заголовок должен показывать **0.5.1**. При установке из ZIP импортировать manifest.json из распакованного архива.

Проверки предыдущей сборки интерфейса: 261 тест и Chromium с моделируемым host прошли. Настоящий Figma Desktop и оборудование для этого интерфейса ещё не проверены. [Протокол интерфейса](../../../verification/results/2026-10-22-button-workflow-ux.md).
