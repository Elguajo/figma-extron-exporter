# Figma → Extron Exporter 0.3.2 preview

Секции Figma теперь экспортируются как проекты из нескольких Frame страниц и popup. Секция может называться произвольно, без `project_`; сами экраны сохраняют точный размер выбранной панели. Существующие Frame проекты, ключи, ID и формат EXUI совместимы. Совместимый CLI — **0.3.0**.

В интерфейсе убрана кнопка демо, библиотека компонентов и ручные настройки свёрнуты. Распознавание показывает компактный список вместо широкой таблицы. Проверка и скачивание всегда доступны в нижней панели; выбор страницы перехода выполняется по имени, без ввода ключа вручную. Старые недоступные цели сохраняются до явного исправления.

Распаковать в постоянную папку и обновить путь development-плагина к `manifest.json` (в полном комплекте — `figma-plugin/manifest.json`). Перезапустить плагин; заголовок должен показывать **0.3.2**. Plugin ID сохранён, назначения переустанавливать не нужно.

Выделить секцию → выбрать профиль → «Распознать по именам» → просмотреть список → «Сохранить распознанные назначения» → «Проверить макет» → «Скачать .exui». Для перехода выделить кнопку и раскрыть «Назначение выбранного элемента → Открыть страницу или popup».

Внутри секции поддержаны непосредственно Frame страниц, popup и групп popup; вложенные секции и произвольные подписи вне страниц отклоняются. Переходы выполняет программа управления Extron по карте ID. GUI Designer Build и физическая панель для этой версии требуют отдельной проверки.

Проверено: TypeScript и сборка; 131/131 автоматический тест; архивный UI в Chromium, ширины 420/320 и тёмные токены; архивный main bundle с моделируемым Figma API → настоящий CLI → GDL обеих панелей, **202/202 + 202/202**.
