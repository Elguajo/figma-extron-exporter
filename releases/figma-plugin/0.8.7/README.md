# Figma → Extron Exporter 0.8.7 preview

Используйте с CLI и LayoutUpdater **0.8.7**. Новый экспорт EXUI/5 содержит проверяемую карту исходных слоёв; plugin ID и назначения metadata прежние.

Экспортируйте EXUI → сопоставьте кнопки с рабочим GDL в LayoutUpdater → сохраните «Карта ID → Figma…» → откройте её в плагине через «Назначения Extron → Импортировать карту ID из LayoutUpdater» → проверьте строки → «Применить ко всем».

Импорт изменяет только управляющие ID связанных кнопок. Проверяются исходная страница, слои, сохранённые ключи/ID и конфликты; обмен номерами в одной группе допустим. Изменившиеся назначения требуют нового предпросмотра. На странице Figma не обязательно выделять отдельную кнопку. Оформление и внутренние objectId остаются прежними.

После установки перезапустите плагин: заголовок должен показывать **0.8.7**. Для обратного импорта нужен свежий экспорт этой версии; старый EXUI не содержит ссылок на исходные слои.
