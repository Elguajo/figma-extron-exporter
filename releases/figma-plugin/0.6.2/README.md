# Плагин 0.6.2 preview — оформление popup

Совместимый CLI — **0.6.1+**, контракт EXUI/5. Архивы прежних выпусков не меняются.

У Frame `popup_…`, `modalpopup_…`, `popupref_…` фон по умолчанию полностью прозрачный, обводка игнорируется. Радиусы углов и Opacity самого Frame игнорируются всегда. Красные рамки и фон можно оставлять в Figma как ориентиры; плагин их не удаляет. Оформление вложенных контролов сохраняет прежние правила.

Для намеренного переноса выберите Frame → «Назначение выбранного элемента» → «Экспортировать фон Frame» и/или «Экспортировать обводку Frame» → «Сохранить назначение». Фон — SOLID либо без заливки; обводка — SOLID Inside, сплошная и одинаковой толщины со всех сторон. Это распространяется на уже назначенные popup: прежний фон сохранится только при явном включении его экспорта.

[Плагин ZIP](../../../output/releases/0.6.2/figma-extron-plugin-0.6.2.zip) · [CLI ZIP](../../../output/releases/0.6.2/figma-extron-cli-0.6.1-windows.zip).

Распакуйте плагин в постоянную папку и импортируйте `manifest.json` через Figma → Plugins → Development → Import plugin from manifest. Для исходников используйте `src/figma-plugin/manifest.json`; после сборки перезапустите плагин. Его заголовок должен показывать **0.6.2**. Plugin ID сохранён, повторно назначать ID элементов не нужно.

[Проверки и ограничения](../../../docs/verification/results/2026-10-22-popup-appearance.md). На реальном макете нужен отдельный цикл GUI Designer Verify → Save and Build → повторное открытие.
