# Плагин 0.6.1 preview

Дата и время с форматами GUI Designer: готовый компонент в Extron Kit и пример вместо формата в тексте слоя.

- **`datetime_Clock` в Extron Kit.** «Библиотека компонентов → Создать Extron Kit» добавляет раздел «03 / Дата и время»: набор вариантов с 28 форматами — 24 пресета Pattern из GUI Designer 1.28 и 4 дополнительных (`MMMM d, h:mm tt`, `dd.MM.yyyy HH:mm`, `dd.MM.yyyy`, `dddd, MMMM d`). Перетащите компонент на экран и выберите **Format** в свойствах экземпляра. Текст показывает пример, как в GUI Designer: `September 28, 12:00 AM`. Шрифт, цвет и размер меняются в экземпляре и сохраняются при смене Format. Часы есть и в примере экрана.
- **Формат по макету.** При каждой проверке формат берётся из макета: свойство Format, Text-слой `Pattern: dddd, d MMMM` внутри компонента, текст-пример из каталога (`9/28/2026 12:00 AM` → `M/d/yyyy h:mm tt`) или, как раньше, текст с самим форматом `HH:mm`.
- **Форма.** В поле «Формат даты/времени» — список готовых форматов и живой пример. Введённый формат сохраняется и важнее макета; пустое поле возвращает формат из макета. Копия слоя введённый формат не наследует.
- **Понятная ошибка.** Текст, который не является ни форматом, ни примером из каталога (например, `12:45`), останавливает проверку с подсказкой, вместо неверного Pattern в GDL.
- **Совместимость.** Прежние макеты не меняются: сохранённый формат используется, пока текст слоя — сам формат.

Комплект: плагин 0.6.1 + CLI 0.6.0 (без изменений). EXUI/5 и plugin ID сохранены; назначения и ID в существующих файлах Figma остаются.

## Установка

Распаковать [архив плагина](../../../output/releases/0.6.1/figma-extron-plugin-0.6.1.zip) в постоянную папку. В Figma: Plugins → Development → Import plugin from manifest… → manifest.json. В заголовке должна быть версия 0.6.1. CLI — прежний [0.6.0](../../cli/0.6.0/README.md). Затем «Библиотека компонентов → Создать Extron Kit» — раздел «03 / Дата и время».

Правила формата: [стандарт макета](../../../src/figma-plugin/AUTHORING_STANDARD.md#дата-и-время) · [Extron Kit](../../../src/figma-plugin/EXTRON_KIT.md#дата-и-время). Проверки и их границы: [протокол](../../../docs/verification/results/2026-10-22-release-0.6.1.md).
