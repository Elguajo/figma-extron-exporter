# Плагин 0.5.5 preview

Лишние видимые состояния кнопок автоматически скрываются при «Проверить макет», «Скачать .exui» и сохранении распознанных назначений. Ошибка «должно быть видно ровно одно состояние» больше не требует ручного переключения слоёв кнопки.

- Если видны несколько состояний, обычное Off / Normal / Passive имеет приоритет среди видимых; иначе остаётся первое видимое.
- Единственное видимое состояние, включая On / Active / Pressed, сохраняется. Если скрыты все, показывается обычное.
- Простое распознавание показывает план, не меняя слои. При других ошибках проверки изменения не применяются; при сбое записи назначения и видимость откатываются.
- Все состояния входят в экспорт. Имена, оформление, ключи и ID сохраняются. Правила Multistate Level не меняются.

Совместим с CLI 0.5.2; EXUI/5 и plugin ID сохранены. Включены исправления 0.5.4 для дробных линий.

## Установка

Распаковать [архив плагина](../../../output/releases/0.5.5/figma-extron-plugin-0.5.5.zip) в постоянную папку. В Figma: Plugins → Development → Import plugin from manifest… → выбрать manifest.json. Для manifest из src/figma-plugin достаточно перезапустить плагин после сборки. В заголовке должна быть версия 0.5.5. Выбрать исходный экран и нажать «Проверить макет».

Проверки и их границы: [протокол](../../../docs/verification/results/2026-10-22-button-preview-visibility.md).
