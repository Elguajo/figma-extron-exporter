# Плагин 0.5.4 preview

Исправлен оставшийся строгий запрет дробной толщины и геометрии у линий Pen/Line Tool. Общее округление из 0.5.2 ранее не распространялось на этот отдельный путь экспорта.

Толщина Stroke и x/y/ширина/высота окрашенной области округляются до ближайшего целого пикселя. Например, вертикальная линия длиной 48 px с осью X=311, Y=18 и Stroke 1.5 экспортируется как rect [310,18,2,48], thickness=2. Привязка оси к полупикселю не требуется. Линия остаётся редактируемым PBLine без PNG; исходный Stroke, геометрия и назначения сохраняются.

После округления толщина должна быть 1..1280 px, длина — строго больше толщины, а линия — помещаться в контейнере. Проверки прямого отрезка, Center/Uniform, плоских окончаний, цвета и трансформаций сохранены. Совместим с CLI 0.5.2; EXUI/5 и plugin ID сохранены. Включены предыдущие исправления 0.5.3.

## Установка

Распаковать [архив плагина](../../../output/releases/0.5.4/figma-extron-plugin-0.5.4.zip) в постоянную папку. В Figma: Plugins → Development → Import plugin from manifest… → выбрать manifest.json. Для manifest из src/figma-plugin достаточно закрыть и заново открыть плагин после сборки. В заголовке должна быть версия 0.5.4. Выбрать исходный экран и нажать «Повторить распознавание».

Проверки и границы проверки: [протокол](../../../verification/results/2026-10-22-fractional-line-rounding.md).
