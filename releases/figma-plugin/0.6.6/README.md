# Figma → Extron Exporter 0.6.6 (preview)

Совместимый CLI: **0.6.3**, контракт **EXUI/5**.

## Растровый фон и Clip content

Включите **Clip content у Frame экрана или popup**, внутри которого лежит `image_Background`. Фон может выступать за его границы: плагин экспортирует видимую часть PNG с прежним масштабом и смещением. Например, Frame 1280×998 при Y=-99 внутри экрана 1280×800 даёт картинку 1280×800 на X=0, Y=0. Поддержаны `image_`, `img_`, `logo_`.

Размеры, координаты, содержимое, назначения и ID исходного макета сохраняются. Обрезка производится во временном Frame; он удаляется и после успешного рендера, и при ошибке.

Clip content самой картинки обрезает её внутренние слои. Для выхода самого Frame картинки за экран включайте клиппинг у экрана. Скругления экрана игнорируются как раньше. Полностью невидимая графика, выход нативных элементов за холст и выход картинки при выключенном клиппинге родителя остаются ошибками.

## Установка

Распакуйте [архив плагина](figma-extron-plugin-0.6.6.zip). Figma Desktop → Plugins → Development → Import plugin from manifest → `manifest.json`. После перезапуска в заголовке должно быть **0.6.6**. Plugin ID сохранён; CLI обновлять не нужно.
