# Плагин 0.8.0 — AV-сценарии Extron Kit, стабильность и производительность

Парный комплект: **плагин 0.8.0 + CLI 0.8.0**, контракт **EXUI/5**. Plugin ID, metadata слоёв и сохранённые назначения не менялись: обновление не требует повторной подготовки макетов.

Дополнение от 25.10.2026: режим **«Текст кнопок для GCP»** включён в 0.8.0. Подписи экспортируются как текст состояний Button, без отдельного Label и без текста в PNG; Text Feedback назначается кнопке. Положение — по центру или снизу по центру. Настройка обратима, исходные слои и ID сохраняются. Чтобы применить её к готовому GDL/GCP, нужен повторный экспорт и обновление интерфейса. [Инструкция](../../../src/figma-plugin/NATIVE_TEXT.md#текст-кнопок-для-gcp-080) · [Проверки функции](../../../verification/results/2026-10-25-button-native-text.md). Промежуточная локальная сборка 0.8.1 включена в этот выпуск.

- **Extron Kit.** Apple-inspired Light для всех 30 семейств и 28 форматов часов, AV-сценарии `project_AVPatterns` (Welcome, Presentation, Audio Zones, Connection Help, System Status, `modalpopup_Shutdown`) для 1025M и 300M, 18 иконок Lucide, Volume +/− и навигация — Normal / Pressed. Новая библиотека создаётся рядом со старой; существующие экземпляры не заменяются. [Extron Kit](../../../src/figma-plugin/EXTRON_KIT.md).
- **Быстрее.** Выделение слоя, «Проверить макет» и «Скачать .exui» в 2–3 раза реже обходят дерево дизайна. Пакет `.exui` и сообщения панели совпадают с прежними байт в байт.
- **Стабильнее.** Повреждённые данные Extron в выделенном слое больше не «замораживают» панель: показывается предупреждение, назначение можно исправить вручную. Изменения выделения во время выгрузки обрабатываются после неё. Временные копии экспорта PNG, оставшиеся после аварийного закрытия Figma, удаляются при следующем запуске.
- **Диагностика.** «Скопировать диагностику» под статусом копирует версию, область, профиль и последнюю ошибку без содержимого макета — для обращения в поддержку.
- Нумерация обрабатывает только непосредственно выделенные кнопки.

Распакуйте `figma-extron-plugin-0.8.0.zip` в постоянную папку. В Figma Desktop: **Plugins → Development → Import plugin from manifest…** → `manifest.json`. Для обновления существующей установки замените файлы и перезапустите плагин. Заголовок должен показывать **0.8.0**.
