# Плагин 0.6.7 — прозрачность линий

Совместимый CLI: **0.6.4**. SOLID Stroke линий Pen/Vector и Line Tool поддерживает непрозрачность 0–100%. Учитывается и общая Opacity слоя; у прямоугольных линий — Fill и Opacity. Линия остаётся нативной, редактируемой PBLine, без PNG. Например, Stroke `#D2AE6D` с непрозрачностью 10% экспортируется как `#1AD2AE6D`.

Распакуйте `figma-extron-plugin-0.6.7.zip` в постоянную папку. В Figma Desktop: Plugins → Development → Import plugin from manifest… → `manifest.json`. Перезапустите плагин, проверьте версию **0.6.7**, повторите распознавание и экспорт. Для development-плагина из репозитория достаточно перезапуска после сборки.

Обновите CLI до 0.6.4: прежний CLI отклонит альфа-цвет линии. Контракт остаётся EXUI/5, прежние пакеты принимаются. ID плагина, назначения и исходные слои сохраняются. Остальные ограничения нативных элементов сохраняются.
