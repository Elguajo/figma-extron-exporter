# Плагин 0.6.3 preview — стартовая страница первой

Комплект: **плагин 0.6.3 + CLI 0.6.3**, контракт EXUI/5. Архивы прежних выпусков не меняются.

- Назначенная стартовая страница экспортируется первой независимо от имени и порядка выделения. Остальные страницы сохраняют числовую сортировку по именам; ключи, ID и цели переходов сохраняются.
- Оформление кнопок применяется к выбранному popup или группе popup, включая макеты без назначений Extron и без внешнего Frame проекта. Панель показывает область и число кнопок; при выборе одного popup соседние не меняются.
- CLI 0.6.3 переносит стартовую страницу в начало и для ранее сохранённых EXUI/5, сохраняя порядок остальных страниц.

[Скачать плагин](../../../output/releases/0.6.3/figma-extron-plugin-0.6.3.zip) · [Скачать CLI](../../../output/releases/0.6.3/figma-extron-cli-0.6.3-windows.zip).

Распакуйте плагин в постоянную папку и импортируйте `manifest.json` через Figma → Plugins → Development → Import plugin from manifest. В заголовке должно быть **0.6.3**. Plugin ID сохранён, назначения элементов остаются на месте.

У прежней стартовой страницы выберите «Показывается → Программой управления», затем у `screen_StartPage` — «Показывается → Стартовая страница». Имя само по себе не меняет назначение. В дереве GUI Designer служебная Offline Page остаётся выше страниц проекта. Действие кнопки Start задаётся программой управления Extron.

После конвертации проверьте GDL в GUI Designer: Verify → Save and Build → закрыть и открыть снова. [Проверки сборки](../../../verification/results/2026-10-22-release-0.6.3.md).
