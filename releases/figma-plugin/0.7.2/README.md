# Плагин 0.7.2 — выбор пары состояний

Выпускается вместе с **CLI 0.7.2**, контракт **EXUI/5**.

1. Выделите один или несколько фреймов экранов, popup либо сами кнопки. Оформление применяется только внутри текущего выделения; остальные фреймы, сохранённый состав экспорта и связанные popup автоматически не добавляются.
2. В «Оформление кнопок» выберите **Off / On** для включения/выбора либо **Normal / Pressed** для нажатия/удержания.
3. Выберите **«Пропустить готовые кнопки»** или **«Применить новый стиль и к готовым»** (Override), если готовые кнопки уже есть.
4. Нажмите **«Применить оформление»**.

Override также преобразует готовые двухсостояниевые `button_` / `btn_` в выбранную пару: Off / On ↔ Normal / Pressed. Обычный образец оформляет первое состояние, активный — второе. Обновляются и имена слоёв, и роли в сохранённых назначениях. ID кнопки, существующие слои, содержимое, геометрия и видимость сохраняются; в EXUI/GDL остаются слоты 0/1. При пропуске готовые кнопки не меняются. `feedbackbutton_` / `fbtn_` сохраняют собственную схему Normal / Active с необязательным Pressed.

Включены коррекция контраста текста/иконок и применение активного образца к существующему Pressed. Сложные оформления по-прежнему требуют ручной проверки. Подробности — [правила оформления](../../../src/figma-plugin/BUTTON_STATES.md).

Область оформления задаёт текущее выделение независимо от режима экспорта: один/несколько фреймов или контейнеров кнопок. Невыбранные экраны и автоматически связанные popup не меняются. Для отдельной кнопки выделяйте её контейнер `button_`, а не текст внутри.

Распакуйте `figma-extron-plugin-0.7.2.zip` в постоянную папку. В Figma Desktop: **Plugins → Development → Import plugin from manifest…** → `manifest.json`. Для обновления существующей установки замените файлы и перезапустите плагин. Заголовок должен показывать **0.7.2**. Plugin ID не меняется.
