# Figma → Extron Exporter 0.4.5 preview

Статические подписи txt_/text_ с Inter и другими доступными в Figma шрифтами автоматически экспортируются в PNG/PBImage. Достаточно оставить обычный Text, например txt_title.source.type: вручную оборачивать его во Frame img_Title больше не нужно. Сохраняются выравнивание, смешанные шрифты и дробная геометрия. В Figma текст остаётся редактируемым, в Extron такая подпись является изображением. Arial Regular/Bold с поддержанным оформлением остаётся нативным PBLabel; Value/DateTime сохраняют нативные требования и возможность обновления содержимого.

Inter поддержан и в подписях ранее созданных Frame-состояний кнопок. Дробные размеры и координаты logo_/img_ сохраняются внутри прозрачного PNG с целыми внешними границами, без масштабирования или округления исходного слоя.

Исправлены подтверждённые недочёты подготовки кнопок:

- прозрачный Frame не считается вторым фоном рядом с Background;
- вручную созданные Frame-состояния принимают сгруппированную графику;
- из единственного Pressed создаётся пара Normal/Pressed, без лишнего On;
- команды создания и обновления состояний используют экран, даже если выбран слой внутри него.

Включено исправление 0.4.4: линия Center с профилем Uniform и толщиной 2 экспортируется нативным PBLine. Скругление внешнего Frame экрана игнорируется при экспорте, исходный макет сохраняется.

[Скачать плагин](../../../output/releases/0.4.5/figma-extron-plugin-0.4.5.zip). Совместим с CLI **0.4.0**, EXUI/5. Plugin ID и сохранённые назначения не меняются.

Для development-плагина из src/figma-plugin/manifest.json закрыть и снова запустить плагин; заголовок должен показывать **0.4.5**. При установке из ZIP импортировать manifest.json распакованного архива. Затем выбрать экран и нажать «Проверить макет» → «Скачать .exui».
