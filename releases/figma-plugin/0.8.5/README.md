# Figma → Extron Exporter 0.8.5 preview

Используйте с CLI и утилитой обновления **0.8.5**. Контракт EXUI/5 и plugin ID сохранены.

- Выберите кнопку → «Назначение выбранного элемента» → «ID управления Extron» → «Сохранить ID». Можно взять номер кнопки, созданной вручную в GUI Designer, включая `1`.
- Ошибки других слоёв и отсутствие кнопки в текущей области экспорта не блокируют сохранение её ID. Занятые номера проверяются в проекте выбранной кнопки. Оформление проверяется отдельно перед экспортом.
- Для замены оформления существующей кнопки в рабочем GDL используйте `updater/Extron.LayoutUpdater.exe` из CLI ZIP и включите режим замены по ID управления. Одно сохранение ID в Figma не изменяет открытый GDL.

Распакуйте архив, обновите файлы установленного плагина либо импортируйте `manifest.json` через Plugins → Development. Перезапустите плагин: заголовок должен показывать **0.8.5**.
