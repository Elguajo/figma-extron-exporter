# Плагин 0.7.3 — нумерация кнопок

Парный комплект: **плагин 0.7.3 + CLI 0.7.3**, контракт **EXUI/5**.

Под «Оформление кнопок» появился отдельный раздел **«Нумерация кнопок»**:

1. Выделите группы, фреймы или сами кнопки в Figma.
2. Задайте основу имени (например, `Box`) и начальный номер.
3. Выберите **«Заново по расположению»** или **«Исправить только повторы»**.
4. Включите изменение имён слоёв и, при необходимости, текста кнопок. Обновление текста изначально выключено.
5. Проверьте список и нажмите **«Пронумеровать»**.

Счёт отдельный для каждого непосредственного родителя, включая вложенные контейнеры. Порядок — слева направо, сверху вниз; верхние края в пределах 2 px считаются одним рядом. Префиксы сохраняются: `button_Box1`, `btn_Box2`, `feedbackbutton_Box3`. Основа применяется ко всем кнопкам выделения; чтобы сохранить другие имена, выделите только нужные кнопки.

Исправление повторов сохраняет занятые номера, отдаёт приоритет оригиналу перед копией и выдаёт свободные номера копиям и кнопкам без номера выбранной основы. Невыбранные соседи резервируют свои номера и не меняются. Сохранённая область экспорта не расширяет выделение.

Обновление текста затрагивает подписи во всех состояниях, включая скрытые. Нужна одна подпись в каждом состоянии без смешанного оформления внутри Text и с доступным шрифтом. При неоднозначности плагин предлагает исправить структуру или выключить обновление текста. План проверяется до и после загрузки шрифтов; изменившийся макет требует нового предпросмотра. Имена, текст и ID состояний не смешиваются: ID Extron сохраняются. Автоматические ключи следуют новым именам при следующей проверке/выгрузке.

Распакуйте `figma-extron-plugin-0.7.3.zip` в постоянную папку. В Figma Desktop: **Plugins → Development → Import plugin from manifest…** → `manifest.json`. Для обновления существующей установки замените файлы и перезапустите плагин. Заголовок должен показывать **0.7.3**. Plugin ID не меняется.
