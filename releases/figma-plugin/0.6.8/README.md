# Плагин 0.6.8 — связанные popup в составе экспорта

Совместимый CLI: **0.6.4**, контракт **EXUI/5**.

Исправлена ложная ошибка «цель должна быть обычным popup/группой того же размера» после сохранения связи popupref с группой и повторного выбора только экранов. Сохранённые цели автоматически включаются в состав экспорта в режимах «Выбранные фреймы» и «Текущая страница». Несвязанные popup, незавершённые группы и цели другого проекта не добавляются.

Если цель действительно отсутствует, отчёт сообщает об этом и указывает на конкретный popupref. При несовпадении размеров выводятся размеры места и popup.

Распакуйте `figma-extron-plugin-0.6.8.zip` в постоянную папку. В Figma Desktop: Plugins → Development → Import plugin from manifest… → `manifest.json`. Перезапустите плагин и проверьте версию **0.6.8**. Для development-плагина из репозитория достаточно перезапуска после сборки. ID плагина остаётся прежним, поэтому существующие назначения доступны после обновления.

После сохранения связи выделите нужные `screen_…`, выберите «Выбранные фреймы», нажмите «Проверить макет», затем «Скачать .exui». Связанную группу отдельно выделять не требуется. «Текущая страница» включает все подходящие экраны, в том числе черновики, поэтому для частичного экспорта используйте «Выбранные фреймы».
