# Плагин 0.5.3 preview

Совместим с CLI 0.5.2; EXUI/5 и plugin ID сохранены.

- Поворот и отражение кнопки и её Group/Frame состояний сохраняются в PNG. Включены унаследованные трансформации и скрытые состояния. Исходные слои не меняются.
- Текст трансформированного состояния остаётся в PNG; кнопка сохраняет состояния, ключи и управляющий ID. Область нажатия в Extron — охватывающий прямоугольник; состояния должны совпадать с его границами.
- Label/Value/DateTime принимают основной Component с одним непосредственным Text, в дополнение к Text, экземплярам и текстовым Frame кита. DateTime и Value остаются нативными обновляемыми элементами; геометрия, шрифт и оформление проходят прежние проверки.
- Автоматическое разложение произвольных компонентов на нативные фигуры в этот выпуск не входит.

## Установка

Распаковать [архив плагина](../../../output/releases/0.5.3/figma-extron-plugin-0.5.3.zip) в постоянную папку. В Figma: Plugins → Development → Import plugin from manifest… → выбрать manifest.json. Если используется manifest из исходников, достаточно перезапустить плагин после сборки. В заголовке должна быть версия 0.5.3. Повторить проверку исходного экрана.

## Проверка

Проверка типов, автоматические тесты и сборка выполнены локально. Тесты проверяют матрицу, переданную в Figma API, распознавание/экспорт, сохранение ID, исходных слоёв и очистку временных копий. Это модель границы Figma API: визуальный рендер трансформированного оформления в настоящей Figma и работа на панели требуют отдельной проверки.
