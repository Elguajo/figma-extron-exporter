# Figma → Extron Exporter 0.6.5 (preview)

Совместимый CLI: **0.6.3**, контракт **EXUI/5**. Обновлять CLI для этих возможностей не требуется.

## Установка

Распакуйте `figma-extron-plugin-0.6.5.zip` в отдельную папку. Figma Desktop → Plugins → Development → Import plugin from manifest → `manifest.json`. Plugin ID сохранён: назначения существующего макета доступны и после обновления.

## Связи по именам

- Выберите `popupref_…`. В «Содержимое места popup» выберите обычный popup либо готовую группу и нажмите «Сохранить связь popup». Предлагаются цели текущего проекта с подходящими размерами/профилем. Ниже отображается сохранённая связь; кнопки «Показать…» находят её участников на холсте.
- «Без связи» → сохранить снимает связь, сохраняя исходные Frame. Несвязанные обычные popup или места popup могут блокировать экспорт до нового назначения. Создание организационной группы из отдельных popup по-прежнему доступно в «Размещение popup» при выделении источников.
- Выделите две или больше кнопок одной страницы либо popup. «Группа выбора кнопок» → «Создать группу из выделенных кнопок» → «Сохранить группу выбора». Ключ будет создан автоматически. Для присоединения других кнопок выберите готовую группу; «Без группы» убирает назначение у выделенных кнопок. ID, visibility/enabled и остальные назначения сохраняются. Группа выбора — указание для программы управления Extron, не автоматическая AV-логика в GDL.
- Выберите проект/экран: «Запуск проекта» → «При запуске открыть» → «Сохранить стартовую страницу». Прежняя стартовая страница в этом проекте переводится в program. При экспорте выбранного состава Frame остальные экраны страницы не меняются.
- У кнопки в «Открыть страницу или popup» выберите цель и нажмите «Показать цель в Figma», чтобы найти её на холсте. Это действие не сохраняет ещё не записанные поля формы.

Изменение списка само по себе не сохраняет назначения. Изменения записываются кнопками сохранения в pluginData файла Figma и восстанавливаются при повторном выборе или перезапуске. Схемы metadata и EXUI не меняются.
