# Figma → Extron Exporter 0.8.8 preview

Используйте с CLI и LayoutUpdater **0.8.8**. После установки перезапустите плагин: заголовок должен показывать **0.8.8**.

- `imagebutton_` / `ibtn_` сохраняют всю графику и подписи состояния в PNG. Нативный Text пустой; подписи меняются в Figma с повторным экспортом. ID и состояния сохраняются.
- Переходы между страницами и показ/скрытие popup настраиваются в GCP. Поля цели перехода и режима «По кнопке» удалены; новые EXUI не содержат `navigate`. Сохранённые старые назначения читаются без смены ID. Стартовая страница, popupref и группы popup сохранены.
- Включены исправления распознавания и восстановления назначений состояний. Формат EXUI/5, plugin ID и схемы metadata прежние.

Обратная карта ID: EXUI → сопоставление кнопок в LayoutUpdater → «Карта ID → Figma…» → импорт и предпросмотр в плагине → «Применить ко всем».

Импортируйте `manifest.json` из распакованного архива через Figma → Plugins → Development → Import plugin from manifest. [Проверки и границы выпуска](../../../docs/verification/results/2026-10-28-release-0.8.8.md).
