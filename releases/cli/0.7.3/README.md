# CLI 0.7.3 preview

CLI для плагина **0.7.3**, контракт **EXUI/5**. Парный выпуск: нумерацию имён и подписей выполняет плагин, алгоритм конвертации CLI не менялся. Существующие Object ID, Control ID и ID состояний сохраняются; автоматические ключи следуют новым именам при проверке/выгрузке из Figma.

В плагине под «Оформление кнопок» появился отдельный раздел «Нумерация кнопок»: счёт внутри каждого родителя, порядок по расположению либо исправление повторов, независимое обновление имён и текста. Включены выбор Off / On или Normal / Pressed, Override и прежние исправления GCP, прозрачных углов кнопок и сравнение экспортов. Прежние пакеты EXUI/5 поддерживаются.

Распакуйте `figma-extron-cli-0.7.3-windows.zip`. Комплект для плагина 0.7.3: заголовок плагина должен показывать **0.7.3**.

Для `convert-package` нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные закреплённые доноры. Доноры и DLL Extron в архив не входят. `validate-package`, `id-map` и `compare-packages` работают без Extron.
