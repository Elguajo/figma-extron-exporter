# CLI 0.7.2 preview

CLI для плагина **0.7.2**, контракт **EXUI/5**. Это парный выпуск: алгоритм конвертации прежний, выбор пары и Override выполняет плагин. Обычная пара Off / On экспортируется без press feedback; Normal / Pressed — с press feedback 1. Обе используют слоты 0/1 и сохраняют ID кнопки.

Сохранены исправления 0.7.0: пустой Text вместо null для изображений, фигур, линий и регуляторов (устранение пустых страниц GCP), прозрачные углы кнопок с PNG и сравнение экспортов. Прежние EXUI/5 можно конвертировать без повторного экспорта.

Для `convert-package` нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные закреплённые доноры. Доноры и DLL Extron в публичный архив не входят. `validate-package`, `id-map` и `compare-packages` работают без Extron.

Распакуйте `figma-extron-cli-0.7.2-windows.zip`. Комплект для плагина 0.7.2: заголовок плагина должен показывать **0.7.2**.
