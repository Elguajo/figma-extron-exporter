# CLI 0.8.0 preview

CLI для плагина **0.8.0**, контракт **EXUI/5**. Прежние пакеты EXUI/5 поддерживаются и дают тот же проект: для шести эталонных пакетов `.gdl` совпадает с CLI 0.7.3 байт в байт.

- **Профили совместимости.** Поддерживаемые версии GUI Designer описаны в `cli/compatibility/extron.json`; команды генерации принимают `--compatibility <файл>`. Неизвестные версии автоматически не поддерживаются; исходный профиль — 1.28.0.7.
- **`doctor`.** Проверяет установку без загрузки проекта: версии GUI Designer/GCP, контракт x86-адаптера, контрольные суммы основных DLL. Код выхода 0 — готово к конвертации.
- **Обновление компоновки.** `plan-layout-update <existing.gdl> <incoming.gdl>` формирует план; `update-layout <existing.gdl> <incoming.gdl> <selection.json> <new-output.gdl>` применяет выбор в новый файл. После обновления выполните Verify и Save and Build в GUI Designer и проверьте импорт в копии проекта GCP; сохранность назначений GCP автоматически не подтверждается.
- **Быстрее и стабильнее.** Генерация больших проектов ~15% быстрее. Сбой удаления временных файлов не превращает успешную конвертацию в ошибку; брошенные рабочие папки прерванных запусков старше двух суток удаляются автоматически. Повреждённый ответ хоста и таймаут сообщаются как `ERROR [код]`, без аварийного завершения .NET.
- **Переменные окружения.** `EXUI_HOST_TIMEOUT` — таймаут хоста в минутах (1–1440, по умолчанию 10); `EXUI_HOST_TRACE=1` — время этапов хоста в `HostOutput` отчёта. Без них поведение прежнее.

Распакуйте `figma-extron-cli-0.8.0-windows.zip`. Комплект для плагина 0.8.0: заголовок плагина должен показывать **0.8.0**. Перед первой конвертацией выполните `.\ExtronExporter.ps1 doctor`.

Для `convert-package` нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные закреплённые доноры. Доноры и DLL Extron в архив не входят. `validate-package`, `id-map` и `compare-packages` работают без Extron.
