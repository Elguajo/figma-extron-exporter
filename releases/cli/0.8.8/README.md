# CLI и LayoutUpdater 0.8.8 preview

Комплект для плагина **0.8.8**. Распакуйте весь архив. Утилита находится в `updater/Extron.LayoutUpdater.exe`; нужны .NET Desktop Runtime 10 x64 и, для конвертации EXUI, GUI Designer с закреплёнными донорами.

1. Экспортируйте новый EXUI из плагина 0.8.8. ID вручную задавать не требуется.
2. В LayoutUpdater выберите рабочий GDL и новый EXUI, нажмите «Сравнить».
3. В столбце «Новая кнопка Figma» выберите соответствующую новую кнопку для старой — ID могут различаться. Для группы выделите старые строки (Ctrl/Shift) и нажмите «Связать выделенные по порядку…», затем выберите столько же новых кнопок по порядку списка. Проверьте пары и превью.
4. Отметьте нужные строки и сохраните новый GDL. Внутренние ID, имена и поведение старых кнопок сохранятся. Число, ID и порядок состояний обязаны совпадать.
5. Нажмите «Карта ID → Figma…». На исходной странице Figma откройте в плагине «Импортировать карту ID из LayoutUpdater», выберите файл, проверьте предпросмотр и нажмите «Применить ко всем». Следующий экспорт будет содержать ID из GUI Designer.

Карту можно позже открыть через «Загрузить соответствия…»: связи восстанавливаются по исходным слоям, включая экспорт после переноса ID в Figma. Удалённые слои и карта другого макета отклоняются. Если входной файл менялся, выполните сравнение заново.

Старые EXUI/5 без исходных слоёв и обычные GDL доступны для конвертации/обновления; для обратной карты нужен новый EXUI 0.8.8. Старые CLI не поддерживают новый необязательный `figma.json` в EXUI/5. Схемы metadata Figma не меняются.

CLI: `plan-layout-update old.gdl new.gdl --bindings pairs.json`, где пары — массив `[{"controlId":1,"sourceControlId":8101}]`. В selection JSON передайте те же `bindings` и выбранные целевые `controlIds`. `update-layout` сохраняет GDL; `export-figma-id-map old.gdl new.gdl source.exui selection.json map.json` сохраняет обратную карту.

Результат проверьте через GUI Designer Verify / Save and Build и импорт в копию GCP. Доноры и DLL Extron в публичный CLI ZIP не включены.
