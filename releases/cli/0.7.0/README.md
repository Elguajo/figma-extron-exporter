# Figma → Extron CLI 0.7.0 preview

CLI для плагина 0.7.0, контракт **EXUI/5**. Принимает EXUI/5 прежних плагинов без повторного экспорта.

## Пустые страницы в GCP

Global Configurator Plus 3.34.1.4 оставлял пустым preview всей страницы или popup, если на ней была картинка, фигура, линия или регулятор. У таких элементов writer записывал `Text = null`, а GCP при отрисовке читает `Text.Length`. Теперь пишется пустой текст `""`, как у элементов, созданных в самом GUI Designer. Независимая проверка GDL отклоняет результат с `null` у этих видов элементов. Пользователь подтвердил в GCP, что после исправления все страницы и popup отображаются.

GDL, сконвертированные прежним CLI, достаточно сконвертировать заново из того же EXUI. Для уже настроенного GDL без исходного EXUI в репозитории есть отдельный скрипт починки `scripts/fix-null-text` (в архив не входит).

## Кнопки с прозрачными углами

EXUI плагина 0.7.0 передаёт для состояний кнопок с PNG прозрачную заливку `#00000000`. CLI записывает её в нативное состояние, и в GUI Designer под скруглениями виден фон страницы вместо белого прямоугольника.

## Требования

Для `convert-package` нужны .NET 10 Runtime x64, GUI Designer 1.28.0.7 и собственные закреплённые доноры; доноры и DLL Extron в архив не входят. `validate-package`, `id-map` и `compare-packages` работают без Extron.

Комплект для плагина 0.7.0: заголовок плагина должен показывать **0.7.0**.
