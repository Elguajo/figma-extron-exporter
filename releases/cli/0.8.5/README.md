# CLI и утилита обновления 0.8.5 preview

Комплект для плагина **0.8.5**, контракт **EXUI/5**. Распакуйте `figma-extron-cli-0.8.5-windows.zip` целиком.

Для замены оформления кнопки, созданной в GUI Designer:

1. В Figma выберите внешний Frame кнопки, укажите её номер из GUI Designer в «ID управления Extron» (например, `1`) и нажмите «Сохранить ID». «ID объекта» оставьте текущим.
2. Исправьте ошибки экспорта и скачайте EXUI.
3. Запустите `updater/Extron.LayoutUpdater.exe`. Выберите рабочий GDL из GUI Designer и новое EXUI либо GDL из Figma.
4. Включите «Заменять оформление кнопок GUI Designer по ID управления», нажмите «Сравнить» и отметьте нужную строку с ID `1`. Проверьте её имя и превью. Для переноса размера и положения включите отдельную настройку.
5. Сохраните результат в новый GDL, откройте его в GUI Designer и выполните Verify → Save and Build. Затем проверьте импорт в копии проекта GCP.

Исходная кнопка и её внутренние ID, контейнер, имя, описание, имена/ID состояний и поведение сохраняются. Переносится оформление; число, ID и порядок состояний должны совпадать. По умолчанию режим замены по ID выключен.

CLI: `plan-layout-update working.gdl figma.gdl --rebind-by-control-id`. В `selection.json` для этой операции укажите `rebindByControlId: true` и нужные `controlIds`; затем используйте обычную команду `update-layout`.

Для CLI нужен .NET 10 Runtime x64, для окна обновления — .NET Desktop Runtime 10 x64. Конвертация EXUI дополнительно требует GUI Designer 1.28.0.7 и закреплённые доноры. Доноры и DLL Extron в публичный ZIP не входят. Сохраняйте всю папку `updater`, а не только EXE.
