# Extron.LayoutUpdater 0.8.5

Распакованная утилита обновления оформления. `Extron.LayoutUpdater.exe` и все DLL, шрифт и папки `host` / `compatibility` должны оставаться вместе. Нужен .NET Desktop Runtime 10 x64.

Для сравнения двух GDL запустите EXE напрямую. Для конвертации нового EXUI из этого репозитория запустите `Start-LayoutUpdater.cmd`: он передаёт путь к существующему `samples/donors.json` в корне проекта. Доноры остаются в `samples`, их копии сюда не помещаются. Конвертация EXUI требует установленного GUI Designer.

Чтобы заменить оформление кнопки, созданной в GUI Designer, задайте новой кнопке Figma тот же ID управления, включите «Заменять оформление кнопок GUI Designer по ID управления», сравните файлы и отметьте нужную строку. Сохраните новый GDL, затем выполните Verify / Save and Build в GUI Designer.

`SHA256SUMS.txt` содержит контрольные суммы десяти файлов сборки. Исходные GDL не перезаписываются.
