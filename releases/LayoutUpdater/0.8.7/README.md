# Extron.LayoutUpdater 0.8.7

Запускайте `Extron.LayoutUpdater.exe` вместе с остальными файлами этой папки. Для EXUI в этом репозитории используйте `Start-LayoutUpdater.cmd`: он передаёт существующий `samples/donors.json`. Нужны .NET Desktop Runtime 10 x64 и GUI Designer для конвертации EXUI.

Выберите рабочий GDL и новый EXUI плагина 0.8.7 → «Сравнить» → выберите новые кнопки для старых в столбце «Новая кнопка Figma». Можно выделить группу старых строк и связать столько же новых по порядку списка. Проверьте превью и отметьте строки.

Сохраните новый GDL и «Карта ID → Figma…». В плагине на исходной странице откройте карту через «Назначения Extron → Импортировать карту ID из LayoutUpdater» и примените ко всем. ID записываются в исходные кнопки Figma; следующие экспорты уже содержат их. Карту можно повторно открыть через «Загрузить соответствия…».

Внутренние ID и поведение рабочего GDL сохраняются; число, ID и порядок состояний должны совпадать. После обновления выполните GUI Designer Verify / Save and Build и проверьте копию GCP. Архивы и EXE версии 0.8.5 сохранены отдельно.
