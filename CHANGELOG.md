# История изменений

## Не выпущено — заливка popup в CLI

- При конвертации страниц и popup очищаются унаследованные из донора BorderFillColor, обводка и общая прозрачность. Прозрачный popup больше не получает серую заливку шаблона поверх своего фона.
- Независимая проверка GDL контролирует оформление контейнера, включая внутреннюю заливку, а не только BackgroundFillColor. Схема принимает прозрачный `states[].fill`, который плагин использует для кнопок внутри прозрачных popup.

## 0.6.8 — связанные popup в составе экспорта (CLI 0.6.4)

- После связывания popupgroup с popupref можно снова выбрать только экраны: режимы «Выбранные фреймы» и «Текущая страница» включают сохранённую цель вместе с её popup. Группы другого проекта и несвязанные макеты не добавляются.
- Отсутствующая цель больше не выдаётся за несовпадение размеров. Отчёт указывает на конкретное место popup, а при действительном расхождении показывает оба размера.
- ID плагина, EXUI/5, сохранённые назначения и геометрия исходных слоёв сохраняются. [Установка](releases/figma-plugin/0.6.8/README.md).

## 0.6.7 — прозрачность нативных линий (CLI 0.6.4)

- Pen/Vector и Line Tool принимают SOLID Stroke с непрозрачностью 0–100%; общая Opacity слоя перемножается с непрозрачностью Stroke. Для линий из Frame/Rectangle аналогично учитываются Fill и Opacity.
- Линии остаются редактируемыми PBLine, без PNG. Цвет `#D2AE6D` при 10% записывается как `#1AD2AE6D`; назначения, ID и исходный макет сохраняются.
- EXUI/5 расширяет `line.fillColor` до `#RRGGBB` / `#AARRGGBB`. Для таких пакетов нужен CLI 0.6.4; старые EXUI/5 по-прежнему принимаются.

Подробности, установка и протоколы проверок каждой версии — в `releases/figma-plugin/<версия>/README.md` и `releases/cli/<версия>/README.md`. Архивы прежних выпусков не изменяются.

Совместимая версия CLI для каждого плагина указана в его заметках к выпуску и в поле `compatibleCliVersion` файла `src/figma-plugin/package.json`. Текущая пара: **плагин 0.6.8 + CLI 0.6.4**, контракт **EXUI/5**.

## Плагин 0.6.6

- Растровые `image_` / `img_` / `logo_`, выходящие за границы экрана или popup с включённым Clip content, экспортируются видимой частью PNG. Масштаб и положение рисунка сохраняются, исходные слои не меняются. Например, фон 1280×998 при Y=-99 на экране 1280×800 становится PNG 1280×800.
- Клиппинг включается у родительского экрана/popup. При выключенном клиппинге, полностью невидимой графике и выходе нативных контролов за холст проверка продолжает сообщать об ошибке.
- EXUI/5, plugin ID и совместимый CLI 0.6.3 сохранены. [Установка](releases/figma-plugin/0.6.6/README.md).

## Плагин 0.6.5

- Выбранный popupref показывает доступные popup/группы по именам и сохранённые связи. Цель можно заменить или снять через «Без связи» → «Сохранить связь popup»; связанные popup доступны через «Показать…». Исходные Frame не перемещаются и не удаляются, размеры и профиль проверяются. Поля ключей перенесены в дополнительные настройки.
- Для выделенных кнопок — «Группа выбора кнопок»: создать группу из выделения, присоединить к существующей или убрать назначение. Ключ создаётся автоматически; ID и другие свойства кнопок сохраняются. Группа является указанием в карте ID для программы управления Extron.
- В настройках проекта — список «При запуске открыть» и явное сохранение стартового экрана. Возле цели перехода кнопки — «Показать цель в Figma». Выбор списков сам ничего не записывает; сохранённые назначения восстанавливаются после перезапуска.
- Контракт EXUI/5, схемы metadata, plugin ID и совместимый CLI 0.6.3 сохранены. [Установка](releases/figma-plugin/0.6.5/README.md).

## Плагин 0.6.4

- Связь popup с местом по именам: пустой popupref сохраняется без ручных ключей/ID; при выборе popup или полной существующей группы появляется блок «Размещение popup». Группа создаётся автоматически или переиспользуется, положение Frame сохраняется. Размеры/профиль проверяются; при ошибке изменения откатываются.
- Типы и свойства контейнеров сохраняются после кнопки «Сохранить назначение»; новые контейнеры получают ключи и ID автоматически. При выборе новой стартовой страницы прежняя автоматически переводится в «Программой управления».
- Профиль панели, режим экспорта и выбранные Frame проекта запоминаются отдельно на текущей странице Figma и восстанавливаются после перезапуска. Назначения и связи остаются в слоях Figma; формат EXUI/5 и CLI 0.6.3 не изменены. [Установка](releases/figma-plugin/0.6.4/README.md).

## Плагин и CLI 0.6.3

- Стартовая страница всегда первая в GDL независимо от имени и порядка в пакете; остальные страницы сохраняют прежний порядок. Работает при новом экспорте из Figma и конвертации существующих EXUI/5; назначения, ключи и ID сохраняются.
- Оформление кнопок применяется к выбранному `popup_` и к вложенным popup выбранной группы `popupgroup_`, включая макеты без назначений Extron и внешнего Frame проекта. Панель показывает область и число кнопок; соседние popup при выборе одного popup не меняются.
- PDF-шпаргалка префиксов обновлена до плагина 0.6.2 + CLI 0.6.1: дата и время (`datetime_Clock`, свойство Format, текст-пример, `Pattern: …`), латиница в именах слоёв, ключи по именам, порядок страниц и прозрачный по умолчанию фон popup. [PDF](docs/prefix_map/figma-extron-prefix-cheatsheet.pdf)

- Контракт EXUI/5 и plugin ID сохранены. [Плагин: установка](releases/figma-plugin/0.6.3/README.md) · [CLI: установка](releases/cli/0.6.3/README.md).

## Плагин 0.6.2 / CLI 0.6.1

- Popup/popupref: фон по умолчанию полностью прозрачный, обводка не переносится; радиусы углов и Opacity Frame игнорируются. Красные рамки и заливки можно оставить в Figma как ориентиры. Содержимое и исходные Frame не меняются.
- В форме назначения — независимые флажки «Экспортировать фон Frame» и «Экспортировать обводку Frame». Настройки сохраняются в Figma. Для существующих popup фон теперь тоже прозрачен по умолчанию: сохранение прежнего фона включается явно.
- CLI 0.6.1 добавляет альфа-цвета только для фона popup и заливки/обводки фигур; EXUI/5 прежних плагинов совместимы. Старый CLI 0.6.0 прозрачные цвета отклоняет. [Правила](src/figma-plugin/AUTHORING_STANDARD.md#7-страницы-и-popup).

## Плагин 0.6.1

- Дата и время: в Extron Kit добавлен набор вариантов `datetime_Clock` — 24 формата Pattern из GUI Designer 1.28 и 4 дополнительных, включая `MMMM d, h:mm tt`. Формат выбирается свойством **Format** экземпляра; текст показывает пример, как в GUI Designer (`September 28, 12:00 AM`), а оформление текста сохраняется при смене формата. [Подробнее](src/figma-plugin/EXTRON_KIT.md#дата-и-время)
- Формат PBDateTime определяется по макету при каждой проверке: свойство Format, Text-слой `Pattern: …` внутри компонента, текст-пример из каталога или, как раньше, текст с самим форматом `HH:mm`. Формат, введённый в плагине, сохраняется и важнее макета; пустое поле возвращает формат из макета. В форме есть список форматов и живой пример. [Правила](src/figma-plugin/AUTHORING_STANDARD.md#дата-и-время)
- Прежние макеты не меняются: сохранённый формат используется, пока текст слоя — сам формат. Текст, который не является ни форматом, ни примером (например, `12:45`), теперь даёт понятную ошибку вместо неверного Pattern.
- Совместим с CLI 0.6.0; EXUI/5 и plugin ID сохранены. [Установка и проверки](releases/figma-plugin/0.6.1/README.md)

## Плагин и CLI 0.6.0

- Ключи следуют текущим именам слоёв: устаревшие `page.home`, `home.*` и суффиксы `-2` от прежних копий исправляются при каждой проверке и скачивании, переходы обновляются, ID не меняются. Ключ, введённый вручную, сохраняется; пустое поле возвращает автоматический. [Подробнее](src/figma-plugin/AUTHORING_STANDARD.md)
- Русские буквы в именах слоёв экранов, popup, групп и элементов запрещены; ошибка предлагает латинский вариант. Видимый текст может оставаться русским.
- Страницы и popup идут в GDL по именам фреймов, числа сравниваются по значению: `screen_01-MainDashboard`, `screen_02-AudioControl`, `screen_10-Video`. Номер не входит в ключ. Стартовая страница не меняется: сохранённая или первая выделенная.
- Нативные подписи Inter (Label и подпись кнопки) больше не обрезаются в GUI Designer: рамка расширяется под метрики GDI от точки выравнивания, не выходя за кнопку или холст. Arial не меняется. [Подробнее](src/figma-plugin/NATIVE_TEXT.md)
- CLI пересобран с номером 0.6.0 для общей версии комплекта; конвертация не изменилась с 0.5.2. EXUI/5 и plugin ID сохранены. [Установка и проверки](releases/figma-plugin/0.6.0/README.md) · [CLI](releases/cli/0.6.0/README.md)
