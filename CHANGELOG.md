# История изменений

Подробности, установка и протоколы проверок каждой версии — в `releases/figma-plugin/<версия>/README.md` и `releases/cli/<версия>/README.md`. Архивы прежних выпусков не изменяются.

Совместимая версия CLI для каждого плагина указана в его заметках к выпуску и в поле `compatibleCliVersion` файла `src/figma-plugin/package.json`. Текущая пара: **плагин 0.5.5 + CLI 0.5.2**, контракт **EXUI/5**.

## Не выпущено

- Нативные подписи Inter (Label и подпись кнопки) больше не обрезаются в GUI Designer: рамка расширяется под метрики GDI от точки выравнивания, не выходя за кнопку или холст. Arial не меняется. [Подробнее](src/figma-plugin/NATIVE_TEXT.md)

## Плагин 0.5.5

- При «Проверить макет», «Скачать .exui» и сохранении назначений лишние видимые состояния кнопки скрываются автоматически. Приоритет у Off / Normal / Passive; единственное выбранное состояние сохраняется. В экспорт входят все состояния. [Подробнее](releases/figma-plugin/0.5.5/README.md)

## Плагин 0.5.4

- Округление геометрии распространяется на Pen/Line Tool: Stroke 1.5 → 2 px, дробные координаты больше не блокируют распознавание. Линия остаётся нативным PBLine. [Подробнее](releases/figma-plugin/0.5.4/README.md)

## Плагин 0.5.3

- Поворот и отражение кнопок сохраняются в PNG состояний.
- Label / Value / DateTime принимают Component с одним Text; Value и DateTime остаются нативными. [Подробнее](releases/figma-plugin/0.5.3/README.md)

## Плагин и CLI 0.5.2

- Координаты и размеры нативных элементов округляются до целых пикселей при экспорте; исходный макет не меняется.
- Ошибка имени указывает позицию недопустимого символа и пример исправления.
- «Показать слой» центрирует холст по абсолютным координатам, включая линии нулевой высоты.
- Обновлена PDF-шпаргалка префиксов. [Подробнее](releases/figma-plugin/0.5.2/README.md) · [CLI](releases/cli/0.5.2/README.md)

## Плагин и CLI 0.5.1

- Единое «Применить оформление» кнопок по образцам Off / On с явным выбором: пропустить или обновить готовые кнопки. Кнопки и состояния могут быть Group или Frame. [Инструкция](src/figma-plugin/BUTTON_STATES.md)

## Плагин и CLI 0.5.0

- Inter и Inter Display (18 начертаний) экспортируются нативным редактируемым текстом; шрифт встроен в GDL и поставляется с CLI.
- Девять вариантов выравнивания для Label / Value / DateTime.
- CLI принимает только EXUI/5: пакеты EXUI/1–4 нужно экспортировать из Figma заново, ключи и ID сохраняются.

## Плагин 0.4.x

- 0.4.5: статические `txt_` с ненативными шрифтами автоматически уходят в PNG; дробная геометрия `logo_` / `img_` сохраняется.
- 0.4.4: устранён ложный отказ для линий Center с профилем Uniform.
- 0.4.3: скругление внешнего Frame экрана игнорируется при экспорте.
- 0.4.0: `button_` принимает Off / On, Passive / Active или Normal / Pressed; у `feedbackbutton_` Pressed необязателен. Общие правила назначений для формы и распознавания.

## Плагин 0.3.x

- 0.3.6: отчёт об ошибках распознавания с путём до слоя, инструкцией и кнопкой «Показать слой».
- 0.3.5: ключи и свободные ID назначаются автоматически при проверке и скачивании; копии и конфликты исправляются. Диапазон регуляторов по умолчанию 0–100.
- 0.3.4: прямые линии Pen Tool и Line Tool экспортируются в нативный PBLine (`line_` / `ln_`).
- 0.3.3: несколько выбранных экранов страницы экспортируются в один проект без секции.
- 0.3.2: секции Figma как проекты, переходы по имени страницы. Снят отдельный предел 16 PNG (нужен CLI 0.3.0).
- 0.3.0: «Создать Extron Kit» — библиотека из 30 компонентов.

## 0.2.x и ранее

- 0.2.1: первый комплект, прошедший GUI Designer Verify 0/0 → Save and Build → повторное открытие на Home 1025M. [Протокол](verification/results/2026-10-21-release-0.2.1.md)
- 0.1.x: распознавание имён, `logo_` / `img_`, кнопка Normal / Pressed, экспорт скрытых состояний. История — в [README плагина](src/figma-plugin/README.md).
