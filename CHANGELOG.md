# История изменений

## Локальное обновление 28.10.2026 — открытие EXUI без PowerShell

- В Windows-утилиту добавлен режим `--convert`: выбор EXUI или автоматическая конвертация переданного файла, новый GDL рядом с исходным, автоматическое открытие в GUI Designer и понятный отчёт об ошибке.
- Регистрация `.exui` для текущего пользователя позволяет запускать конвертацию двойным щелчком; существующий выбор другого приложения сохраняется. Занятые GDL и отчёты не перезаписываются; утилита выбирает следующее свободное имя.
- Используются существующие генератор, проверка EXUI/5, профиль панели, закреплённые доноры и совместимость GUI Designer. Добавлены лаунчеры для следующих комплектов и [инструкция](docs/exui-desktop-converter.md). Опубликованные архивы не менялись.

## Локальное исправление 28.10.2026 — button_ с нативным текстом по умолчанию

- Исправлено наложение иконки Mute на нативную подпись: соседняя иконка сдвигается к новой позиции текста только в экспортной копии с сохранением зазора. Прозрачные заполнители предотвращают схлопывание Auto Layout. Текст остаётся в самом Button; исходный макет и ID сохраняются.
- Обычные button_ / btn_, feedbackbutton_ / fbtn_ экспортируют подпись как редактируемый Text самого Button без применения отдельной команды. Удалён автоматический отдельный Label и скрытый переход к PNG-тексту; для сложной неподдержанной подписи выводится ошибка с предложением imagebutton_ / ibtn_.
- imagebutton_ / ibtn_ сохраняют состояние целиком в PNG независимо от сохранённого выравнивания. Нативный текст исключается только из временных PNG-копий. Кнопки без Text, в том числе с иконкой во вложенном Frame, поддержаны. ID, типы и состояния сохраняются.
- «Выравнивание текста кнопок» меняет выравнивание; сброс возвращает нативный текст по умолчанию. Старые настройки позиционирования совместимы. Обновлён development build 0.8.8; EXUI/5, CLI и опубликованные архивы не изменены.

### Стабильность и производительность

- **Плагин.** Клик по слою делает 1 полный обход дерева дизайна вместо 3, проверка проекта — 3 вместо 9, выгрузка — 5 вместо 11. Проверочные захваты не строят неиспользуемую подпись, после выгрузки панель обновляется по только что применённому плану, область экспорта определяется один раз за событие. Выгрузка проекта в синтетическом замере — 110 мс вместо 324 мс. Бандл и все сообщения панели совпадают с прежними байт в байт.
- **Плагин.** Повреждённые данные Extron в выделенном слое больше не «замораживают» панель: показывается предупреждение для ручного исправления. Непредвиденная ошибка в событиях холста выводится в панели. Изменения выделения и страницы во время выгрузки, создания Kit или нумерации обрабатываются один раз после операции, а не на недостроенном макете. Временные копии экспорта PNG помечаются; оставшиеся после аварийного закрытия Figma удаляются при следующем запуске плагина.
- **CLI.** Генерация ~15% быстрее на больших проектах (индекс шрифтов донора вместо перебора ресурсов для каждого состояния); `.gdl` совпадает с прежним байт в байт. Временные папки удаляются без ошибки после успешной записи результата. Повреждённый `result.json` хоста и гонка при таймауте дают `ERROR [host-failed]` вместо аварийного завершения .NET.
- **Плагин.** Кнопка «Скопировать диагностику» под статусом: версия, область, профиль, состояние операции и последняя ошибка без содержимого макета. Доступна и во время операции.
- **CLI.** Команды, распаковывающие пакеты или запускающие хост, удаляют собственные рабочие папки в `%TEMP%`, оставшиеся после прерванных запусков старше двух суток.
- **CLI.** `EXUI_HOST_TIMEOUT` — таймаут хоста в минутах (по умолчанию 10), `EXUI_HOST_TRACE=1` — время этапов хоста в `HostOutput` отчёта. Без переменных поведение прежнее.
- **Проверки.** Эталонные SHA-256 `.gdl` для шести пакетов (`--golden`, входит в `--integration`), бюджет обходов дерева в тестах плагина, fuzz-тест чтения `.exui`, CI на GitHub Actions для чистого checkout. Исправлено устаревшее ожидание порядка страниц в сценарии `selected-frames` архивной проверки. [Анализ](docs/performance-stability-review-2026-10-24.md).

## Плагин 0.6.1

- Дата и время: в Extron Kit добавлен набор вариантов `datetime_Clock` — 24 формата Pattern из GUI Designer 1.28 и 4 дополнительных, включая `MMMM d, h:mm tt`. Формат выбирается свойством **Format** экземпляра; текст показывает пример, как в GUI Designer (`September 28, 12:00 AM`), а оформление текста сохраняется при смене формата. [Подробнее](src/figma-plugin/EXTRON_KIT.md#дата-и-время)
- Формат PBDateTime определяется по макету при каждой проверке: свойство Format, Text-слой `Pattern: …` внутри компонента, текст-пример из каталога или, как раньше, текст с самим форматом `HH:mm`. Формат, введённый в плагине, сохраняется и важнее макета; пустое поле возвращает формат из макета. В форме есть список форматов и живой пример. [Правила](src/figma-plugin/AUTHORING_STANDARD.md#дата-и-время)
- Прежние макеты не меняются: сохранённый формат используется, пока текст слоя — сам формат. Текст, который не является ни форматом, ни примером (например, `12:45`), теперь даёт понятную ошибку вместо неверного Pattern.
