# Обновление оформления Pressed — 23.10.2026, плагин 0.7.0

## Изменение по запросу пользователя

Раньше обновление готовых кнопок исключало роль `pressed`, поэтому Normal менялся по образцу, а Pressed сохранял прежний фон. Теперь при явном выборе «Применить новый стиль и к готовым» существующие состояния сопоставляются образцам так:

| Состояние | Образец |
|---|---|
| Normal / Off / Passive | обычный |
| On / Active / Feedback | активный |
| Pressed | активный |

Это работает для пары Normal / Pressed и тройки Normal / Active / Pressed. Существующая команда обновления оформления также обновляет Pressed. Роли, имена, ID, состав слоёв, размеры и видимость сохраняются. Скругление переносится только по соответствующему флажку. Вариант пропуска готовых кнопок сохраняет Pressed полностью; автоматического создания Pressed не добавлено.

`presetRole()` в `button-preparation.ts` задаёт единое сопоставление для плана, предварительной проверки фона и применения. При ошибке после обновления Pressed его оформление восстанавливается общей операцией отката. Текущие изменения коррекции контраста в рабочей папке сохранены.

Подсказка в интерфейсе, сообщение старой команды обновления, инструкция по состояниям и заметки выпуска приведены в соответствие с новым правилом. Версия остаётся **0.7.0**, совместимый CLI **0.7.0**, EXUI/5 и metadata прежние.
