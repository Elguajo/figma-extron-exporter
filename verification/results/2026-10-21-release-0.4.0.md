# Проверка комплекта 0.4.0

21.10.2026. По запросу пользователя плагин обновлён с 0.3.7 до **0.4.0**, CLI остаётся **0.4.0**. Обновлены package.json, lock-файл, заголовок UI и текущие инструкции/ссылки. Формат **EXUI/5**, plugin ID, назначения, ключи и ID не менялись. Изменения выполнены в основной папке на `main`; прежние незакоммиченные изменения сохранены.

## Результат

Автоматическая проверка пройдена, комплект пригоден для дальнейшей локальной проверки как **preview**. Новый ручной цикл Figma Desktop → GUI Designer Verify/Save and Build и оборудование не проверялись. Эти уровни не обозначены как пройденные.

В каждом профиле проверялись реальные CLI, x86-host, Extron writer и независимый reader. Figma API/PNG моделируются fixtures; Chromium использует настоящий UI с моделируемым Figma bridge.
