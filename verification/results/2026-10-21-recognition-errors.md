# Понятные ошибки в UI плагина — 0.3.6

Дата: 21.10.2026. Работа в основной папке, ветка main; существующие изменения сохранены.

## Проблема и исправление

Прежний RecognitionPlan содержал только строки ошибок. UI выводил их после списка успешных назначений вместе с информационными предупреждениями. По трём сообщениям `Normal: состояние должно быть Frame` нельзя было определить родительскую кнопку или перейти к слою. Ошибки автоматической подготовки при проверке/экспорте попадали только в нижнюю строку статуса.

Добавлены структурированные ошибки с nodeId, фактическим типом слоя, путём, требованием и инструкцией. UI показывает их перед свёрнутыми назначениями. «Показать слой» выделяет точный узел и приближает холст; отчёт сохраняется. «Повторить распознавание» использует исходный экран или набор экранов. При повторной проверке отдельного экрана выбор возвращается к корню, чтобы последующее сохранение плана прошло обычную проверку области. Обычная смена выделения или страницы сбрасывает отчёт. При ошибках назначения не записываются.

Проверка оформления сохраняет идентичность узла при передаче ошибки вверх: в том числе конкретные Text, состояние, кнопка и иконка. Идентичность не восстанавливается по совпадению имён. Строки ошибок оставлены для существующих потребителей. Требования структуры и оформление остаются строгими; после исправления структуры могут обнаружиться следующие требования оформления.
