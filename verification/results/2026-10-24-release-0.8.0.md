# Выпуск: плагин 0.8.0 + CLI 0.8.0

24.10.2026. Решение: **SHIP WITH KNOWN RISKS**, preview. Локальные архивы собраны из рабочего дерева на основе коммита `e46905693500e43834aae3c4b7eb195580d4459a`. Изменения не закоммичены, поэтому в CLI `version.json` записано `sourceDirty: true`. Работа велась непосредственно в `main`, без веток и worktree. GitHub-публикация не выполнялась.

## Изменения

- Extron Kit: Apple-inspired Light, AV-сценарии, иконки Lucide, Normal / Pressed для Volume и навигации; нумерация только выделенных кнопок. Всё это вошло в рабочее дерево после 0.7.3 и описано в [CHANGELOG](../../CHANGELOG.md).
- Профили совместимости Extron (`compatibility/extron.json`, `--compatibility`) и команда `doctor`.
- Стабильность и производительность по [анализу](../../docs/performance-stability-review-2026-10-24.md):
  - P1 — проверочные захваты не строят подпись дизайна;
  - S1 — защита событий холста;
  - S2 — удаление временных папок без ошибки;
  - S3 — повреждённый ответ хоста и гонка при таймауте;
  - P4 — индекс шрифтов донора в хосте;
  - переменные `EXUI_HOST_TIMEOUT` и `EXUI_HOST_TRACE`;
  - эталонный тест `.gdl`, бюджет обходов дерева, fuzz-тест `.exui`, CI.
- `Package-Release.ps1` явно пишет `/` в путях ZIP и останавливается, если в имени записи есть `\`. Без этого запуск в Windows PowerShell 5.1 давал CLI-архив с 25 путями через `\`, тогда как архив 0.7.3 таких путей не содержит.
- EXUI/5, metadata schemas и plugin ID не менялись.

## Отклонено при проверке

Кэш поиска полей в хосте (P3) **не включён**. Значения проекта он не меняет, но `.gdl` выходил с другими байтами: .NET Framework упорядочивает сериализуемые поля типа по тому, как заполнялся кэш рефлексии, поэтому меньшее число вызовов `GetField` меняет порядок членов в BinaryFormatter. Расхождение нашёл эталонный тест — на всех шести пакетах. Причина записана в комментарии к `Find-TypeField`.

## Известные ограничения

- Браузерные тесты UI (`test:browser`, `test:numbering-browser`) не запускались: на машине нет браузера Playwright. `ui.ts` в этом выпуске не менялся, изменён только заголовок версии в `ui.html`.
- Сценарий `selected-frames` в `archive-smoke` не проходит. Тест ожидает стартовую страницу второй, а генератор намеренно ставит её первой. Так же он падает на архивах 0.7.3, так что это устаревшее ожидание теста, не регрессия. В релизные проверки 0.7.3 он не входил.
- Ручной прогон в Figma Desktop, GUI Designer Verify / Save and Build / повторное открытие, GCP и на панели для 0.8.0 не выполнялся. Генерация для шести эталонных пакетов совпадает с 0.7.3 байт в байт.
