# Выпуск плагина и CLI 0.6.0 — 22.10.2026

Плагин 0.6.0, CLI 0.6.0, EXUI/5. Работа выполнена в основной папке на main; прежние несохранённые изменения, включая исправление подписей Inter из параллельной работы, вошли в выпуск. `sourceDirty: true`.

## Изменения

- **Ключи по именам слоёв** (`src/key-sync.ts`). После восстановления копий распознавание строит ключи из текущих имён: страница — `page.`/`popup.` + имя фрейма, элемент — пространство имён страницы + суффикс префиксного имени, иконка — `icon.<ключ кнопки>.state<N>`. Сначала закрепляются ручные ключи и ключи, не выводимые из имени; затем ключи, уже совпадающие с именем; остальные получают свободный ключ. Ссылки `navigate`, `popup`, `group` следуют переименованным контейнерам. ID объектов, управления и состояний не меняются. Общие ключи иконок не автоматического вида (`icon.note-light`) сохраняются.
- **Ручной ключ.** Форма отправляет признак изменения поля; ключ отмечается pluginData `exui-key-manual` = id узла. Копия отметку не наследует; пустое поле снимает отметку; неудачное сохранение восстанавливает прежнюю.
- **Латиница** (`src/latin-name.ts`). Кириллица в именах экранов, popup, групп, элементов и корневого Frame проекта — ошибка распознавания с транслитерированным примером; «Подготовить выбранный экран» проверяет то же. Ошибка экрана не останавливает проверку его элементов. Секции и страницы Figma не ограничены.
- **Порядок страниц** (`project.ts`). Страницы, popup и группы попадают в пакет по именам с числовым сравнением; стартовая страница без сохранённого выбора — по-прежнему первая выделенная.
- **Демо** получает латинские имена и ручные ключи; режим `legacy` по-прежнему воспроизводит `examples/exui-v1`.
- **Скрипт выпуска** пишет `version.json` и README CLI в UTF-8 без BOM: под Windows PowerShell 5.1 BOM ломал чтение `version.json` в Node.
