# Выпуск плагина 0.6.1 — 22.10.2026

Плагин 0.6.1, CLI 0.6.0 без изменений, EXUI/5. Работа в основной папке на main от `4c47f4d`; изменения не закоммичены на момент сборки архива.

## Изменения

- **Каталог и превью** (`src/datetime-format.ts`). 28 форматов: 24 пресета Pattern, извлечённые из ресурсов `GUI Designer.exe` 1.28 (`strHHmm`, `strMdyyyyhmmtt`, …), и 4 дополнительных. Форматтер .NET custom date/time (InvariantCulture) рендерит пример для 2026-09-28 00:00 — такой пример показывает GUI Designer.
- **Определение формата** (`resolvePattern`): поле формы (отметка `exui-pattern-manual` = id узла) → Text-слой `Pattern: …` внутри компонента → свойство Format экземпляра → текст-пример из каталога → ранее сохранённый формат → текст-формат. Распознавание больше не записывает формат в назначение; он вычисляется при каждой проверке. Сохранённый прежними версиями формат проигрывает только явным сигналам макета (Format, `Pattern:`, пример).
- **Extron Kit** (`kit.ts`): набор вариантов `datetime_Clock` (`Format=<имя>`), слой `Content` одинаков во всех вариантах, чтобы Figma сохраняла оформление экземпляра при смене Format. Часы добавлены в пример экрана. `kit.json`: `datetime_Clock` — тип `datetime`.
- **Форма**: datalist форматов, живой пример или ошибка, источник формата из макета в placeholder.
- В браузерном тесте исправлено устаревшее с 0.6.0 ожидание порядка страниц (сортировка по именам).
