# Автоматические назначения при экспорте — плагин 0.3.5

21.10.2026. Работа выполнена в основной папке, в `main`; прежние изменения и релизы сохранены. Совместимый CLI — 0.3.0. Форматы EXUI и схемы metadata не менялись.

## Поведение

«Проверить макет» и «Скачать .exui» выполняют единый предварительный план распознавания, исправления конфликтов и проверки структуры. При успешной проверке план сохраняется существующим механизмом транзакции и отката. При ошибках структуры записей нет. Сохраняются диапазон, направление, поведение и переходы; отсутствующий диапазон регуляторов по-прежнему равен 0–100. Для существующих уникальных назначений сохраняются ключи и ID.

Копии элементов, состояний, иконок и экранов получают собственные назначения. Оригинал приоритетнее копии независимо от порядка слоёв. Исправляются совпадения ключей, ID объектов внутри контейнера, управляющих ID внутри проекта и путей разных PNG. Разрешены повторяющиеся имена обычных слоёв. Одинаковые имена страниц различаются только в экспортном пакете, исходные фреймы не переименовываются. Скопированный реестр используется как нижняя граница резервирования ID. Повторный экспорт и перезапуск плагина сохраняют результат.

Сценарий из чата «Найти причину одинаковых настроек» воспроизведён отдельным тестом: Main Dashboard и Audio Control с `page.home`, ID `100` объединяются в один пакет. Первое назначение сохраняется, второе получает свободные значения. Ручная подготовка нового экрана также больше не присваивает каждому фрейму фиксированные `page.home`/`100`.

Ссылки внутри скопированного проекта обновляются вместе с контейнерами. Неоднозначная ссылка на старый повторяющийся ключ сохраняет цель, оставшуюся с этим ключом; пользователь может выбрать другую цель в форме. После исправления исторических конфликтов программа управления должна использовать актуальную карту ID. При отказе PNG-рендера успешно сохранённые назначения остаются в макете и используются при повторной попытке.
