# Только существующие состояния кнопки / 0.3.0 preview

21.10.2026. По запросу пользователя: не требовать и не экспортировать отсутствующее третье состояние; принять Passive / Active для зон и Normal / Pressed для кнопок громкости.

## Результат

- Новые `button_` / `btn_`: ровно два состояния, normal + feedback либо normal + pressed.
- Новые `feedbackbutton_` / `fbtn_`: normal + feedback и необязательный pressed.
- Normal / Off / Passive — имена роли normal; On / Active / Feedback — feedback. Регистр и префиксы st_/state_ поддержаны. Авторские имена сохраняются в EXUI и GDL без служебного префикса состояния.
- Никакие состояния автоматически не добавляются и не удаляются. Скрытые существующие состояния экспортируются; отсутствующий Pressed не имеет ни состояния, ни PNG.
- Для двух состояний Normal / Pressed пакет/GDL содержит ID 0/1, press feedback = 1. Без Pressed press feedback = −1. При трёх состояниях press feedback = 2.
- В UI предпросмотр содержит только назначенные состояния. Если их ещё нет, список пуст и кнопка просмотра отключена. Обновлены подсказки и стандарт авторинга 2.2.
- Старые metadata/1 и /2, сохранённые ID, CLI и EXUI wire-формат не изменены. Установленные архивы 0.2.2 и прежний 0.3.0 не заменялись.

Поле «Группа выбора» уже сохраняется в behavior.selectionGroup и выводится в карте ID. Взаимное переключение Hall/Terrace и команды оборудования реализует программа управления Extron; эта правка не добавляет исполняемую AV-логику. Лимит 16 PNG на пакет сохранён.
