# Выпуск: плагин 0.6.8 + CLI 0.6.5

22.10.2026. Решение: SHIP WITH KNOWN RISKS, preview. Работа в основной папке на main.

## Исправление и ручная проверка

В рабочем EXUI фон popup и оформление места popupref были исключены корректно. Серый прямоугольник создавал унаследованный от донора `borderFillColorField = #FFBABDCE`: GUI Designer рисует его поверх прозрачного `backgroundFillColorField`, даже если ресурс обводки пуст. Writer теперь очищает внутреннюю заливку, цвет и ресурс обводки создаваемых контейнеров, сбрасывает общую прозрачность донора. Заданный фон EXUI сохраняется. Offline popup не меняется.

Независимый NRBF reader и verifier проверяют оформление контейнеров. Регрессия с намеренно восстановленной серой заливкой отклоняется. Схема принимает прозрачный `states[].fill`, используемый кнопками внутри popup.

После предложения проверить исправленный GDL через Verify → Save and Build → повторное открытие пользователь ответил «Да всё ок». Это подтверждение пользователя о результате в GUI Designer; точные числа отдельного Verify не записаны, работа физической панели не подтверждена.
