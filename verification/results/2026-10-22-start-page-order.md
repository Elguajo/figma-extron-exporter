# Стартовая страница первой в GUI Designer

Назначенная стартовая страница (`shownBy: start`) экспортируется первой, независимо от имени и порядка выделения. Остальные страницы сохраняют числовую сортировку по именам. CLI также переносит стартовую страницу в начало плана для ранее сохранённых EXUI/5, сохраняя относительный порядок остальных страниц, popup и элементов. Служебная Offline Page сохраняется.

Изменения: `src/figma-plugin/src/project.ts`, `src/screen/ScreenSpec.cs`. Формат пакета и правила назначения стартовой страницы не меняются. Имя `screen_StartPage` само по себе не заменяет сохранённое назначение.
