# Блок громкости 0.2.0: практическая проверка GUI Designer

20.10.2026. GUI Designer **1.28.0.7**, Windows, профиль **TLP Pro 1025M**. Работа в основной папке `main`; прежние изменения сохранены, commit/push не выполнялись.

## Граница прогона

Настоящий GUI Designer управлялся через Windows UI. Вход — **синтетический exui/5**, собранный локально из существующих fixtures, не экспорт из настоящего Figma. Пакет содержит Slider, Value, VolumeDown/VolumeUp с Normal/Pressed и тестовый logo_Company. До выбора пользователем профиля использован 1025M.

На момент проверки Figma Desktop и открытый Figma Design-файл не обнаружены в доступных окнах/вкладках. Реальный Figma → exui/5 и работа панели остаются неподтверждёнными. Логотип — fixture; визуальная точность пользовательского дизайна этим прогоном не проверяется.

## Найдено и исправлено

| Дефект | Причина | Исправление |
|---|---|---|
| Нативный Slider открывается с правильными Thumb Type/Color/Width/Height, но бегунок невидим | В установленной версии геометрия цветного Ellipse/Rectangle рассчитывается только при разрешимой ссылке SliderThumbImage. Новый PBSlider имел null; штатный UI сохраняет ссылку даже при переключении на Ellipse | Writer связывает цветной бегунок с уже имеющимся bitmap `Slider Thumb` закреплённого донора. Рисуется нативная фигура заданного цвета, bitmap служит зависимостью расчёта геометрии. Независимый verifier проверяет ссылку и размеры ресурса |
| Неквадратный бегунок мог менять пропорции при изменении размеров Slider | Служебный коэффициент записывался как width/height; нативный редактор использует height/width | Исправлено направление отношения; оно читается и проверяется независимо. Вертикальный fixture теперь содержит прямоугольный Thumb 28×20 |

Причина первого дефекта проверена сравнением со Slider, созданным штатным инструментом GUI Designer, и локальным исследованием установленной сборки. Первоначальная гипотеза о флагах создания Level не подтвердилась; флаги не менялись. Локальные диагностические материалы находятся в ignored `output/gui-smoke-20261020`, компоненты Extron не добавлены в репозиторий.

Удаление неиспользуемых ресурсов через **Remove** в этом цикле не проверялось.
