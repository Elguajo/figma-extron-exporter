# Дробная геометрия внутри оформления кнопок — 0.4.2

22.10.2026. По скриншоту пользователя плагин 0.4.1 отклонял Rectangle 13 внутри button_Scenario → Normal → Icon: X=145.14, W=114.86, H=91.04. Такие внутренние детали растрируются в PNG и не требуют целочисленной геометрии.

## Причина и исправление

background() вызывал строгий rect() для каждого Rectangle/Frame при сравнении кандидатов с областью кнопки. Поэтому любой прямоугольник с дробной геометрией внутри иконки прерывал поиск фона. Аналогичный вызов в artworkText() отклонял дробную подпись до выбора растрового fallback.

Сравнение кандидата с областью теперь использует исходные absoluteBoundingBox с прежним допуском 0.001, без округления и без применения правил нативной геометрии. Неподходящий внутренний прямоугольник пропускается; подпись с произвольной геометрией остаётся в PNG. Строгая проверка rect() у кнопки, состояния и нативных элементов сохранена.

## Доказательства

- До исправления два новых regression-теста воспроизвели geometry-ошибку: дробная деталь иконки и дробная подпись. Контрольный тест дробной внешней кнопки подтвердил сохранение отказа.
- После исправления `npm run verify`: **219 passed, 0 failed**, основной и UI TypeScript прошли, dist собран.
- Геометрия внутренних деталей не округляется; сравниваются исходные значения с учётом погрешности floating point от операции группирования. Экспорт не меняет signature исходного дерева.
- Финальный архив 0.4.2 выполнен через main bundle с Figma fixture. В подготовленное состояние добавлены дробная деталь Rectangle и дробная подпись. Проверка и PNG-экспорт пройдены; настоящие CLI 0.4.0, writer и reader Extron подтвердили GDL для обеих панелей, **53/53** проверок на профиль.
- Figma API/PNG в тестах моделируются; реальный пользовательский макет и GUI Designer Verify/Build в этой сессии не управлялись. Browser UI не менялся, кроме номера версии; отдельный Chromium-прогон для этого исправления не выполнялся.
- `git diff --check` пройден.
