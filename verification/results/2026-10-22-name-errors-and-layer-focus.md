# Ошибки имён и переход к проблемному слою

22.10.2026. Работа выполнена в основной папке на `main`.

## Диагноз

- На пользовательском скриншоте `line_Devider 4` содержит обычный пробел перед `4`. Действующий стандарт допускает латиницу, цифры, точки и дефисы между непустыми частями. Ошибка имени обоснована; прежнее сообщение показывало только суффикс и не называло конкретный символ.
- `logo_trilliant` на скриншоте имеет тип `BOOLEAN_OPERATION`. Для самостоятельной графики нужен Frame или поддержанный экземпляр кита. Переименование не меняет тип; автоматическое оборачивание не выполнялось.
- Команда «Показать слой» находила слой по ID в исходной области экспорта, выделяла его и вызывала `scrollAndZoomIntoView`. Прежние тесты проверяли передачу ID в этот метод, но не положение камеры. Причина наблюдавшегося в Figma смещения по одному скриншоту не подтверждена; доступного воспроизведения в исходном документе нет.

## Изменения

- Ошибка имени содержит полное имя слоя, позицию недопустимого символа и допустимый пример: `line_Devider 4` → `line_Devider-4`. Пробелы, NBSP и zero-width space покрыты проверками. Стандарт имён и существующие назначения сохранены.
- `focusNode` устанавливает масштаб и центр явно через `figma.viewport`. Используется `absoluteBoundingBox` в координатах холста; при отсутствии границ — четыре угла через `absoluteTransform`. Нулевые размеры линии не вызывают деление на ноль. Максимальное приближение — 200%, отступ от границ viewport — 64 экранных пикселя.
- Отчёт и исходная область повторного распознавания сохраняются. Видимость скрытых состояний, имена, геометрия и metadata при переходе не меняются.
- В браузерном стенде устранена гонка теста восстановления после ошибки: перед снятием блокировки стенд ждёт фактического получения команды `check`.

API сверено с [официальной документацией viewport](https://developers.figma.com/docs/plugins/api/figma-viewport/).
