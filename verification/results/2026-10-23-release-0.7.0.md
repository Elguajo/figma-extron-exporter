- `compatibleCliVersion` = 0.7.0. EXUI/5 не менялся: схема побайтово совпадает с прежней, `textColor` по-прежнему только `#RRGGBB`.

## Полупрозрачный текст

GUI Designer 1.28.0.7 хранит альфу цвета текста: редактор Text Color содержит Alpha 0–255, полупрозрачный текст рисуется со смешиванием, после Save and Build в `layout.json` остаётся `TextColor A=128`, текст не запекается в PNG. Поскольку вид такого текста на панели и в GCP не проверен, по решению пользователя альфа не экспортируется. Непрозрачность заливки или Opacity Text-слоя ниже 100% для label, value, datetime и текста состояний кнопки дают ошибку распознавания с именем слоя и способом исправления; дизайн не меняется. Раньше это была общая ошибка opacity либо молчаливый PNG для статической подписи. Тестовые файлы: `output/text-color-probe/`.
