# Нумерация кнопок — 23.10.2026

Реализована локальная preview-доработка на базе 0.7.2. Публичный выпуск и публикация в GitHub не выполнялись. Разработка в основной папке, ветка `main`.

## Поведение

Отдельный раскрывающийся блок «Нумерация кнопок» расположен под «Оформление кнопок», перед «Назначения Extron». Настройки: основа имени (Box), начальный номер (1), режим «Заново по расположению» / «Исправить только повторы», независимые флажки имён и текста. Обновление текста изначально выключено. Предпросмотр автоматически обновляется после изменения настроек; изменения применяются отдельной кнопкой.

- Область — текущее выделение групп, фреймов, секций или самих кнопок. Режим экспорта, сохранённый проект и связанные popup её не расширяют. Пересекающиеся выделения обрабатываются один раз.
- Счёт отдельный для каждого непосредственного родителя, без продолжения счёта через вложенные контейнеры. Порядок: строки сверху вниз, внутри строки слева направо; верхние края в пределах 2 px от начала строки считаются одним рядом.
- Сохраняются префиксы `button_`, `btn_`, `feedbackbutton_`, `fbtn_`. Определения компонентов и внутренние слои кнопок не нумеруются. Основа применяется ко всем кнопкам выделения; для части кнопок следует выбрать их непосредственно.
- Режим повторов сначала резервирует существующие номера выбранной основы, затем заполняет свободные от начального номера. Сохранённый оригинал имеет приоритет над копией. Невыбранные соседи резервируют номера, но не меняются.
- Текст обновляется во всех состояниях, включая скрытые, либо в одной подписи ещё не подготовленной кнопки. Неоднозначность, отсутствие подписи, смешанное оформление внутри Text или недоступный шрифт останавливают подготовку до изменений.
- Все необходимые шрифты загружаются до записи. План проверяется до и после ожидания шрифтов: выделение, структура выбранных деревьев, новые вложенные контейнеры и резервирующие номера соседей. Устаревший план отклоняется; интерфейс предлагает «Обновить предпросмотр».
- Изменения объединяются в действие Undo, при ошибке записи выполняется восстановление прежних имён и текста. Ошибка неполного восстановления сообщается явно.

## Архитектура и совместимость

`src/figma-plugin/src/button-numbering.ts` строит неизменяющий документ план и применяет его. `code.ts` хранит план и токен только в памяти. Расчёт включается после первого открытия раздела; запуск плагина не запускает дополнительную сериализацию макета. UI использует существующие стили, нативные поля, checkbox, select и details.

Команда не записывает metadata и реестры ID. Следующее распознавание использует существующий `key-sync`: автоматические ключи следуют новым именам, ручные ключи сохраняются. ID объектов, управления и состояний остаются прежними. CLI, EXUI/5, схемы metadata и manifest ID не менялись; миграция не требуется.
