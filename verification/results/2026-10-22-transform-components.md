# Трансформации кнопок и текстовые компоненты — 22.10.2026

## Наблюдение и причина

На пользовательском скриншоте 0.5.2 отказ на Group `Normal` внутри `button_VolumeUp`: «поворот, отражение и skew не поддержаны», хотя Rotation показывает 0°. Другой отказ — `datetime_Clock` типа COMPONENT. Точная матрица исходного файла не получена; ложность первого отказа не утверждается. Пользователь запросил поддержку таких элементов без обязательного доступа к Figma-файлу.

`plain()` запрещал любую неединичную линейную часть relative/absoluteTransform до экспорта состояния в PNG. `exportPng()` дополнительно сбрасывал матрицу временной копии в единичную при помещении в контейнер. `controlText()` принимал Text, Instance и помеченный Frame кита с одним Text, но исключал основной Component.

## Изменение

- Кнопка и её растровое оформление допускают конечную невырожденную трансформацию. Остальные проверки внешнего оформления и нативных элементов сохранены.
- Состояния с трансформацией переходят в растровую ветку, включая Frame с обычным Text. Текст таких состояний сохраняется в PNG; отдельная нативная подпись не создаётся.
- PNG получает исходную абсолютную линейную матрицу, перенесённую относительно absoluteBoundingBox с учётом прозрачных полей. Источник не меняется; временные копии удаляются при успехе и ошибке.
- Полноразмерный фон проверяется в абсолютных границах, что позволяет поворот внешней кнопки. Нативная область нажатия — охватывающий прямоугольник; состояния должны совпадать с ним.
- Component с единственным непосредственным Text принимается для Label/Value/DateTime. Содержимое, геометрия, оформление и шрифт проходят существующие проверки. Value и DateTime сохраняют нативную динамику. Многослойные компоненты общего назначения не получили автоматическое разложение.
- Версия плагина 0.5.3; совместимый CLI 0.5.2, EXUI/5 и plugin ID сохранены.
