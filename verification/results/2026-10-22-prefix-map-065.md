# Prefix Map Cheat Sheet: плагин 0.6.5 / CLI 0.6.3

22.10.2026. Создана актуальная русская PDF-шпаргалка по контракту EXUI/5.

- Генератор: `verification/Generate-PrefixGuide.py`; версии читаются из `src/figma-plugin/package.json`.
- Основной документ: `docs/prefix_map/figma-extron-prefix-cheatsheet.pdf`.
- Копия для передачи: `output/pdf/figma-extron-prefix-cheatsheet.pdf`.
- Четыре листа A4 landscape: структура и popup; управление и состояния; текст, графика и пример громкости; подготовка, назначения по именам и экспорт.

Правила сверены с актуальными разделами AUTHORING_STANDARD.md, PREFIXES.md, BUTTON_STATES.md, recognize.ts и заметками выпуска 0.6.5. Добавлены выбор цели со стороны popupref, создание группы popup через размещение, стартовая страница и группа выбора кнопок. Явно указаны сохранение назначений и исполнение AV-логики программой Extron.

Проверено через pypdf и pdfplumber: ровно 4 страницы A4, все 49 алиасов (включая состояния и зарезервированные неподдержанные типы), Home и Icon, версии 0.6.5 / 0.6.3, три колонки примеров, нумерация 1-4, встраивание используемых TrueType-шрифтов, отсутствие текста за полями. Все четыре страницы отрендерены Poppler на ширине 1600 px и просмотрены; после правки пояснения группы выбора четвёртая страница проверена повторно. Обрезки, наложения и повреждения кириллицы не обнаружены. Основной PDF и выходная копия совпадают по SHA-256. `git diff --check` успешен.

Сборка: Python с ReportLab, `python verification/Generate-PrefixGuide.py`. Нужны Arial и Consolas из `C:/Windows/Fonts`.
