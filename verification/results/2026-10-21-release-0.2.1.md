## Повторение проверок архивов

После распаковки полного комплекта в `output/releases/0.2.1/installed` и сборки исходников для source-тестов:

```powershell
$env:DOTNET_EXE = (Resolve-Path '.tools/dotnet/dotnet.exe').Path
node src/figma-plugin/test/archive-smoke.ts releases/figma-plugin/0.2.1/figma-extron-plugin-0.2.1.zip output/releases/0.2.1/installed output/releases/0.2.1/archive-smoke-new
$env:EXUI_PLUGIN_UI = (Resolve-Path 'output/releases/0.2.1/installed/figma-plugin/dist/ui.html').Path
node src/figma-plugin/test/browser.ts output/releases/0.2.1/browser-new
```

Для повторного прогона использовать новые пути результатов. Полный комплект воспроизводится `scripts/Package-Release.ps1 -DotnetExe ./.tools/dotnet/dotnet.exe -IncludeLocalSamples -OutputDirectory ./output/releases/0.2.1-new`. Скрипт сохраняет старые архивы и разрешает включать локальные образцы только внутри `output/`.
