# Нумерация только выбранных кнопок — 23.10.2026

Уточнение пользователя после сборки 0.7.3: оба режима нумерации должны менять только непосредственно выделенные кнопки.

`planNumbering()` больше не обходит выделенные группы, фреймы и секции рекурсивно. Он фильтрует текущее выделение по признаку кнопки. Выбор родителя либо Text/Artwork внутри кнопки не включает кнопку автоматически. В смешанном выделении учитываются только сами кнопки; выбор родителя дополнительно не расширяет область. Структура состояний выбранной кнопки по-прежнему используется для обновления её подписи.

Невыбранные соседние кнопки не получают изменений имён, текста или metadata; их номера резервируются. Для выбранных кнопок из разных родителей сохранены независимые счётчики. Устаревание плана отслеживает выбранные кнопки и резервирующих номера соседей. Новое содержимое постороннего контейнера не становится частью команды. Порядок, схемы metadata, сохранённые ID, формат EXUI/5 и CLI не менялись.

Обновлены подсказки интерфейса, текущие README, тесты логики, браузерный и архивный сценарии. Первоначальные архивы и протокол выпуска 0.7.3 сохранены; локальное исправление собрано отдельно:
