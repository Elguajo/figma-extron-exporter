# Inter 4.1 — native project font

Unmodified static font collection `Inter.ttc`, from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), `Inter-4.1.zip`, downloaded 2026-10-22. SHA-256: `EA4E3D9970B9B6B566110A1B0E13635FE235280B83DD2443DCB3FACA1E2456EF`.

Copyright Rasmus Andersson. Distributed under the accompanying SIL Open Font License 1.1. The collection includes Inter and Inter Display with their static weights and italics. It is embedded in the CLI assembly and added once to a GDL only when referenced. No system-wide font installation is performed, and no font file supplied by an EXUI package is loaded.
