Выберите один Frame экрана или проекта

Это собственный макет без назначения Extron. Используйте «Распознать по именам» ниже либо подготовьте экран и назначьте элементы вручную. Экспортируется экран или весь project_Name. Ключи и ID сохраняются.
Назначить по именам Выберите экран Home или project_Name. button_/btn_: только Off + On. feedbackbutton_/fbtn_: Normal + Active + Pressed. Регистр букв не важен. Прежние сохранённые кнопки сохраняют свои состояния.

    Элементы
    Назначение выбранного элемента

    Имена слоёв можно менять. Назначение, ключ и ID хранятся на узле. Копиям явно назначьте новые ключи и ID.

    Обычная кнопка: Off + On. Кнопка с feedback: Normal + Active + Pressed. В каждом состоянии — Text и необязательная иконка. Active / On задаёт программа управления, Pressed показывается при удержании. Переименование слоя не меняет сохранённый тип кнопки.

    Переходы, группа выбора, доступность и видимость — указания в карте ID. Их применяет программа управления; GDL сам их не исполняет.
