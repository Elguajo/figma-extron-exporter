2Назначения Extron

Выберите секцию или экран. Плагин распознает имена слоёв и предложит ключи и ID.

      Назначение выбранного элемента

      Выберите элемент на холсте. Здесь можно изменить его тип, переход и свойства. Сохранённые ключи и ID сохраняются при распознавании.

      Ручная подготовка Frame без распознавания дочерних элементов.
      Выберите цель из текущего проекта. Переход подключается в программе управления Extron. Переходы, группа выбора, доступность и видимость — указания в карте ID. Их применяет программа управления; GDL сам их не исполняет.
      Экспорт включает все существующие состояния, в том числе скрытые.
      Библиотека компонентов

      Готовые кнопки, регуляторы и другие элементы для новых макетов.

      Добавит библиотеку и пример рядом с макетами на текущем холсте.
