Состояния обычных кнопок
Обычный образец → Off или Normal; активный → On или Pressed. При обновлении готовых двухсостояниевых button_ / btn_ их пара также заменится на выбранную. У feedbackbutton_ / fbtn_ сохраняется схема Normal / Active. Сливающиеся с фоном цвета станут чёрными или белыми. Для сложных заливок и изображений потребуется ручная проверка.
Уже есть состояния. Что сделать?

Оформление применяется только к текущему выделению Figma. Для точечного изменения выберите сами кнопки. Меняются заливка и обводка фона; при включённой коррекции — неконтрастные цвета текста и иконок. Расположение сохраняется. При обновлении готовых кнопок Pressed получает активный образец.

Выбрать образцы и фон вручную Выберите Rectangle образца или готовое состояние в Figma, затем назначьте его обычным или активным. После назначения вернитесь к экрану. Если у кнопки несколько фонов, выберите нужный Rectangle или Frame размером с кнопку и отметьте его. Повторное нажатие снимает отметку. Новые кнопки: Group или Frame с именем button_ / btn_ → Off / On; feedbackbutton_ / fbtn_ → Normal / Active. Normal / Pressed для удержания и третье состояние Pressed подготавливаются вручную. Passive / Active и другие поддержанные имена сохраняются. Произвольное расположение текста: назовите кнопку imagebutton_VideoControl или ibtn_VideoControl. Каждое состояние целиком сохраняется в PNG: фон, иконки и текст на своих местах. Новые кнопки подготавливаются как button_; у переименованных сохраняются тип, состояния и ID. Подпись редактируется в Figma и не меняется через Text Feedback.
Выравнивание текста кнопок

У обычных кнопок подпись уже является редактируемым текстом Button. Выберите кнопки, экран или popup, чтобы изменить её выравнивание.

Кнопки imagebutton_ / ibtn_ сохраняют весь текст в PNG и пропускаются при применении текста для GCP, даже если раньше для них было настроено выравнивание.

button_ / btn_ и feedbackbutton_ / fbtn_ уже экспортируют подпись как редактируемый текст самой кнопки; применять этот раздел для этого не нужно. Здесь можно изменить выравнивание. По умолчанию текст по центру; у рамки на всю кнопку сохраняется Bottom. «Автоматически из Figma» выбирает центр или низ по положению текстовой рамки; верх и неоднозначное положение требуют ручного выбора. Нужен один непустой Text на состояние и общий поддержанный шрифт; кнопки без текста разрешены. Фон и иконки остаются графикой, ID и слои сохраняются. imagebutton_ / ibtn_ всегда экспортируют состояние целиком в PNG.

Нумерация кнопок

Выделите сами кнопки в Figma. Меняются только выделенные кнопки; выбор родительской группы или фрейма не включает их содержимое. В каждом родителе отдельный счёт.

Слева направо, сверху вниз. Пример: button_Box1 и «Box 1». Невыбранные соседние кнопки сохраняются и резервируют свои номера. В режиме исправления повторов существующие номера сохраняются. Текст обновляется во всех состояниях выбранной кнопки.

        Распознанные назначения

            Размещение popup

            Выберите место по имени. Существующая группа используется повторно; для отдельных popup группа создаётся автоматически. Размеры Frame должны совпадать.

            Содержимое места popup

            Выберите содержимое по имени и сохраните связь. В списке — цели этого проекта с подходящими размерами.

              Группа выбора кнопок

              Новая группа создаётся из выделенных кнопок. Выбор и обратную связь подключает программа управления Extron.
              Назначение выбранного элемента

              Для экспорта заполнять эту форму не нужно. Ключи и свободные ID назначаются автоматически, диапазон по умолчанию — 0–100. Здесь можно задать особые свойства.

              «Сохранить назначение» записывает тип и свойства в файл Figma. При повторном выборе слоя и после перезапуска плагина они восстановятся. Профиль панели и состав проекта запоминаются отдельно на текущей странице Figma. Ручная подготовка Frame без распознавания дочерних элементов.
              Off / On — включение или выбор; Normal / Pressed — нажатие и удержание; Normal / Active / Pressed — выбор с видом нажатия. Passive / Active и кнопки Normal / Active без Pressed остаются совместимыми. Выбор типа не создаёт состояния. Обновляется по имени слоя при проверке и скачивании. Изменённый здесь ключ сохраняется; очистите поле, чтобы вернуть автоматический. ID не меняются.
              Поле ID в GUI Designer — это «ID управления Extron» (1–65535). Можно взять ID кнопки, созданной в GUI Designer, например 1; «ID объекта» оставьте текущим. Сохранение проверяет занятые ID в проекте выбранной кнопки независимо от области экспорта. Чтобы перенести оформление в рабочий GDL, используйте режим замены по ID в утилите обновления 0.8.8. Сохраняет только ID выбранного элемента; остальные поля формы не применяются. Ошибки оформления других слоёв не мешают сохранению. Копии и состояния подготавливаются отдельно при проверке и экспорте.
              Ключи связи вручную
              Новое popupref_Name при проверке находит соседний popup_Name или popupgroup_Name автоматически. При нескольких совпадениях выберите цель в «Содержимое места popup» и сохраните связь. Уже сохранённое место без связи нужно связать через список; ключи и ID вводить не требуется.
              По умолчанию фон прозрачный, обводка не переносится. Радиусы углов и Opacity самого Frame игнорируются; содержимое popup сохраняет своё оформление. Для экспорта: фон — один SOLID; обводка — один SOLID, Inside, сплошная и одинаковой толщины со всех сторон. После выбора нажмите «Сохранить назначение».
              Пусто — формат берётся из макета: свойство Format компонента datetime_Clock из Extron Kit, Text-слой «Pattern: HH:mm» внутри компонента или текст-пример из каталога, например «September 28, 12:00 AM». Введённый здесь формат сохраняется и важнее макета. Переходы между экранами и открытие/закрытие popup настраиваются в GCP после импорта интерфейса. Связывать кнопки с экранами в Figma не требуется. Группа выбора, доступность и видимость — указания в карте ID. Их применяет программа управления; GDL сам их не исполняет.
              Экспорт включает все существующие состояния, в том числе скрытые.
