Уже есть состояния. Что сделать?

Меняются заливка и обводка фона. Иконки, подписи и их расположение сохраняются. Ручной Pressed остаётся без изменений.

Выбрать образцы и фон вручную Выберите Rectangle образца или готовое состояние в Figma, затем назначьте его обычным или активным. После назначения вернитесь к экрану. Если у кнопки несколько фонов, выберите нужный Rectangle или Frame размером с кнопку и отметьте его. Повторное нажатие снимает отметку. Новые кнопки: Group или Frame с именем button_ / btn_ → Off / On; feedbackbutton_ / fbtn_ → Normal / Active. Normal / Pressed для удержания и третье состояние Pressed подготавливаются вручную. Passive / Active и другие поддержанные имена сохраняются.

3Назначения Extron

Ключи и свободные ID заполняются при проверке и скачивании. Распознавание позволяет заранее посмотреть результат.

Покажите слой на холсте и исправьте его в Figma. Затем повторите распознавание всего макета.

    Распознанные назначения

        Назначение выбранного элемента

        Для экспорта заполнять эту форму не нужно. Ключи и свободные ID назначаются автоматически, диапазон по умолчанию — 0–100. Здесь можно задать особые свойства.

        Ручная подготовка Frame без распознавания дочерних элементов.
        Off / On — включение или выбор; Normal / Pressed — нажатие и удержание; Normal / Active / Pressed — выбор с видом нажатия. Passive / Active и кнопки Normal / Active без Pressed остаются совместимыми. Выбор типа не создаёт состояния.
        Выберите цель из текущего проекта. Переход подключается в программе управления Extron. Переходы, группа выбора, доступность и видимость — указания в карте ID. Их применяет программа управления; GDL сам их не исполняет.
        Экспорт включает все существующие состояния, в том числе скрытые.
