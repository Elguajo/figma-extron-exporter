# Префиксы слоёв Figma → Extron

Версия справочника 1.2, плагин 0.1.5. Регистр букв не важен: `btn_volumeup`, `btn_VolumeUp` и `BUTTON_VOLUMEUP` равнозначны. Короткий и полный префиксы дают один и тот же тип элемента.

## Элементы экрана

| Что рисуем | Короткое имя | Полное имя | Что получится и как подготовить |
|---|---|---|---|
| Экран | `Home` или `scr_Home` | `screen_Home` | Внешний Frame 1280×800 или 320×480. Один экран на пакет. |
| Обычная кнопка | `btn_Music` | `button_Music` | Редактируемая кнопка PBButton. Внутри Frame состояний и Text. |
| Увеличить громкость | `btn_VolumeUp` | `button_VolumeUp` | Кнопка «+». Рекомендуемые состояния: Normal / Pressed. |
| Уменьшить громкость | `btn_VolumeDown` | `button_VolumeDown` | Кнопка «−». Рекомендуемые состояния: Normal / Pressed. |
| Заглушить звук | `btn_Mute` | `button_Mute` | Кнопка Mute. Off / On показывает обратную связь; можно добавить Pressed. |
| Ползунок громкости | `lvl_Volume` | `level_Volume` | Горизонтальный PBLevel Slider 0–100. Пустой Frame с одной сплошной заливкой. |
| Надпись | `txt_Title` | `text_Title` | Самостоятельный Text → PBLabel. Arial Regular/Bold, LEFT / CENTER. |
| Значение громкости | `txt_VolumeValue` | `text_VolumeValue` | Статическая подпись, например «42%». Автоматическая динамическая привязка не создаётся. |
| Логотип | `logo_Company` | `logo_Company` | Отдельный Frame внутри экрана → PNG-ресурс и объект PBImage. Состояния и ID управления не нужны. |
| Фото, иллюстрация, статичная графика | `img_Photo` | `image_Photo` | Такой же PBImage. Внутрь Frame поместить нужную графику; она экспортируется одним PNG. |
| Иконка состояния кнопки | `Icon` или `ico_Music` | `icon_Music` | Frame **внутри состояния кнопки**. PNG-ресурс этого состояния; не отдельный объект экрана. |

Все элементы, кроме иконки состояния, располагаются непосредственно во внешнем Frame экрана. `logo_` — уже полное слово, дополнительного сокращения нет. `logo_Company`, `img_Company` и `image_Company` означают одну статичную картинку: одновременно использовать эти имена на одном экране нельзя.

`button_Music` означает «кнопка с функцией Music», но не выбирает аудиоустройство автоматически. Увеличение/уменьшение громкости, шаг, повтор при удержании, Mute и обратную связь реализует программа управления Extron.

## Состояния кнопки

| Имя Frame внутри кнопки | Допустимые варианты | Для чего |
|---|---|---|
| `Normal` | `Off`, `st_Normal`, `state_Normal`, `st_Off`, `state_Off` | Исходный вид. |
| `On` | `Feedback`, `st_On`, `state_On`, `st_Feedback`, `state_Feedback` | Вид по команде программы управления, например Mute включён. |
| `Pressed` | `st_Pressed`, `state_Pressed` | Вид, пока кнопку удерживают; после отпускания возвращается обычный вид. |

Выбирать схему по поведению кнопки:

| Схема | Где подходит | Нажатие и отпускание |
|---|---|---|
| **Normal + Pressed** | «+», «−», команды без постоянного On | При удержании Pressed, после отпускания Normal. |
| **Off + On** | Два состояния устройства без отдельного эффекта нажатия | On выбирает программа; отдельный Pressed не создаётся. |
| **Off + On + Pressed** | Mute/источник с обратной связью и эффектом удержания | Pressed при удержании; после отпускания вид соответствует обратной связи. Проверить с программой управления. |

Нельзя добавлять одновременно Off и Normal или On и Feedback: это дубликаты одной роли. Во всех схемах должно быть видно ровно одно состояние для предпросмотра. Каждый Frame состояния занимает всю кнопку, внутри ровно один непустой Text на всю площадь и необязательная иконка. Шрифт общий, виды различаются текстом, цветом или изображением.

Пример «+», жёлтая при удержании:

```text
Home
├── button_VolumeUp
│   ├── Normal                 Frame, обычная заливка, видим
│   │   └── Text               Text «+», на всю кнопку
│   └── Pressed                Frame, жёлтая заливка, скрыт в preview
│       └── Text               Text «+», на всю кнопку
└── logo_Company               Frame, внутри графика логотипа
```

Жёлтый цвет задаёт дизайнер, например `#FFCC00`. Плагин сохраняет оформление, но не перекрашивает состояние по имени Pressed.

## Имена, зоны и ID

После префикса — имя латиницей, можно цифры и дефисы; первый символ — буква. Без пробелов и дополнительных `_`. Видимый текст внутри Text может быть русским.

Для нескольких зон: `button_HallVolumeUp`, `button_HallVolumeDown`, `level_HallVolume`, `button_TerraceVolumeUp`, `level_TerraceVolume`. Префикс обозначает тип, оставшаяся часть — уникальное назначение на этом экране.

Новые ключи формируются из контекста экрана и имени в нижнем регистре: `Home` + `button_VolumeUp` → `home.volumeup`. CamelCase не добавляет дефисы. `btn_volumeup` рядом с `button_VolumeUp` вызовет ошибку дубликата. При обновлении старые ключи, в том числе `home.volume-up`, и ID не заменяются.

Простое переименование уже назначенного слоя не меняет его сохранённый смысл. Для смены назначения использовать ручную форму. Копии уже назначенных узлов требуют явного переназначения; у копий неназначенного дерева достаточно подготовить уникальные имена до первого распознавания.

## Логотипы и картинки

Внешний Frame логотипа имеет целые координаты/размеры, находится внутри экрана, видим, opacity 100%, без поворота, обводки, эффектов и скруглений на самом внешнем Frame. Для прозрачного фона убрать заливку внешнего Frame. Внутри можно использовать векторы, текст, изображения и скругления — содержимое экспортируется одним PNG 1× с прозрачностью. Прозрачные поля входят в размер Frame.

PBImage остаётся отдельным объектом в GUI Designer: можно менять положение и ресурс. Внутренние векторы/буквы логотипа становятся пикселями PNG и отдельно не редактируются. У логотипа нет нажатий, On/Off или controlId.

Если логотип должен нажиматься — использовать `button_Company` со состояниями и иконкой внутри состояния. Если картинка должна отображать динамическое состояние устройства — это отдельная задача программы управления.

Логотипы и иконки делят лимит 16 PNG на экран, каждый до 4 MiB, общий распакованный пакет до 16 MiB. Масштабирования PNG нет; размер ресурса равен размеру Frame.

## Экспорт

Выбрать внешний Frame и профиль → **«Распознать по именам»** → проверить таблицу и ошибки → **«Сохранить распознанные назначения»** → **«Проверить экран»** → **«Скачать .exui»**.

Для логотипов, картинок и схемы Normal/Pressed нужен плагин 0.1.5 и обновлённый CLI с `.exui/4`. Прежние `.exui/1` и `.exui/3` продолжают использоваться для соответствующих экранов. Результат требует отдельной проверки в Figma/GUI Designer и на панели.

Остальные правила: [полный стандарт подготовки](AUTHORING_STANDARD.md), [установка](README.md).
