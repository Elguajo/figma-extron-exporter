# Extron Kit — исходники и история дизайна

Актуальная ревизия — **2026-10-26-control-feedback / Apple-inspired Light**. Генератор Figma `src/figma-plugin/src/kit.ts` создаёт 29 отдельных компонентов (15 универсальных, 14 готовых), набор `datetime_Clock` с 28 вариантами, палитру и галерею состояний, шаблон проекта и пример выбранной панели. Раздел 08 дополняет их ожиданием, недоступным источником, восстановлением связи и отдельным компактным экраном 320×480. Volume +/− и Back/Home/Settings используют **Normal / Pressed**. Каталог и генератор — источник текущей библиотеки; визуальные правила и Apple HIG — в [DESIGN.md](DESIGN.md).

- `kit.json` — актуальный каталог типов, служебных имён, состояний, палитры и даты ревизии для генератора Figma. Контракт `extron-kit/1` сохранён.
- `content.json` — тексты и компоновки раздела 08 для обоих профилей плюс независимый `screen_CompactAudio`. Используются генератором; по этому же каталогу дополнен живой файл Figma. Состояние пассивного действия не добавляет неподдерживаемые состояния к button_.
- `apple-light-2026-10-24.pen.js` — применённая актуализация всего исходного холста pen.dev: компоненты, примеры обеих панелей, контейнеры, подтверждение, часы и отдельная галерея состояний/токенов. Использует ID исходного документа; выполняется только в нём.
- `organize-community-layout-2026-10-24.pen.js` — последующая группировка по исследованию Figma UI-китов: обложка, пять глав, отдельные рабочие шаблоны и примеры. Перемещает существующие узлы, сохраняет ID основных компонентов и натуральные размеры рабочих экранов. Порядок воспроизведения: сначала визуальный сценарий Apple Light, затем организация холста.
- `apple-light-2026-10-24.snapshot.json` и `previews/apple-light-2026-10-24/` — настоящий MCP-снимок и рендеры полной текущей ревизии. В pen.dev 30 семейств компонентов; 28 форматов часов показаны связанными экземплярами, а Figma создаёт 28 компонентов-вариантов.
- `refresh-2026-10-24.pen.js` — выполненное через MCP обновление существующего холста: состояния пяти моментарных кнопок, инструкция, пример часов и отдельная галерея 28 форматов. Использует ID исходного документа; повторный запуск не добавляет вторую галерею. Форматы в скрипте зафиксированы из `datetime-format.ts` на дату ревизии.
- `pen-refresh-2026-10-24.snapshot.json` — прочитанный через MCP снимок четырёх актуальных секций. В pen.dev 28 форматов показаны экземплярами одного компонента с переопределённым текстом; Figma создаёт настоящий набор вариантов Format. Компоненты, ссылки экземпляров и пользовательский Frame сохранены.
- `previews/2026-10-24/` — настоящие PNG pen.dev после актуализации: `qn7gm.png` — инструкция, `bBKBy.png` — готовые элементы, `S9VIn.png` — 28 форматов.
- `pen-canvas.snapshot.json` — исторический снимок объектов от **21.10.2026**, прочитанный через MCP; это JSON-снимок, не `.pen` и не `.fig`.
- `build-universal.pen.js`, `build-presets.pen.js`, `build-templates.pen.js` — исторические MCP execute-сценарии создания первоначального холста от **21.10.2026**: 30 компонентов (16 универсальных, 14 готовых), 5 переиспользуемых шаблонов контейнеров и два примера. Содержат первоначальные состояния Volume Off/On и часы без нового набора Format; текущую библиотеку не воспроизводят. Повторный запуск добавляет новые объекты.
- `previews/` — исторические PNG настоящего рендера pen.dev от **21.10.2026**: `MeFgF.png` — универсальные, `bBKBy.png` — готовые, `T78n4.png` — 1025M, `EWlyr.png` — 300M. Это не превью ревизии 2026-10-24.

Первоначальный холст создан через pen.dev MCP в пользовательском `untitled.pen`, исходный пользовательский Frame сохранён. Текущие pen.dev и Figma используют Inter Regular/Bold. Нативный экспорт поддерживает Inter, Inter Display и Arial в пределах [контракта текста](../../../src/figma-plugin/NATIVE_TEXT.md).

Новый кит создаёт актуальная локальная preview-сборка на базе плагина **0.7.3** кнопкой **«Создать Extron Kit»**. Обновление плагина не меняет существующие компоненты; новый комплект добавляется рядом и помечен датой ревизии. Архив выпущенной 0.7.3 предшествует актуализации. `.fig` сохраняется из самой Figma. Установка, обновление и ограничения: [EXTRON_KIT.md](../../../src/figma-plugin/EXTRON_KIT.md).
