# Чего не хватало Extron Kit

Исследование 24.10.2026. Проверены текущий каталог, генератор, экспортный контракт и открытая документация авторов. Платные Figma-файлы не использовались; это сравнение состава и подходов, а не рейтинг популярности.

## Основания

| Источник | Наблюдение | Решение для Extron Kit |
|---|---|---|
| [Obra / How to use](https://shadcn.obra.studio/documentation/how-to-use) | Система включает цвет, типографику, радиусы, отступы; предусмотрено расширение своей библиотеки | Дополнить имеющиеся токены шкалой отступов и правилами целей нажатия |
| [Obra / Icons](https://shadcn.obra.studio/documentation/icons) | Иконки — отдельная часть библиотеки; поддерживается Lucide | Дать ограниченный набор из 18 AV-иконок с лицензией и правилами размещения |
| [Obra / Blocks](https://shadcn.obra.studio/documentation/pro-blocks) и [Untitled UI FAQ](https://www.untitledui.com/faqs) | Авторы разделяют базовые компоненты и готовые прикладные композиции | Сохранить 30 семейств; добавить шесть собственных сценариев управления помещением |
| [Extron / GUI Standards Guide](https://media.extron.com/public/download/files/guides/gui_standards_guide_C.pdf), стр. 5–10, 32–33 | Общие контролы имеют предсказуемое расположение; контекст источника меняется внутри основной страницы; нужны вход в систему, feedback, помощь и подтверждение выключения | Welcome, Presentation, Audio Zones, Connection Help, System Status, Shutdown |
| [Lucide License](https://lucide.dev/license) | Разрешено распространение с сохранением уведомлений ISC/MIT | Закрепить SVG из lucide-static 1.61.0, включить исходники и полную лицензию в поставку |

## Вывод по текущему составу

Типы Button, Slider, Level, Value, DateTime, Shape, Line, Graphic и Popup уже представлены. Дублировать их под веб-названиями Switch, Checkbox, Tabs и Select не требуется: соответствующие функции собираются из поддержанных кнопок и feedback. Главный недостаток — переход от отдельных контролов к рабочему сценарию и договорённостям с программистом.

## Контракт дополнения

Источник истины: `kit.json` для токенов и базовых типов, `patterns.json` для состава, контента, размеров обоих профилей и обязанностей программы управления; `icons/icons.json` для закреплённых SVG. Генератор Figma и сценарий pen.dev читают эти данные. Веб-документация показывает их состав и настоящие рендеры.

| Сценарий | Анатомия и состояния | Что подключить в программе |
|---|---|---|
| Welcome | Заголовок, пассивная иконка, Start, Help | Запуск; защита от повторного запуска; показ основной страницы после готовности |
| Presentation | Выбор источника с Active, Mute с feedback, Slider/Value, Help, System off | Эксклюзивный выбор; маршрутизация; feedback; синхронизация Slider/Value; открытие помощи/подтверждения |
| Audio Zones | Отдельные Mute, Slider, Value для Hall/Terrace | Независимые ID, уровни и feedback каждой зоны |
| Connection Help | Два шага, пассивная иконка, Back | Возврат к предыдущему контексту; текст по фактическим входам помещения |
| System Status | Пассивный Multilevel: Starting/Ready/Offline, динамическое сообщение, Retry/Help | Выбор состояния и текста по устройствам; тайм-аут; ограничение повторных Retry |
| Shutdown | Модальная поверхность, объяснение последствий, Cancel, Turn off | Открытие из основной страницы; Cancel закрывает; подтверждение запускает выключение |

Оформление наследует Apple-inspired Light. Кнопки не ниже 56 px; иконки 24 px, шкала отступов 8/16/24/32/48/64. Это проектные значения для двух профилей, не универсальная физическая норма в миллиметрах. Иконка дополняет подпись; пассивный статус не оформляется кнопкой. Длинные переводы требуют перепроверки в своих границах; Figma не выполняет автоматический reflow под другой профиль.

Hover, DOM focus, HTML ARIA, автоматическая анимация загрузки и нативный disabled неприменимы к этим статическим EXUI-макетам. В веб-документации используются обычные ссылки, кнопки и клавиатурная навигация. Блокировку действий и сообщения об изменениях на панели обеспечивает программа управления. Состояния Starting/Ready/Offline представлены существующим Multilevel; цвет сопровождается текстом. Пустое сообщение нужно заменить понятным текстом до показа.

Иконки — вспомогательные компоненты для Artwork, без отдельного controlId. Сценарии — настоящие `screen_`/`modalpopup_` внутри `project_AVPatterns`, с экземплярами существующих основных компонентов. Экспортировать весь проект или отдельный `screen_`; отдельный modal переносить вместе с проектом. Никакая кнопка не получает AV-команду по одному имени.

## Проверка и отложенное

Проверить для каждого профиля границы, цели кнопок, уникальные ключи/ID, скрытые состояния, все шесть контейнеров и PNG-ресурсы; затем реальные CLI/writer и независимое чтение GDL. Проверить настоящие рендеры pen.dev и сайт на узком/широком экране. Figma fixture не доказывает импорт SVG в настоящей Figma; GUI Designer Build и оборудование требуют отдельного ручного прогона.

Тёмная тема, сложная матрица маршрутизации, клавиатуры/PIN, расписания и VC-пульт отложены: нужны конкретные устройства, функции или новые экспортные контракты. Они не добавлены как неработающие декоративные контролы.
