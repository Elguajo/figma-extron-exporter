# Сопоставление и обратная карта ID — 0.8.7, 26.10.2026

Локальный preview-комплект: **плагин / CLI / LayoutUpdater 0.8.7**. Работа в основной папке `main`, прежние изменения и архивы сохранены. В `releases/figma-plugin/0.8.6` уже находился отличающийся архив; он не перезаписан. Сборка из рабочего дерева (`sourceDirty: true`), без публикации и нового Git-тега.

## Результат

- Кнопки с разными управляющими ID сопоставляются в LayoutUpdater через список новой кнопки либо группой по порядку списка. Отметки выбора определяют изменяемые старые кнопки. Одну новую кнопку нельзя использовать дважды в выбранной группе.
- Новый GDL сохраняет внутренние ID, имена, описание, контейнер, структуру состояний и поведение рабочего проекта. Проверки защищённого графа и хешей действуют; несовместимые ID/число/порядок состояний отклоняются.
- Из того же выбора сохраняется карта исходных слоёв. Плагин показывает предпросмотр и массово записывает Control ID, проверяя страницу, владельцев слоёв, ключи, исходные ID, коллизии и устаревший предпросмотр. Допускаются обмен ID и повторное применение. При ошибке записи проверен откат.
- Соответствия повторно загружаются по nodeId, в том числе после переноса целевых ID в Figma. EXUI/5 получил необязательный хешированный `figma.json`; старые пакеты читаются, существующие exui-node/1–3 не мигрируют.
