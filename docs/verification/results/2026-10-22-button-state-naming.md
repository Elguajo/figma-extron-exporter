# Единые имена состояний кнопок

22.10.2026. Согласованное правило для новых макетов:

- Off / On — включение или выбор (`button_` / `btn_`).
- Normal / Pressed — нажатие и удержание (`button_` / `btn_`).
- Normal / Active / Pressed — выбор с отдельным видом нажатия (`feedbackbutton_` / `fbtn_`).

Правило отражено в подсказках создания состояний, выборе типа кнопки, встроенном справочнике, сообщениях об ошибках и документации. Для образцов рекомендованы два Rectangle Off / On внутри Group или Frame Button Styles вне экранов.

Распознавание и экспорт уже поддерживали эти схемы: алгоритмы подготовки, валидации и экспорта не менялись. Passive / Active, Normal / Active без Pressed и прочие поддержанные синонимы остаются допустимыми. Сохранённые имена, metadata и ID не мигрируют. По эталонам по-прежнему создаются Off / On либо Normal / Active; Normal / Pressed подготавливается вручную, Pressed для тройки добавляется вручную.
