# Pen Tool / Line Tool → PBLine — 21.10.2026

Плагин **0.3.4 preview**, совместимый CLI **0.3.0**. Разработка в основной папке на `main`; ранее существовавшие изменения 0.3.3 сохранены.

## Реализация и решение

`line_` / `ln_` теперь принимают Vector с двумя вершинами и одним открытым прямым сегментом и стандартный LineNode. Геометрия берётся из vectorNetwork / длины LineNode и relativeTransform; цвет и толщина — из Stroke. Вычисляется целочисленный прямоугольник окрашенной области с учётом CENTER. Повороты/отражения, сохраняющие горизонтальное или вертикальное направление, поддержаны; масштаб/skew отклоняются.

В пакет записываются существующие `kind=line`, `fillColor`, `rect`, `native.thickness`. CLI, EXUI/5 и схемы metadata не менялись. В GDL создаётся PBLine без управляющего ID и PNG. Прежние Frame/Rectangle с заливкой остаются рабочими. Имена, исходная геометрия и существующие ID не меняются. Ручное назначение также проверяет геометрию до записи metadata; изменения Stroke/пути инвалидируют ожидающий план распознавания.

Приняты ограничения текущего контракта: горизонталь/вертикаль, плоские окончания, SOLID CENTER постоянной целой толщины, без Fill. Длина строго больше толщины, края обводки и длина — целые пиксели. При нечётной толщине ось смещается на половину пикселя самим дизайнером; плагин не округляет её молча. Диагонали, кривые, ломаные, замкнутые контуры, кисти, переменная толщина, пунктир и стрелки дают явную ошибку.

Первичные источники API: [VectorNetwork](https://developers.figma.com/docs/plugins/api/VectorNetwork/), [LineNode](https://developers.figma.com/docs/plugins/api/LineNode/); контракт сверялся с установленными `@figma/plugin-typings 1.142.0`, включая BASIC/brush strokes и свойства отдельных вершин.
