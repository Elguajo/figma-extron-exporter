# Center / Uniform и постоянная толщина линии — 0.4.4

22.10.2026. Приоритетная задача пользователя: закончить исправление линии с Center и толщиной 2 до общего поиска похожих недочётов. Сохранены предыдущие локальные исправления 0.4.2/0.4.3; работа на main.

## Причина и изменение

readStrokeLine() отклонял любой непустой variableWidthStrokeProperties. Но API Figma допускает {widthProfile: 'UNIFORM'}, который обозначает постоянную толщину: [официальная документация](https://developers.figma.com/docs/plugins/api/VariableWidthStrokeProperties/). Это согласуется с установленными @figma/plugin-typings 1.142.0.

Теперь null и UNIFORM поддерживаются. Остальные профили, кисти и динамические обводки сохраняют отказ. Проверки Position, пунктира, профиля толщины и типа кисти разделены: сообщение называет реальную причину вместо общего требования CENTER. Добавлена конкретная инструкция исправления.

Скриншот пользователя не раскрывает значения скрытых API-полей: найден и воспроизведён соответствующий ложный отказ для UNIFORM; живой документ не инспектировался. Растрирование разрешено пользователем как запасной путь для текущей задачи. Для проверенной линии оно не потребовалось: native PBLine получен и проверен.
