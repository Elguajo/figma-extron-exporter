# Область оформления кнопок — 23.10.2026

Причина: `ExportScope.resolveButtons()` ограничивал выделением только popup. Для экранов он вызывал общий resolver экспорта: сохранённый набор экранов, режим страницы, родительский проект и автоматически связанные popup могли расширить область Override.

Исправление: область оформления определяется текущим выделением независимо от экспорта. Поддерживаются один или несколько Frame, секция и отдельные Group/Frame кнопок. Вложенные выбранные элементы не обрабатываются повторно. Для выбранного рисунка или текста сохраняется ближайший экран/popup; для точечного изменения следует выбирать контейнер самой кнопки. При пустом выделении команда отклоняется. Интерфейс показывает отдельную область оформления без подстановки области экспорта.
