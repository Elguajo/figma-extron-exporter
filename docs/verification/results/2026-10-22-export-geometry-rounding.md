# Округление геометрии при экспорте — 22.10.2026

Координаты и размеры нативных элементов округляются до ближайшего целого пикселя при чтении экспортной геометрии. Примеры: 218.21 → 218, 218.7 → 219, 218.5 → 219. Исходные слои Figma не изменяются.

Размеры состояний, отдельных нативных подписей, частей Slider, обычных popup и popupref проверяются с учётом округлённых размеров контейнера. PNG состояний получает размер экспортируемой кнопки. Проверки положительных размеров, выхода за границы, структуры, оформления и целочисленных краёв Stroke у Pen/Line Tool сохраняются. Отдельная графика и статический текст сохраняют прежнее размещение точной дробной геометрии в прозрачном PNG-контейнере.
