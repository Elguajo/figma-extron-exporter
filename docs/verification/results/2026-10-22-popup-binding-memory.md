# Связь popup по именам и сохранение настроек страницы — 22.10.2026

Плагин **0.6.4**, совместимый CLI **0.6.3**, EXUI/5. Работа в основной папке на main; существовавшие изменения 0.6.3 сохранены. Коммит, push и веб-публикация для этой доработки не выполнялись. Старые архивы сохранены.

## Поведение

- Пустой popupref внутри экрана сохраняется кнопкой формы без ключа, ID и цели. Автоматически подготавливаются его назначение, новые родительские контейнеры и резерв ID. Это черновик: экспорт остаётся заблокированным до связывания.
- При выборе обычных popup вместе или полной существующей группы доступен блок «Размещение popup». В списке — места по именам экранов/Frame того же проекта и профиля; несохранённые места с корректным именем popupref_ тоже доступны. Группа создаётся автоматически или переиспользуется. Сохранённая привязка повторно выбирается в списке, если место одно.
- Создание группы перемещает popup в организационный Frame с сохранением абсолютного положения, размеров, внутреннего содержимого и оформления. Для нового группирования нужны popup-соседи непосредственно в проекте без Auto Layout и трансформаций; из существующей группы выбираются все участники. Модальные popup, неподходящие размеры/профили и другой проект отвергаются до изменений.
- Новый контейнер можно назначить без ручных ключей/ID/имени проекта. При сохранении новой стартовой страницы остальные явные или неявные стартовые страницы того же проекта становятся обычными. Запись атомарна, включая старые назначения exui-node/1.
- Типы/свойства сохраняются после «Сохранить назначение», а не на каждом изменении поля. Они остаются в DATA_KEY слоёв Figma, включая показ/start и связи group/popup. Запрос сохранения из UI содержит ID выбранного слоя, чтобы задержанный запрос не изменил другой слой.
- Профиль, режим экспорта и состав выбранного проекта сохраняются в pluginData текущей страницы под exui-page-settings. Формат exui-page-settings/1 содержит owner pageId, mode, profile и список node ID в исходном порядке; записи не накапливают историю. Перезапуск и переход между страницами восстанавливают собственные настройки, в том числе Frame внутри секций. Удалённые ID пропускаются; неизвестная/повреждённая версия настроек не блокирует чтение назначений слоёв. Client storage и внешнее хранение не используются.
- Привязка не требует готового оформления остальных кнопок: сохраняются выбранные контейнеры и новые предки, а не назначения посторонних контролов. Валидация макета при экспорте сохраняется. При отказе записи/группирования восстанавливаются metadata, резерв и положение; при невозможности полного отката выводится отдельная ошибка, исходные popup не удаляются.
