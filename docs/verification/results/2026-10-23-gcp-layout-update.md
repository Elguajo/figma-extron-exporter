# GCP — обновление настроенного макета TLP Pro 1025M

23.10.2026. Проверка через интерфейс установленных приложений: Global Configurator Plus **3.34.1.4**, GUI Designer **1.28.0.7**. Работа в основной папке на `main`; исходные пользовательские проекты не перезаписывались.

## Исходные данные и границы

Использована пара GDL из `output/update-workflow/cli-0.6.6-archive/`, созданная настоящим bundled plugin → EXUI/5 → CLI 0.6.6 → native writer. API и рендер Figma в генераторе этой пары моделируются; новый экспорт внутри Figma Desktop в этом испытании не выполнялся. Изменения v2: оформление/подпись/положение Music 8101, удаление Mute 8103, добавление Extra 8104. Уровень 8102 не изменён.

Для GUI-проверки созданы отдельные копии в `output/update-workflow/gcp-retry-2026-10-23/`. Исходный открытый пользовательский GDL с несохранёнными правками остался открытым отдельно. В GCP создан отдельный локальный проект: IPL Pro CR88 с тестовым адресом `192.0.2.10`, TLP Pro 1025M с адресом `192.0.2.11`. Подключение к оборудованию и загрузка конфигурации не выполнялись.

## Фактический прогон

1. Первичный Import Layout несобранного GDL был отклонён GCP: layout не найден; приложение потребовало GUI Designer → Save and Build.
2. Обе копии 1025M открыты в GUI Designer, выполнены Verify и Save and Build. Для каждой наблюдалось **Build Complete — 0 error(s), 0 warning(s)**. В оптимизации выбрано Keep. Независимое чтение контейнера подтвердило запись `.tgz4` рядом с `ProjectGCP` в каждом GDL.
3. Собранный v1 импортирован в GCP. В preview доступны Music 8101, уровень 8102, Mute 8103.
4. Для Music настроены **Press → Relay 1 Toggle**, **Visual Feedback → Relay 1 State**, соответствия **Off → Open**, **On → Close**. Для Mute отдельно настроено **Press → Relay 1 State (Open)**. Сохранён `configured-v1.gcplus`.
5. Через Save As создан `configured-v2.gcplus`. В нём выполнен Import Layout собранного v2. В Layout Reconciliation Music 8101 сопоставлен с Music 8101; Mute 8103 отмечен красным **Missing**. Выбран **Import new layout and keep my existing layout configuration**, затем Import.
6. В новом preview отображаются синяя кнопка с подписью Music zone и Extra. У Music сохранились **Relay 1 Toggle**, **Relay 1 State**, **Off → Open**, **On → Close**. У Extra 8104 вкладки Press и Visual Feedback пусты: действие удалённого Mute не переназначилось новой кнопке.
7. Обновлённый проект сохранён и повторно открыт через Open Project. У Music повторно подтверждены действие и оба соответствия visual feedback; новое оформление сохранено.

## Результат

**PASS в указанных границах:** обновление оформления существующей кнопки сохранило её действие и visual feedback; удалённая кнопка показана как конфликт; новая кнопка получила отдельный ID и не унаследовала действие удалённой. Результат сохраняется после повторного открытия GCP.

Это подтверждение конкретной пары и версии GCP, а не универсальная гарантия совместимости. Не проверены: назначение и перенос связи уровня 8102, GUI/GCP-цикл профиля 300M, переименование страниц/popup, смена типа/структуры состояний, физическое исполнение команд и feedback. Не установлено, как GCP хранит неиспользуемую конфигурацию удалённого Mute после импорта; подтверждено отсутствие переноса этой команды на Extra.

Поле `gcpVerified: false` команды `compare-packages` сохраняется: команда сравнивает EXUI и не читает конкретный проект GCP. Настоящий GUI-прогон фиксируется этим отдельным протоколом.
