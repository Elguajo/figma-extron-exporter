# Статические шрифты и подтверждённые недочёты подготовки — 0.4.5

22.10.2026. Работа на main, сохранены предыдущие локальные исправления. Область: ошибки, из-за которых дизайнеру приходилось вручную менять структуру или геометрию макета перед экспортом. Проверены экспорт, распознавание, подготовка состояний и их команды. Это ограниченный поиск связанных дефектов, а не заявление об отсутствии всех ошибок в плагине.

## Исправления

- **Подтверждённый отказ:** статический Text с Inter/другим шрифтом или выравниванием отклонялся как неподдержанный нативный Label. Теперь статический txt_/text_ автоматически становится PNG/PBImage, без ручного Frame. Нативный Arial остаётся PBLabel; metadata, key и objectId сохраняются. Смешанные шрифты и изменения оформления диапазонов включены в signature, чтобы экспорт не объединял разные версии дизайна.
- **Подтверждённый отказ:** Inter в обычных ранее созданных Frame-состояниях проходил по старому пути нативного текста. Теперь такое состояние использует общий экспорт оформления в PNG. Внешний Button и ID не меняются.
- **Подтверждённый отказ:** дробные координаты/размеры logo_/img_ проверялись как нативная геометрия. Теперь прозрачный PNG-контейнер имеет целые внешние границы; исходный слой внутри сохраняет точный размер и смещение. Пример X=48.42, Y=27.91, W=204.01, H=29.09 → rect=[48,27,205,30], без масштабирования и изменения Figma.
- **Тот же класс ошибки определения фона:** прозрачный Frame состояния ошибочно конкурировал с дочерним Background. Он больше не считается вторым фоном; Frame без отдельного фона остаётся допустимой поверхностью оформления.
- **Подтверждённый разрыв путей:** вручную подготовленное Frame-состояние с Group/Vector-иконкой требовало старую структуру Frame-иконки. Составная графика теперь попадает в общий путь artwork без специальной отметки генератора.
- **Подтверждённая ошибка дополнения:** из единственного Pressed создавались Off и On, получались три состояния обычной кнопки. Создаётся только Normal, с сохранением Pressed; пакет получает плотные ID 0/1.
- **Подтверждённая ошибка области команды:** UI показывал содержащий экран при выбранном внутреннем слое, но команды создания/обновления состояний требовали строго внешнее выделение. Они теперь используют тот же разрешённый экран, что проверка и экспорт.

## Сохранённые требования

Value и DateTime должны обновлять содержимое, поэтому не превращаются в статичную картинку: по-прежнему требуются нативный Arial и LEFT/CENTER. Геометрия управляющих нативных элементов остаётся целочисленной. Непостоянные линии, кисти, эффекты и взаимодействия не объявлены нативно поддержанными. Исправление Center/Uniform из 0.4.4 включено; для проверенной линии растрирование не понадобилось.
