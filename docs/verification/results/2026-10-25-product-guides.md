## Текст и иконки

В установленном `Extron.GUICPro.Layout.Contracts.dll` перечислен `Extron.GUICPro.Layout.Contracts.Enumerations.AlignmentEnum`: BottomCenter / BottomLeft / BottomRight, MiddleCenter / MiddleLeft / MiddleRight, TopCenter / TopLeft / TopRight и None. В локальной справке GUI Designer `Help/Content/HTML_Files/Window_Modules/Properties/Appearance.htm` у Button описано свойство Text Alignment.

Таким образом, **сетка 3x3 есть в GUI Designer**. Две позиции относятся к текущему экспорту нативного текста Button: `ButtonTextMode` в `button-native-text.ts` допускает auto / middle-center / bottom-center. Auto игнорирует абзац Figma; верхние / неоднозначные / выходящие за кнопку рамки отклоняются. Label / Value / DateTime имеют девять сочетаний.

Принятое правило нового авторинга: **текст по центру всей кнопки, иконка слева либо справа в Artwork**, с явным применением «По центру». Иконка входит в PNG состояния; отдельного controlId нет. С обеих сторон нужен равный резерв под самое длинное значение Text Feedback. Экспортёр не измеряет будущие значения feedback и не проверяет пересечения. Существующие макеты / настройки автоматически не меняются; низ по центру остаётся альтернативой.
