# Ручные ID и замена оформления GUI Designer — 26.10.2026

Локальная preview-сборка: плагин, CLI и LayoutUpdater **0.8.5**, EXUI/5. Работа в основной папке `main`; существующие изменения сохранены. Архивы собраны из незакоммиченного рабочего состояния (`sourceDirty: true`), публикация и Git-тег не выполнялись.

## Исправления

- «Сохранить ID» больше не требует успешной проверки оформления или наличия выбранного элемента в строках распознавания. Назначение сохраняется в проекте выбранной кнопки независимо от запомненных экранов экспорта. Занятые ID проверяются по фактическим владельцам metadata, включая слои с ошибками распознавания.
- Проверены ID `9140` и `1`, копии popup, восстановление номера удалённой кнопки, сохранение после перезапуска и экспорта, конфликты и откат при ошибке записи. Ошибки оформления продолжают блокировать экспорт.
- Для кнопки, созданной только в GUI Designer, добавлен явный режим замены оформления по Control ID. Различия Object ID/контейнера/описания/имён состояний разрешены только при этом выборе; число, ID и порядок состояний обязаны совпадать. Строгий режим и проверка хешей не ослаблены.
- Утилита включена в CLI ZIP вместе с зависимостями и показывает версию 0.8.5. Изменение режима сопоставления сбрасывает старый план и выбранные строки.
