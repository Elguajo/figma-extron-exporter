# Контраст при оформлении кнопок — 23.10.2026

## Причина и исправление

`prepareButtons` переносил с образцов только оформление фона. Белый текст Input 7 и золотая иконка сохраняли исходные цвета на золотом On и становились плохо различимыми.

Добавлена включённая по умолчанию настройка «Исправлять контраст текста и иконок». После создания/обновления состояний каждая изменённая поверхность проверяется отдельно, включая скрытые состояния. Копии создаются до коррекции, чтобы сохранять исходный контрастный цвет другого состояния. Неподходящие однотонные заливки и обводки заменяются чёрным или белым. Пороги: 4.5:1 для всех подписей, 3:1 для графики; формула относительной яркости sRGB из [WCAG 2.2](https://www.w3.org/TR/WCAG22/). Сохраняются содержание, геометрия, имена и ID. Пропущенные готовые кнопки не обрабатываются.

Изображения, градиенты, mixed-заливки текста, маски, эффекты, особые режимы наложения и недостаточная прозрачность учитываются в количестве участков для ручной проверки. Сложные фоны не оцениваются предположительно. Полупрозрачные однотонные foreground-заливки сравниваются после смешивания с непрозрачным фоном; alpha сохраняется. Текст на локальном заполненном Frame сравнивается с его локальным фоном. Изменения цветов входят в общий откат операции.

Совместимость с параллельно добавленным обновлением Pressed: коррекция выполняется для всех состояний, получивших образец, включая Pressed при явном обновлении готовых кнопок. Другие изменения этой работы сохранены.
