# Секции проекта и интерфейс плагина 0.3.2

21.10.2026. Работа выполнена в основной папке `main`, без создания веток/worktree. Существовавшие изменения в исходниках, EXUI и документации сохранены. Commit/push не выполнялись.

## Результат

- Section принимается как корень проекта с произвольным непустым именем, в том числе кириллицей и именами, похожими на префиксы элементов. Внутри — Frame страниц, popup и групп popup. Frame проекты и одиночные экраны совместимы.
- Используются прежние metadata, реестр ID и exui/5. Проверка/экспорт из дочернего элемента разрешают весь родительский проект. Размер и оформление секции не экспортируются; страницы сохраняют локальную геометрию.
- Демо убрано из UI. Библиотека, ручные настройки и справочник свёрнуты. Проверка/экспорт закреплены внизу; показаны выбранный узел и область экспорта. Распознавание выводит компактный список с ключами и ID.
- Кнопка перехода выбирает страницу/popup по имени. Текущий контейнер исключается из целей; недоступный сохранённый ключ остаётся видимым до явного исправления. Переходы по-прежнему исполняет программа управления Extron.
- При обработке команды блокируются действия и поля, после ошибки доступен повтор. Поддержаны Figma theme tokens, клавиатурный фокус и ширина 320 px.
