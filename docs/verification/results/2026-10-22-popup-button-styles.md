# Оформление кнопок внутри popupgroup — 22.10.2026

## Причина и исправление

Панель оформления и команды подготовки использовали только область экспорта. Отдельный `popupgroup_AudioControls` размером 2237×800 без внешнего проекта не определялся как экран; кнопка применения оставалась недоступной. При наличии проекта область могла охватывать соседние контейнеры.

`ExportScope.resolveButtons()` разрешает в режиме выделения ближайший Frame popup или группы по назначению либо префиксу (`popup_`, `pop_`, `modalpopup_`, `mdl_`, `popupgroup_`, `pgrp_`). Предпросмотр плана и команда используют одну область. Отдельный popup ограничивает работу своими кнопками, группа включает вложенные popup. Режимы выбранных экранов и текущей страницы сохраняют свои прежние области. Правила проверки и экспорта не расширены.
