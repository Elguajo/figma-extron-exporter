# Extron Kit: ожидание, доступность и компактный экран — 26.10.2026

Локальная ревизия **2026-10-26-control-feedback**, плагин **0.8.4**, CLI **0.8.3**, EXUI/5. По уточнению пользователя генератор сохраняет Apple-inspired Light; выбора стиля не добавлено. Существующие незакоммиченные исправления геометрии экземпляров сохранены.

## Что добавлено

Раздел 08 создаётся той же командой `createKit(profile)` после существующих разделов 06/07. Общий renderer экранов переиспользует основные компоненты и ограничения геометрии экземпляров. Новых типов управления и зависимостей нет.

- `project_ControlStates`: SystemWaiting, SourceUnavailable и ConnectionLost для выбранного профиля, с Multilevel, обновляемым Value причины, доступной Help и моментарной Retry.
- Ожидающее/недоступное основное действие — `image_UnavailableAction` без controlId. В современные button_/feedbackbutton_ не добавлены неподдерживаемые state_Disabled/state_Waiting. Программа выбирает экран и блокирует повторные команды.
- Отдельный `screen_CompactAudio` 320×480 с Music/HDMI, Mute, Slider/Value и Volume −/+. Он вне проекта выбранной панели; экспортируется с профилем 300M даже при создании 1025M-кита.
- `content.json` — общий каталог текста и двух компоновок для генератора и обновления живого файла. Обложка, ревизия и сообщение об успешном создании обновлены.
