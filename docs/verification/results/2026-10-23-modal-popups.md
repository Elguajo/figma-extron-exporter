# Модальные popup: плагин → GDL → GUI Designer Build → GCP — 23.10.2026

Экспортёр на `fb2004d` (CLI из исходников, включая исправление пустого `Text` из `f21bd48`), GUI Designer **1.28.0.7**, Global Configurator Plus **3.34.1.4**, TLP Pro 1025M. Оборудование не подключалось. Работа в основной папке на `main`.

## Итог

**Модалки работают по всей цепочке до GCP.** После Save and Build ссылки на модалку появляются на каждой странице. GCP показывает модалку в списке страниц и в целях Show Popup / Hide Popup. Все её элементы отрисовываются кодом GCP без ошибок. Полупрозрачное затемнение после Build сохраняется. Дефектов экспортёра не найдено.

Не проверено: поведение на панели (блокирует ли модалка касания страницы под ней, Show/Hide Popup с Timeout на контроллере).

## Как устроено

- **Плагин.** Frame `mdl_`/`modalpopup_` или «Модальный popup: Да» в форме. Размер Frame строго равен холсту панели, иначе экспорт отказывает (`export.ts`). Группа и `popupref` для модалки запрещены (`project.ts`, `popup-binding.ts`, `ScreenSpec.cs`).
- **Фон.** По умолчанию прозрачный (`#00000000`). Общая Opacity Frame игнорируется. С флажком «Экспортировать фон Frame» SOLID-заливка переносится вместе с её прозрачностью (`#AARRGGBB`) в нативный фон popup.
- **Фигуры `shp_`.** Только непрозрачная заливка и Opacity слоя 1; иначе плагин отказывает («opacity не поддержаны»). Альфу несут только фигуры оформления, которые плагин создаёт сам.
- **GDL после конвертации.** `Modal = true`, `HasReferences = false`, ссылок нет — так и задумано.
- **Save and Build.** Добавляет на каждую страницу полноэкранную `PBPopupPageReference` на каждую модалку и выставляет `HasReferences = true`.
- **GCP** (`LayoutAsset`, декомпиляция). Popup попадает в список страниц и в параметр `Popup` команд Show Popup / Hide Popup, только если `IsConfigurable`, не Offline и `HasReferences`. Модалки в списке идут последними, с серой иконкой. Отдельной логики для модалок нет. У Show Popup есть параметр Timeout 0–100 с. Переходы в GDL не хранятся: открытие и закрытие модалки настраиваются только в GCP.

### Две ловушки, найденные по ходу

1. **Порядок цвета `#AARRGGBB`.** В первом пакете затемнение было записано как `#000000B3` (альфа 0) — ошибка тестового пакета, не экспортёра. Build честно отрисовал его прозрачным. Плагин пишет альфу первой (`paint-color.ts`).
2. **Окно «Save and Build Optimization».** Если закрыть его крестиком, GUI Designer сохраняет файл, но Build не выполняется: в GDL нет `.tgz4`, и GCP не может его импортировать (`LayoutNotFound`). Нужно выбрать Keep или Remove.
