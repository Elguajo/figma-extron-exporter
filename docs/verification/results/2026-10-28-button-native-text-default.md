# button_ — редактируемый текст, imagebutton_ — состояние целиком в PNG

Локальное исправление 28.10.2026 поверх 0.8.8, в основной папке репозитория и ветке `main`.

## Причина и контракт

Пользователь подтвердил однозначный выбор по префиксу: `button_` / `btn_` и `feedbackbutton_` / `fbtn_` должны экспортировать подпись как редактируемый Text состояний самого Button. `imagebutton_` / `ibtn_` сохраняют состояние целиком в PNG, включая подписи. Ранее обычная кнопка могла оставить текст в PNG либо создать отдельный статичный Label; для текста самого Button требовалось отдельно применить команду. Это не соответствовало требованию.

Теперь обычным кнопкам не требуется отдельное действие для включения редактируемого текста. Поддержана одна непустая видимая подпись на состояние, включая вложенный Artwork; пустые заполнители игнорируются. Состояния без подписи и кнопки только с иконкой не требуют пустого Text. Фон и иконки могут оставаться PNG; подпись исключается только из временной копии для рендера. Отдельный Label больше не создаётся.

Несколько непустых Text, неподдержанный шрифт, маски и преобразования в цепочке подписи дают ошибку с предложением `imagebutton_` / `ibtn_`, без скрытой растеризации. Шрифт остаётся общим для состояний, цвет и содержимое могут различаться. Преобразованное оформление без нативного текста покрывается imagebutton-тестами.

По умолчанию текст располагается по центру; Bottom сохраняется для текстовой рамки на всю кнопку. Явные сохранённые Auto / Middle-Center / Bottom-Center совместимы. Сброс выравнивания теперь возвращает нативный текст. Произвольные координаты текста в GDL не обещаются. Раздел UI переименован в «Выравнивание текста кнопок» и больше не описывает применение команды как условие редактируемого текста.

Нового поля в metadata не добавлено; ID, типы и состояния не мигрируют. При смене только префикса с сохранением окончания имени идентификаторы остаются прежними. Старые EXUI/GDL/GCP не изменяются автоматически; необходим новый экспорт. Пакеты EXUI/5 и CLI не менялись.

## Реализация

- `src/figma-plugin/src/button-native-text.ts`: нативный режим по умолчанию, совместимость сохранённого выравнивания и явные ошибки неподдержанных подписей.
- `src/figma-plugin/src/button-artwork.ts`: удалён старый выбор между PNG и нативным текстом по геометрии; вложенные подписи и кнопки без Text корректно проходят через экспорт оформления.
- `src/figma-plugin/src/export.ts`: удалено создание отдельного caption Label; обычная подпись записывается в Text Button и исключается из временного PNG. Выделение ID для декораций popup сохранено.
- UI, документация и тесты приведены к выбору через префикс. Прежние проверки отдельных caption Label заменены проверками нативного текста самой кнопки; проверки статичного Inter Label сохранены.
