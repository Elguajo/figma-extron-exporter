# Проверка имён экранов и переходов — плагин 0.8.6

Дата: 26.10.2026. Плагин 0.8.6, CLI/утилита обновления 0.8.5, EXUI/5.

## Причины и исправление

У копии `screen_AudioControl`, переименованной в `screen_VideoControl`, сохранялось унаследованное `projectName`. Распознавание теперь предлагает имя нового Frame до записи, а при сохранении выдаёт копии собственные назначения. Автоматические имена существующих экранов следуют переименованию; пользовательские имена оригиналов сохраняются. Имя общего проекта продолжает браться из файла Figma.

В режиме выбранных фреймов список целей строился только из запомненного состава проекта. Новый соседний экран не входил в него. Теперь соседние экраны того же профиля доступны с пометкой «добавить в проект». При сохранении кнопки выбранная цель проверяется по Figma node ID, получает актуальный ключ и входит в запомненный экспорт. Остальные соседи не добавляются. Просмотр цели на холсте не расширяет проект. Экраны другой секции/проекта и другого размера не предлагаются. Внутри уже выбранной секции её экраны доступны через обычный список целей.

Используется существующая транзакция распознавания: ошибка макета, удалённая/перемещённая цель, другой размер панели или сбой записи не оставляют частичных назначений. Просмотр и список целей не записывают назначения. Черновик связей повторно используется для формы, сохраняя бюджет одного снимка проекта на выбор слоя.
