# Выпуск 0.8.1 — 25.10.2026

Решение: **SHIP WITH KNOWN RISKS**, preview. Парный выпуск **плагин 0.8.1 + CLI 0.8.1**, контракт **EXUI/5**. Версия Windows-утилиты обновления в исходниках также 0.8.1; отдельный архив этой утилиты не выпускается. Работа выполнена в основной папке на `main`, без веток и worktree.

## Изменения и причина четырёх сбоев

Выпуск включает нативный текст состояний Button для GCP, команды обновления компоновки и изменения 0.8.0. Версии согласованы в package.json/lock, UI, проектах CLI/updater и текущей документации.

Четыре прежних сбоя воспроизведены со стеком вызовов: подготовка тестов вызывала `NrbfDocument.Get(node, "userIdField")`, предполагая одно поле, хотя Extron хранит ID в нескольких уровнях наследования. Сбой возникал до проверки результата обновления. Тесты теперь читают все копии ID, требуют их согласованности и обновляют все копии при создании ручной страницы. Проверки сохранения соседней кнопки/ручной страницы и запрета несовместимой замены проходят для обеих панелей. Код конвертера и обновления компоновки не менялся.

Тестовый раннер печатает полный стек ошибки. Архивная проверка нумерации берёт текущую версию из package.json. Тест старого плагина 0.2.1 поддерживает исходное расположение архива и каталог Legacy; отсутствие архива по обоим путям остаётся ошибкой.

- Figma API/PNG в автоматических сценариях моделируются; CLI использует настоящий генератор Extron и независимый reader.

- Блокирующих автоматических сбоев после исправления подготовки тестовых данных не осталось. Для снятия указанных ограничений требуется отдельный ручной цикл в Extron/GCP и на панели.
