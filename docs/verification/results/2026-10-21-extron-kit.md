## Обзор изменения и ограничения

Проверены изменённые пути `kit.ts → recognize → capture/nativeElement → exportFrame`, транзакционная запись назначений, UI busy/selection, упаковка и совместимость с существующими сценариями. Ошибка отсутствующих popupref в первом шаблоне проекта исправлена добавлением двух ссылок: отдельный popup и группа зон. Служебная подсказка группы входит в сигнатуру, поэтому изменение цели инвалидирует отчёт распознавания. Ручная форма не позволяет назначить экземпляр компонента внешним проектом/страницей: для структурных контейнеров остаётся обязательным обычный Frame.

Полностью произвольный дизайн **внутри каждого типа** ещё не реализован. В Artwork кнопки/картинки он поддержан; Slider/Level/Shape/Line/Text/Value/DateTime используют прежние нативные ограничения. PNG-лимит остаётся 16 на весь проект. Копии уже назначенных узлов не переназначаются автоматически. В pen.dev Inter, для нативных текстов Figma Arial. Эти ограничения отражены в EXTRON_KIT.md.

Пользователь не использует платный Figma MCP; отдельную копию `.fig` сохранять не просит, кит должен остаться в Figma. Обратный экспорт pen.dev в `.fig` не подтверждён; выбран локальный development-плагин. Никакие Figma MCP вызовы не выполнялись. Пользователь создал файл Extron Kit (`Oc7Y0RTUweZQMGvlVCDerX`) и импортировал локальный manifest. Через Windows UI запущен плагин 0.3.0, создан кит, распознан и экспортирован пример. Настоящий API обнаружил два расхождения с первоначальной моделью: запрещена привязка componentPropertyReferences на дочернем слое SLOT; переименование SLOT-свойства автоматически меняет имя слоя. Оба случая исправлены в генераторе/распознавании и отражены в тестовой модели. При первой ошибке комплект был полностью убран транзакционным откатом; повторный запуск создал один комплект. Скриншоты: `2026-10-21-extron-kit/figma-desktop-screen.png`, `figma-desktop-resize.png`.

Оставшаяся реальная проверка: произвольное редактирование Artwork/Label с наследованием и локальными overrides в Figma; GUI Designer Verify/Build → Global Configurator Pro → устройство. Реальное создание второго размера 300M в Desktop пока не проверено; автоматические и CLI-проверки обоих размеров пройдены.
