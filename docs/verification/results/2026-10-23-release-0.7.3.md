## Изменения

- Под «Оформление кнопок» добавлен независимый блок «Нумерация кнопок»: основа имени, начальный номер, предпросмотр, два режима, независимое изменение имён и подписей.
- Порядок слева направо, сверху вниз; отдельный счёт в каждом непосредственном родителе, включая вложенные группы/фреймы. Область ограничена текущим выделением. Невыбранные соседние кнопки резервируют номера и не меняются.
- Исправление повторов сохраняет занятые номера выбранной основы, отдаёт приоритет оригиналам над копиями и выдаёт свободные номера копиям и кнопкам без номера этой основы.
- Подписи обновляются во всех состояниях, включая скрытые. Неоднозначная подпись, смешанное оформление внутри Text и недоступный шрифт останавливают подготовку до записи. Смена макета/выделения требует нового предпросмотра; есть кнопка его обновления.
- Metadata и реестры ID команда не перезаписывает. ID объектов, управления и состояний сохраняются при следующем распознавании и конвертации. Автоматические ключи следуют новым именам, ручные сохраняются.
- CLI 0.7.3 — парный выпуск с прежним конвертером. EXUI/5, metadata schemas и plugin ID не менялись. Сохранены выбор пары состояний и Override из 0.7.2.

Подробности реализации и её ограничения: [нумерация кнопок](2026-10-23-button-numbering.md).
