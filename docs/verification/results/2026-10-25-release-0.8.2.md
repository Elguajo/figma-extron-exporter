- Путь выборочного обновления проверен в копии реального проекта GCP ([протокол](2026-10-25-gcp-selected-update.md)); анализ ручных ID — [отдельно](2026-10-25-gcp-missing-button-ids.md).

## Найдено при проверке и исправлено

- **GDL в контейнере `PK`.** Рабочий GDL, сохранённый не GUI Designer (обычная сигнатура ZIP `PK` вместо `KP` у GUI Designer), CLI не читает: `Missing KP end record…`. Чтение не менялось; инструкция указывает брать GDL, сохранённый GUI Designer, и объясняет ошибку.
- **Ошибки CLI в PowerShell.** Без проверки `$LASTEXITCODE` последовательность команд продолжалась после ошибки и выдавала путаные сообщения. В инструкцию добавлены остановки; сообщения `throw` на ASCII, так как Windows PowerShell 5.1 читает `.ps1` без BOM в ANSI и ломается на кириллице.

- Figma API и PNG в автоматических сценариях моделируются; CLI использует настоящий генератор Extron и независимый reader.
