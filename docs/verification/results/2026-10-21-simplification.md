# Последовательное упрощение плагина и текущего EXUI

21.10.2026. Работа выполнена непосредственно в основной папке на `main`, без новой ветки или worktree. Исходные незакоммиченные изменения сохранены, включая подробную диагностику распознавания. Плагин **0.3.7**, CLI **0.4.0**.

## Изменения

1. `assignment-rules.ts` задаёт общие требования к типам узлов для ручных назначений и распознавания, включая состояния, изображения и контейнеры. Синонимы состояний находятся в одном словаре `stateRole`.
2. `scope.ts` владеет режимом, профилем, запомненными выбранными экранами и разрешением области экспорта. Обработчики и сообщения UI получают один вычисленный контекст. Сохранены секции, Frame-проекты, выбранные фреймы, текущая страница, работа из дочернего элемента и возврат из отчёта ошибок.
3. `MetadataInput`/`Metadata` требуют поля соответствующего типа: профиль/имя страницы, роль/ID состояния, путь изображения, ID активного контрола; пассивный элемент имеет `controlId: null`. Ручная форма создаёт полное назначение в каждой ветке. Формат сохранённых plugin data не менялся. Compile-time проверки в `test/metadata-types.ts` входят в обычный typecheck.
4. `applyRecognition` возвращает описание после записи и проверки. Команда check использует его напрямую, export передаёт его в `exportCaptured`. Описание не кэшируется между командами. Проверки актуальности выполняются до и после PNG; подпись включает родителя, абсолютную геометрию и transform. Проверка черновика перед записью, проверка результата записи, откат и резервы ID сохранены.
5. По прямому уточнению пользователя поддерживается только текущий EXUI/5. Producer всегда пишет `/5`; reader принимает только `/5`. Из CLI удалены выбор схемы 1–4, встроенные старые схемы, параметры `allowTwoStateButtons`, `allowGraphics`, `allowMomentaryButtons`, `allowExtended` и связанные ветвления. Исторические схемы, примеры и архивы сохранены в репозитории как материалы исследования. Старый ZIP нужно экспортировать заново из исходного макета Figma. Сохранённые ключи и ID не сбрасываются.

## Границы доказательства

Figma API и PNG в автоматических main/native-тестах моделируются существующими fixtures; Chromium исполняет настоящий упакованный UI с моделируемым bridge. CLI, x86-host, доноры, Extron writer и независимый NRBF-reader настоящие. Новый ручной цикл Figma Desktop → GUI Designer Verify/Save and Build и физическое устройство для этой сборки не выполнялись. Результат остаётся preview; автоматические результаты не обозначены как проверка GUI Designer или оборудования.
