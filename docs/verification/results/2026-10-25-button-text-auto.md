# Автоматическое положение текста Button — плагин 0.8.2

## Решение

Режим `auto` в существующем `exui-button-native-text` вычисляет положение при каждом capture/export. Используется центр прямоугольника Text относительно состояния, с округлением существующей функцией rect. Ближайшая середина даёт Middle-Center; ближайший низ — Bottom-Center. Ближайший верх и равные расстояния отклоняются. Прямоугольник должен находиться внутри кнопки. Figma paragraph alignment (по обоим направлениям) намеренно игнорируется по уточнению пользователя: горизонтальное положение в GDL всегда Center. Полноразмерный Text даёт Middle-Center независимо от его внутреннего выравнивания.

Два варианта — ограничение экспортёра, а не GUI Designer. Проверено чтением установленного `Extron.GUICPro.Layout.Contracts.dll`: AlignmentEnum содержит BottomCenter, BottomLeft, BottomRight, MiddleCenter, MiddleLeft, MiddleRight, TopCenter, TopLeft, TopRight и None. Справка GUI Designer `Help/Content/HTML_Files/Window_Modules/Properties/Appearance.htm`, раздел Button, описывает Text и Text Alignment как свойства кнопки. Справка GCP `Help/Content/HTML_Files/Config_Palette/User_Interfaces.htm`, раздел Button Feedback, описывает Text Feedback для объекта. Отдельный Label не превращается в текст Button из-за изменения выравнивания.

Автоматический режим включается одним применением к выделенным кнопкам / экрану / popup. Старые режимы и экспорт без настройки не меняются. Новые кнопки включаются повторным применением к области. Слои не перемещаются, ID не меняются. Текст исключается из временного PNG и записывается в состояния Button через существующий путь. Не добавлены API, зависимости или изменения схемы EXUI/5; CLI 0.8.1 остаётся совместимым. Сохранённый `auto` требует плагин 0.8.2: перед возвратом к старому плагину нужно применить ручное положение или отменить настройку.

Figma API/PNG в тестах моделируются. Проверка замены текста выполнена CLI, не живым GCP. Открытый пользовательский импорт GCP и ранее построенный GDL не изменялись. Метаданные живого документа Figma этим изменением автоматически не переписаны. Development build обновлён обычной сборкой; следующему запуску плагина доступен режим auto.

## Проверка кода и готовность

Проверен diff button-native-text.ts, message handler, UI, тесты и версия архива. Основной риск — принятие Figma paragraph alignment за позицию текста на Button — устранён явным игнорированием абзаца. Защиты preflight/rollback и signature во время PNG-экспорта переиспользованы. Связанные проверки ручных режимов сохранились. Значимых дефектов при ревью не выявлено.

Решение: SHIP WITH KNOWN RISKS для плагина 0.8.2. Автоматически определяется положение рамки, а не пиксельная геометрия глифов; произвольные отступы не воспроизводятся. Нет новой проверки физической панели или живого GCP; это остаётся границей доказательств.
