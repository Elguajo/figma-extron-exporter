# imagebutton_ / ibtn_ — 27.10.2026

## Контракт и реализация

По согласованному требованию карточки с произвольным расположением текста используют `imagebutton_` / `ibtn_`. Каждое состояние целиком экспортируется в PNG: фон, иконки и подписи. Нативный Text Button пустой, служебный Label для подписи не создаётся. Сама кнопка сохраняет управляющий ID, действия и состояния. Подпись изменяется в Figma с повторным экспортом; Text Feedback не заменяет текст, нарисованный в PNG.

Основание: до реализации прочитан пользовательский `interface-tlp-pro-1025m-v3.gdl`, а свойства Video Control проверены в открытом GUI Designer. Video Control / Audio Control / Scenario — PBButton с ID 8130 / 8131 / 8132, двумя состояниями Off / On, пустым Text и PNG целиком по размеру кнопки. Извлечённые из GDL preview содержат фон, иконку и подпись. Этот GDL при проверке не изменялся.

Префикс определяется по текущему имени при capture/export, имеет приоритет над сохранённым нативным режимом (`auto`, Center, Bottom Center) и запрещает как извлечение текста в Button, так и создание отдельного Label. Команды настройки текста пропускают imagebutton во всех режимах, сохраняя старую настройку для обратного переименования. Слои, private metadata и ID автоматически не переписываются. Новые imagebutton используют обычный buttonMode on-off; у переименованных существующих кнопок сохраняется назначенный тип, включая feedback и Pressed. Подготовка, выделение области и нумерация принимают оба префикса. EXUI/5 и CLI не менялись.
