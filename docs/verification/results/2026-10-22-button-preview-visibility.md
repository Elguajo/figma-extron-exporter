# Автоматическая видимость состояний кнопок — 22.10.2026

Плагин 0.5.5, совместимый CLI 0.5.2, EXUI/5. Работа выполнена в основной папке на main, прежние изменения сохранены.

## Причина и исправление

Распознавание выполняло capture до сохранения назначений. Проверка требовала ровно одно видимое состояние и блокировала Passive/Active с двумя видимыми слоями, хотя PNG экспортируются по отдельности для всех состояний.

Распознавание теперь составляет план изменения видимости только для Button. План проходит прежнюю проверку через отдельное чтение будущей видимости, не меняя Figma. При сохранении назначений, проверке или скачивании изменения применяются вместе с metadata; повторный capture использует фактическую видимость. Сбой откатывает изменённую видимость, назначения и реестр. Изменение макета после распознавания по-прежнему отклоняет устаревший план.

Если видны несколько состояний, приоритет у обычной роли среди видимых; иначе остаётся первое видимое. Если скрыты все, показывается обычная роль. Единственное видимое состояние сохраняется. Сохранённая роль имеет приоритет над переименованием слоя. Остальные слои, имена, оформление, ключи/ID и все экспортируемые состояния сохраняются. Правила Multistate Level не меняются.
