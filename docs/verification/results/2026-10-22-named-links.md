Дата: 22.10.2026. Предыдущие изменения сохранены и отправлены в main первым коммитом `95620b5`; этот отчёт относится к следующей части.

## Реализация и решение

Используются существующие metadata EXUI и атомарная запись назначений/резерва ID. Новая схема хранения, зависимость или изменение CLI не потребовались. `authoring-links.ts` строит доступные цели из плана распознавания текущего проекта, но просмотр не применяет этот план. Сохранение записывает только затронутые назначения и необходимые новые предки.

- Popupref: выбрать готовую группу или одиночный popup, заменить/снять связь, увидеть сохранённых участников и показать их на холсте. Предлагаются только цели нужных размеров/профиля; групповые popup не предлагаются как отдельная цель. Frame не перемещаются и не удаляются. Для создания новой организационной группы из отдельных popup остаётся существующий поток «Размещение popup».
- Кнопки: создать группу выбора из кнопок одной страницы/popup, присоединить к готовой группе, снять назначение. Ключ генерируется; другие behavior-поля и ID сохраняются. Группа остаётся указанием в карте ID для управляющей программы.
- Запуск: выбрать страницу проекта по имени и сохранить единственную стартовую страницу. Состав выбранного проекта ограничивает изменяемые страницы.
- Переход: показать выбранную цель кнопки на холсте. Нет записи незаписанной формы; удалённая/чужая цель не выбирается.

Поля ручных ключей popup доступны в раскрываемом блоке. Все новые списки сохраняются явно кнопками, после перезапуска данные восстанавливаются из pluginData. Совместимость: plugin 0.6.5, CLI 0.6.3, EXUI/5; plugin ID и схемы metadata сохранены.
