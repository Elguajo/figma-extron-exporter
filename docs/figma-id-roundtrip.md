# Сопоставление GDL и обратная карта ID — 0.8.7

Экспорт Figma не обязан заранее иметь ID существующей кнопки GUI Designer. LayoutUpdater связывает старую кнопку с новой по выбору пользователя, переносит оформление в исходную структуру и сохраняет карту для обратного назначения ID в Figma.

## Рабочий процесс

1. Экспортируйте EXUI плагином 0.8.7. Откройте в LayoutUpdater рабочий GDL и этот EXUI.
2. Нажмите «Сравнить». Выберите соответствия в столбце «Новая кнопка Figma», затем отметьте строки для применения. Для группы выделите старые строки и используйте «Связать выделенные по порядку…». Порядок группового связывания показан в диалоге; перед сохранением проверьте основную таблицу и превью.
3. Сохраните новый GDL и «Карта ID → Figma…». В плагине на исходной странице откройте карту через блок «Назначения Extron», проверьте номера до/после и нажмите «Применить ко всем».
4. Следующий EXUI содержит исходные ID GUI Designer. Через «Загрузить соответствия…» можно повторно открыть ту же карту в LayoutUpdater: источники будут найдены по слоям, даже если их управляющие номера уже изменились после импорта.

Число, ID и порядок состояний обязаны совпадать. Имена состояний могут различаться при явном связывании. Обновление сохраняет ID, контейнер, имя, описание, состояния и поведение рабочего GDL; положение и размеры переносятся отдельной настройкой. Проверка GCP и устройства выполняется отдельно.

## Контракты и совместимость

- EXUI/5 допускает необязательное `manifest.figma = {path:"figma.json", sha256:"…"}`. Файл ограничен 128 КиБ, проверяется SHA-256, JSON Schema и точное соответствие кнопкам screen.json. Необъявленные/лишние ZIP entries по-прежнему отклоняются.
- `exui-figma-origin/1` содержит pageId, постоянный pageToken исходной страницы, имя проекта и строки nodeId/key/controlId/name. Токен хранится в отдельном pluginData `exui-figma-origin-token`; существующие назначения не мигрируют и не сбрасываются.
- `exui-layout-selection/1` дополнен необязательным `bindings: [{controlId, sourceControlId}]`. Первый ID — существующая кнопка рабочего GDL, второй — новая кнопка. Ноль в sourceControlId означает явно снятую связь при сравнении. Применение требует ненулевых выбранных источников и не допускает повторного использования одной новой кнопки в выбранной группе.
- `exui-figma-id-map/1` содержит profile/pageId/pageToken/projectName и entries с nodeId/key/sourceControlId/controlId/name. sourceControlId — номер экспортированного слоя; controlId — целевой номер GUI Designer.
- CLI 0.8.7 читает прежние EXUI/5 без provenance. Старые CLI отклоняют новое расширение: используйте согласованные версии 0.8.7. Генерация GDL не использует provenance, схемы exui-node/1–3 не меняются.

## Проверки импорта и откат

Предпросмотр не записывает данные. Импорт требует точного исходного nodeId, владельца metadata, ключа и страницы. Текущий ID должен совпадать с исходным либо уже целевым, поэтому повторное применение идемпотентно. Копии/удалённые/изменённые назначения не угадываются по имени. Коллизии проверяются в проектах связанных кнопок по конечному состоянию всей группы; обмен номерами допустим, занятый номер вне группы блокирует весь импорт.

Перед записью проверяется снимок назначений/реестров. Записи синхронны; при ошибке плагин восстанавливает прежние metadata и реестры. Неполный откат выдаёт отдельную ошибку и оставляет резерв ID. Figma не предоставляет транзакции для нескольких pluginData; абсолютная атомарность не заявляется. Для полного дубликата файла с теми же nodeId и pluginData происхождение унаследовано; токен не является криптографической аутентификацией документа.
