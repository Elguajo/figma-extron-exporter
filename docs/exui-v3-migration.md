# Совместимость кнопок Off/On

Изменение поставляется с плагином 0.1.4 и текущей сборкой CLI. Metadata/1 не мигрируют, отдельный реестр резервирования ID добавляется при сохранении распознавания. [Подробные инварианты и восстановление](figma-naming-implementation.md).

| Producer / документ | Текущий CLI | Старый CLI с v1/v2 |
|---|---|---|
| Прежний пакет exui/1, три состояния | Читается как раньше | Читается как раньше |
| Прежний пакет exui/2, страницы и popup | Читается как раньше | Читается как раньше |
| Плагин 0.1.4, все кнопки с Pressed | Выдаёт и читает exui/1 | Читается как раньше |
| Плагин 0.1.4, есть кнопки Off/On без Pressed | Выдаёт и читает exui/3 | Отказ по неизвестной версии |

Обновить локальную сборку CLI перед конвертацией exui/3. Исходники, доноры и прежние пакеты не заменяются. Все результаты конвертации — новые файлы; merge с вручную отредактированным GDL отсутствует. Возврат к старому плагину не удаляет реестр и metadata, но не обеспечивает поддержку двухсостояниевых кнопок. Из двух состояний автоматически не создаётся третье ради совместимости.
