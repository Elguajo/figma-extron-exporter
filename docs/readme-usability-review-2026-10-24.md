- `git diff --check` для затронутых инструкций прошёл. Код плагина и конвертера в этой задаче не менялся; продуктовые тесты заново не запускались.

## Что остаётся за пределами редакторской проверки

Установка CLI всё ещё зависит от эталонного GDL, которого нет в публичном комплекте. Инструкция настройки честно описывает необходимый файл и отсутствие общедоступной ссылки. Перенос этой информации из README улучшает фокус, но не устраняет зависимость продукта.

Для проверки самостоятельности первого запуска нужен человек, ранее не пользовавшийся плагином: он должен без подсказок пройти быстрый старт на собственном небольшом экране и назвать места, где пришлось угадывать. До такого прогона нельзя утверждать, что onboarding проверен пользователем или полностью устраняет затруднения.
