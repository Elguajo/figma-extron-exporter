- [Префиксы и подготовка макета](figma-extron-prefix-cheatsheet.pdf): 5 страниц, 22 типа, состояния и popup, схемы текста с иконкой.

- [Локальная веб-документация](../web/index.html): поиск, фильтр префиксов, пошаговые сценарии и оба PDF. Открывается из файлов без сервера после сборки.

Для новых кнопок с иконкой принят вариант: нативный текст по центру **всей кнопки**, иконка слева или справа внутри Artwork. Настройку «По центру» применяют явно; это рекомендация авторинга, без автоматической смены существующих макетов. Подробности и границы проверки: [NATIVE_TEXT](../../src/figma-plugin/NATIVE_TEXT.md), [протокол](../verification/results/2026-10-25-product-guides.md).

## Обновление файлов

Из корня репозитория, Python + ReportLab:

```powershell
python docs/verification/Generate-PrefixGuide.py
python docs/verification/Generate-UseCases.py
npm run build --prefix docs/web/extron-kit-docs
npm test --prefix docs/web/extron-kit-docs
```

Первый генератор также обновляет `prefix-data.json`, который использует сайт. Сценарии и правила компоновки для PDF и сайта берутся из одного `guide-data.json`. Версии берутся из `src/figma-plugin/package.json`. PDF используют Arial / Consolas из Windows Fonts; сайт содержит локальные Inter WOFF2.

После изменения PDF отрисуйте все страницы через Poppler и визуально проверьте таблицы, схемы, кириллицу и команды. Публикуемые архивы прежних выпусков не переписываются: внутри них остаётся документация на дату выпуска.
