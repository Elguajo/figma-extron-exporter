# Figma > Extron: таблица префиксов

Плагин 0.2.0 / стандарт 2.0 / 20.10.2026.

Короткий и полный префиксы равнозначны, регистр не важен. Примеры: button_VolumeUp и btn_volumeup. После префикса нужно уникальное имя назначения внутри экрана. Поэтому рядом со slider_Volume использовать value_VolumeValue. Сохранённые ключи и ID при переименовании не меняются.

## 1. Экраны и структура

| Сущность | Для чего нужна в твоём проекте | Что у нас сейчас / что добавить |
|---|---|---|
| Проект: `prj_Trilliant` / `project_Trilliant` | Объединить весь интерфейс в одном экспорте: Home, настройки, popup. | Реализован экспорт из Figma. Внутри Frame проекта находятся страницы, popup и группы. |
| Страница: `Home`, `scr_Home` / `screen_Home` | Отдельные экраны Home, Hall, Terrace, Settings. | Реализовано. Каждая страница - Frame точного размера панели. В проекте ровно одна стартовая страница. |
| Popup: `pop_Sources` / `popup_Sources` | Открыть выбор источника или настройки, сохранив основной экран. | Реализовано. Свой размер; на странице нужен popupref того же размера. |
| Модальный popup: `mdl_Confirm` / `modalpopup_Confirm` | Показать подтверждение, например «Выключить систему?». | Реализовано. Полноэкранный popup без группы; modal можно также задать в форме. |
| Группа popup: `pgrp_Zones` / `popupgroup_Zones` | Менять содержимое одной области между Hall и Terrace. | Реализовано. Внутри - обычные popup одинакового размера. Группа взаимоисключающая, её Frame - организационная обёртка. |
| Место popup: `pr_Sources` / `popupref_Sources` | Задать область страницы, в которой появится popup. | Реализовано. Пустой Frame; автоцель popup.sources. Через форму можно указать группу вместо popup. |

## 2. Управление и индикаторы

| Сущность | Для чего нужна в твоём проекте | Что у нас сейчас / что добавить |
|---|---|---|
| Кнопка: `btn_Music` / `button_Music` | Выбор источника, команды устройства, переход к экрану. | Реализован PBButton с 2-8 состояниями. Действие и переход исполняет программа Extron по карте ID. |
| Громкость «+»: `btn_VolumeUp` / `button_VolumeUp` | Увеличивать громкость; жёлтый вид во время удержания. | Реализованы Normal / Pressed. Цвет Pressed рисует дизайнер. Шаг и повтор при удержании задаёт программа. |
| Громкость «-»: `btn_VolumeDown` / `button_VolumeDown` | Уменьшать громкость с визуальным нажатием. | Реализованы Normal / Pressed. После отпускания кнопка возвращается в обычный вид. |
| Mute: `btn_Mute` / `button_Mute` | Показывать включённое заглушение звука. | Реализованы Off / On и вариант с Pressed. Постоянный On выбирается по обратной связи устройства. |
| Кастомный Slider: `sld_Volume` / `slider_Volume` | Регулировать громкость круглым бегунком на цветной дорожке. | Реализован нативный PBSlider. Внутри Track, Fill, Thumb; цвета, размеры, скругление дорожки, направление и диапазон. |
| Простой Level: `lvl_Volume` / `level_Volume` | Простой регулятор без собственных частей Track/Fill/Thumb. | Реализован PBLevel в режиме Slider. Пустой Frame с заливкой; диапазон и направление задаются формой. |
| Gauge: `gau_Signal` / `gauge_Signal`; `ind_Status` / `indicator_Status` | Показывать уровень сигнала или другое числовое значение. | Реализован режим Gauge у PBLevel. indicator_ - тот же тип отображения, не отдельная кнопка или лампа. |
| LED-шкала: `led_Audio` / `volumeled_Audio` | Показывать уровень аудио сегментами. | Реализован экспорт PBLevel VolumeLED. Фактический вид и работу на панели нужно проверить отдельно. |
| Multistate Level: `mlvl_Status` / `multilevel_Status` | Показывать несколько дискретных состояний индикатора. | Реализован PBLevel MultistateLevel с 2-8 состояниями. Первый Normal, остальные feedback; без Pressed. |

## 3. Текст и графика

| Сущность | Для чего нужна в твоём проекте | Что у нас сейчас / что добавить |
|---|---|---|
| Статичный текст: `txt_Title` / `text_Title` | Заголовок Hall, подписи секций и пояснения. | Реализован редактируемый PBLabel без управляющего ID. Text, Arial Regular/Bold, LEFT/CENTER. |
| Динамическое значение: `val_VolumeValue` / `value_VolumeValue` | Обновлять «42%», имя источника или состояние подключения. | Реализован PBLabel с dynamicText и управляющим ID. Связь со Slider и обновление задаёт программа. |
| Дата/время: `dt_Clock` / `datetime_Clock` | Показывать часы и дату на главном экране. | Реализован PBDateTime. В Text или форме задаётся формат HH:mm либо dd.MM.yyyy HH:mm. Время и часовой пояс проверить на панели. |
| Логотип: `logo_Company` | Разместить фирменный знак отдельным объектом. | Реализован PBImage из PNG с прозрачностью. Положение и ресурс редактируются; внутренние векторы становятся пикселями. |
| Картинка: `img_Photo` / `image_Photo` | Фото, иллюстрация, статичная обложка или фон. | Реализован отдельный PBImage. Frame с графикой экспортируется в один PNG Native 1x. |
| Иконка: `Icon`, `ico_Music` / `icon_Music` | Добавить значок внутри состояния кнопки или Multistate Level. | Реализован PNG-ресурс состояния. Это вложенный Frame, не отдельный интерактивный объект. |
| Фигура: `shp_Card` / `shape_Card` | Сохранить фон карточки или рамку редактируемой. | Реализован PBShape: прямоугольник/эллипс, заливка, единый radius, одна внутренняя SOLID-обводка. |
| Линия: `ln_Divider` / `line_Divider` | Разделить секции интерфейса. | Реализован PBLine. Frame/Rectangle без скругления и обводки; меньшая сторона задаёт толщину. |

## 4. Состояния, поведение и ограничения

| Сущность | Для чего нужна в твоём проекте | Что у нас сейчас / что добавить |
|---|---|---|
| Исходный вид: `Normal` / `Off`; `st_Normal` / `state_Normal` | Обычный вид кнопки до нажатия. | Реализована роль normal, ID 0. Не добавлять одновременно Normal и Off. |
| Обратная связь: `On` / `Feedback`; `st_On` / `state_On` | Показывать Mute или выбранный источник. | Реализована роль feedback. On/Off показывает реальное состояние, которое сообщает программа. |
| Нажатие: `Pressed`; `st_Pressed` / `state_Pressed` | Сделать VolumeUp/Down жёлтыми, пока кнопку держат. | Реализована отдельная роль pressed. После отпускания возвращается исходный вид или текущая обратная связь. |
| Дополнительные виды: `st_Ready` / `state_Ready`, `state_Error`, `state_Disabled` | Показывать готовность, ошибку или недоступность. | Реализовано до 8 состояний всего и preview каждого по имени/ID. Disabled задаёт внешний вид; блокировку выполняет программа. |
| Группа выбора, доступность, видимость: свойства в форме, префикса нет | Выбирать один источник, запрещать или скрывать элемент при запуске. | Экспортируются указания в id-map для программиста. Сам GDL их не исполняет; состояния и управляющие ID уже доступны. |
| Видео: `vid_Preview` / `video_Preview` | Показывать живой видеосигнал. | Зарезервировано. Для профилей 1025M/300M явная ошибка. Нужны подходящий профиль, эталон и отдельная реализация. |
| Динамическая картинка: `dimg_Cover` / `dynamicimage_Cover` | Обновлять обложку или изображение по URL. | Зарезервировано. Для наших профилей явная ошибка. Статичную картинку можно экспортировать через image_. |

Экспорт: выбрать внешний Frame экрана/проекта и профиль, распознать имена, проверить таблицу, сохранить назначения, проверить экран, скачать .exui. Новые функции требуют текущего CLI с exui/5 и актуального реестра доноров. Старые пакеты exui/1-4 поддерживаются.

Проверки нативного конвертера и браузера выполнены автоматически. Настоящий Figma 0.2.0, открытие/Build новых GDL в GUI Designer и оборудование пока не проверены. Оформление Slider ограничено сплошными цветами и описанными в стандарте скруглениями; изображения Track/Thumb и сложные эффекты не входят в текущий вариант. Программа управления отдельно задаёт команды, feedback, начальное значение Slider и форматирование динамического текста.

Основания: [полный стандарт](../src/figma-plugin/AUTHORING_STANDARD.md), [схема пакета](exui-v5.md), [протокол проверки](../verification/results/2026-10-20-expanded-controls.md).
