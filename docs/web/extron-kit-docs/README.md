# Extron Kit - локальная документация

**Плагин 0.8.4 + CLI 0.8.3**, EXUI/5. Документация обновлена 25.10.2026; визуальная ревизия кита остаётся `2026-10-24-av-patterns`.

Откройте [docs/web/index.html](../index.html) двойным щелчком в Проводнике. Готовый сайт находится в `dist/`: поиск, фильтр префиксов, 5 подробных сценариев, примеры текста с иконками, 30 семейств компонентов, 28 форматов времени и скачивание двух PDF работают без сервера. Шрифты, данные, изображения и файлы скачивания лежат внутри `dist/`; CDN и сетевые API не используются. Внешние ссылки на источники требуют интернета.

## Сборка

Нужен Node.js >= 22.18 и установленные зависимости плагина (`npm ci --prefix src/figma-plugin --ignore-scripts`). Зависимостей npm у сайта нет. Из корня репозитория:

```powershell
npm run build --prefix docs/web/extron-kit-docs
npm test --prefix docs/web/extron-kit-docs
```

Сборка создаёт игнорируемую папку `docs/web/extron-kit-docs/dist/`. Если менялись сценарии / префиксы, сначала пересоздайте PDF по [инструкции](../../prefix_map/README.md). Затем снова откройте `docs/web/index.html`. Для переноса на другой компьютер достаточно скопировать всю папку `docs/web` вместе с `dist`.

Готовые архивы плагина и CLI берутся из `releases/figma-plugin/0.8.4/` и `releases/cli/0.8.3/`. Архивы исключены из Git: на новом checkout их нужно скачать из соответствующих выпусков и положить туда до сборки сайта. Они копируются без изменения байтов. Новые PDF предлагаются отдельно; архивы выпусков не переупаковываются.

Необязательный сервер для проверки в браузере:

```powershell
npm run preview --prefix docs/web/extron-kit-docs
```

Откройте `http://127.0.0.1:4318`. Сервер слушает только loopback; для обычного использования не нужен.

## Источники данных

- `docs/design/extron-kit/kit.json`: каталог, палитра и размеры.
- `docs/prefix_map/guide-data.json`: пять use case, шаги, команды и правила текста / иконок; общий источник для PDF и сайта.
- `docs/prefix_map/prefix-data.json`: 22 строки префиксов, формируются генератором шпаргалки.
- `src/figma-plugin/package.json`: текущая версия плагина и совместимого CLI.
- `datetime-format.ts`: 28 форматов; сохранённые рендеры pen.dev: изображения примеров.

Оформление продолжает существующий язык документации Extron Kit. `guides.js` - обычный скрипт: данные подключаются через `kit-data.js`, без fetch и module-импортов, чтобы поддерживать открытие из файлов. Кнопки «скопировать» зависят от Clipboard API браузера; имена можно выделить и скопировать вручную.
