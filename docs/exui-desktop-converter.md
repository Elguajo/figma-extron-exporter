# Конвертация EXUI без PowerShell

Windows-режим существующей утилиты `Extron.LayoutUpdater.exe` использует тот же генератор и независимые проверки, что команда CLI `convert-package`. Режим доступен в локальной сборке после 0.8.8; ранее опубликованные архивы не менялись.

## Использование

1. Дважды щёлкните `Convert-EXUI.cmd` в распакованном комплекте конвертера и выберите свой `.exui`. Можно также перетащить один EXUI на этот файл.
2. Для дальнейшего открытия двойным щелчком нажмите в окне **«Открывать .exui этой утилитой»**. Комплект должен оставаться в постоянной папке. Если Windows уже использует другое приложение, выберите конвертер через **«Открыть с помощью» → «Всегда»**.
3. Откройте любой EXUI двойным щелчком: конвертация запустится автоматически. Утилита сохранит новый GDL рядом с исходным файлом и откроет его в GUI Designer.

Первое свободное имя: `имя.gdl`, затем `имя-v2.gdl`, `имя-v3.gdl` и т. д. Занятый GDL, его отчёт или одноимённая папка не перезаписываются. Исходный EXUI сохраняется. Два одновременных запуска, выбравших одно имя, не перезапишут друг друга: второй покажет ошибку; выберите EXUI повторно.

Рядом сохраняется `.gdl.report.json`. После открытия GDL выполните **Verify → Save and Build** в GUI Designer. Автоматическая конвертация не подтверждает эту ручную проверку и не меняет настроенный проект GCP.

## Совместимость и необходимые файлы

Нужны **.NET Desktop Runtime 10 x64**, установленный GUI Designer с проверенным профилем совместимости и подготовленные GDL-доноры. Утилита не скачивает обновления и не подменяет компоненты Figma. Она использует комплект по своему расположению: `samples/donors.json` ищется от папки приложения вверх, независимо от текущей папки Проводника. Профиль панели берётся из EXUI, SHA-256 донора и версия GUI Designer проверяются существующим движком.

Если версия EXUI не поддерживается, повторите экспорт совместимым плагином. Подготовка доноров описана в [настройке CLI](cli-setup.md). Публичные архивы не содержат закрытых доноров.

`EXUI_DONOR_REGISTRY` задаёт явный путь к своему реестру; неверный путь не приводит к скрытому выбору другого реестра. `EXTRON_GUI_DESIGNER_DIR` задаёт папку GUI Designer. Профили версий и host берутся из папок `compatibility` и `host` рядом с приложением.

## Разработка и снятие регистрации

Из папки сборки: `Extron.LayoutUpdater.exe --convert [полный-путь.exui]`. Без пути открывается окно выбора файла. Без `--convert` сохраняется прежний режим обновления оформления рабочего GDL.

`--register-exui` регистрирует приложение для текущего пользователя, без прав администратора. `--unregister-exui` снимает только регистрацию этой копии. Регистрация сохраняет существующий обработчик другого приложения и защищённый Windows `UserChoice`. После перемещения или обновления комплекта повторно нажмите кнопку регистрации в новой копии.

Регистрация соответствует [документации Microsoft для OpenWithProgids](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-include-an-application-on-the-open-with-dialog-box).
